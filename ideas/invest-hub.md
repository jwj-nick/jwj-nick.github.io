## 1. 진짜 문제 = 소비 → 자산화 ★★ (설계의 중심)

> Nick: *"책·유튜브 엄청 봤지만 계속 소비만 하고 나의 자산화를 못했다."*

→ 허브의 심장은 **정적 페이지가 아니라 인제스천 워크플로우**: 입력 → 전체 체계에 비춰 *어디가 바뀌는지* 판단 → 갱신 → **출처와 함께 영구 기록**. 이게 K를 "분석 도구"가 아니라 **복리로 쌓이는 지혜 자산**으로 만든다.

---

## 2. ★ 인제스천 워크플로우 (핵심 — `invest-ingest`)

유튜브/책/강의/뉴스 **하나를 봤을 때**:
1. **캡처** — 출처·핵심 주장 3줄 추출
2. **라우팅** — 전체 체계(지식·시장관·보유·원칙)에 비춰 분류: *새것 / 강화 / 반박 / 시장관 변화 / 특정 기업 논리에 영향*
3. **갱신** — 해당 모듈에 반영: 명언카드 추가 · 원칙 업데이트 · 시장관 변경 플래그 · 기업 thesis 보강 · 포트폴리오 노트
4. **트레이스** — 출처 링크로 영구 기록 (다시 증발 안 함)

> "이걸 봤을 때 어디가 업데이트되나"를 **워크플로우가 알도록** = Nick이 정확히 요청한 것. (B15 RAG·B16 에이전트와 연결 가능)
