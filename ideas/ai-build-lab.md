## 4. 형식 = 노트북 + 재현 실험 + 측정 대시보드

- **단위 = 실험(experiment)**, 챕터가 아님. 각 실험: `목표 → 코드(노트북) → 돌린 결과 → 측정 숫자 → HW lens 주석 → 다음 질문`
- **재현성**: 누구나(=미래의 Nick) 다시 돌릴 수 있게 — seed·환경·명령 고정
- **측정 대시보드**: tok/s·메모리·양자화별 품질·loss 곡선 (viz 컴포넌트 I44 재사용)
- **HW lens 주석** ★: 모든 소프트 개념에 "이건 하드웨어에서 무슨 비용?"(메모리/사이클/대역폭) 한 줄 — **이게 Nick의 해자이자 A와의 접점**

## 5. A와의 다리 — 두 랩, 한 다리 (억지 연결 아님)

- **공유 노드 = `microgpt-hw`(B10) + NPU lens(B14).** GPT를 RTL로 돌리는 것은 B(소프트 이해)와 A(하드 설계)의 **합법적 교집합** — Nick이 직접 원한 "맥락 확장".
- 두 랩은 **독립**(툴체인·형식 다름: Python/ML vs RTL). 단 이 한 노드에서 만난다. **codec↔NPU 같은 억지 연결과 다름** — 여기는 실제로 같은 객체(GPT)를 두 각도로 본다.
