### P2 — NCC가 스킬·디자인·환경을 자율적·점진적으로 개선한다

> 한 문장 요약: **P1 = 새 도구는 챕터가 당긴다. P2 = 있는 것의 품질은 NCC가 상시 끌어올린다.**

## 3. 아키텍처 — 메가 허브 (대규모 전제)

콘텐츠가 **매우 커질 수 있음** → 처음부터 **manifest 기반 모듈 구조**로.

- **랜딩 = 포지셔닝 지도** (H36, NPU 스코프): "여기서 여기까지 · 지금 내 위치 · 다음 한 걸음"
- **챕터 트리**: A1~A8이 대분류, 각 아래 다수 챕터. `manifest.json`이 사이드바·네비 SSOT
- **챕터 구조** (uvm-drill 규약 재사용): `TL;DR → 본문 → RTL/코드 워크스루 → 데이터플로우 그림 → 검증 포인트 → Gotcha → checkpoint(read-gated)`
- **부속** (챕터당): 퀴즈(I41) · 한 장 카드/SR(I42)
- **횡단 뷰**: 지식그래프(I46) — 커버 vs 빈칸 · 클라이언트 검색
- **커리어 레이어**: 면접 드릴 모드(H39) · 전체가 곧 포트폴리오(H37) · 선별 챕터 → 공개 글(H38)
- **스케일 대비**: 빌드 없음 유지하되 lazy-load + manifest 분할 + 클라이언트 검색으로 수백 챕터 견디게
