# E — 아들(고1) 전용 학습 허브 · 설계 질문

> 2026-06-28 · ⚠️ 이건 **일차 정리(plan)가 아니라 질문 세트**. Nick(+아들)이 답을 채우면 → 종합 계획으로 전환.
> 성격: **하나의 큰 허브** (자기관리 + 성장기록 + 공부거리 탐구 + 실제 학습앱 + 시험준비/오답노트/수행평가 도우미).
> 전제: **E 먼저 완성 → F(딸 중1)로 커스터마이징.** 핵심 = **몇 년 후 본인이 가져가 계속 발전** → *source/DB 관리가 중요*.
> 답하는 법: 번호로 답 주세요(예: "Q1-1: …"). ★제안 = 제 추천 기본값(동의하면 "Q1 ★" 만 쳐도 됨). [아들] = 아들에게 물어볼 것.

## ⭐ 먼저 — 가장 중요한 둘 (이게 나머지를 좌우)

### Q1. 주인의식 & 인계 (handover)
- **1-1.** 지금 운전대는? ★제안: *Nick+NCC가 빌드, 아들은 콘텐츠/사용* → 점차 아들이 빌드까지.
- **1-2.** "몇 년 후 인계"의 그림 — 언제(고3? 졸업?)·무엇을 넘기나(계정·repo·DB 전부)?
- **1-3.** 아들이 **코드를 직접 만지게** 할까? (= 코딩 학습도 목표인가, 아니면 콘텐츠만?) ★제안: *처음엔 콘텐츠만, 관심 보이면 코드 개방.*
- **1-4.** github account: 아들 **단독 소유 계정** 새로 만들까? 지금?

### Q2. 데이터 / DB (본인이 "중요"라 명시)
- **2-1.** 영속성: localStorage(간단·기기종속·인계 약함) vs **클라우드 DB(Supabase 등, 기기무관·인계 쉬움)**? ★제안: *인계가 전제니 Supabase(Postgres+auth).* (가족일기장 전례 있음)
- **2-2.** 무엇을 저장? 시작 엔티티 ★제안: *할일/루틴 · 과목별 진도 · 오답 항목 · 시험 일정·성적 · 수행평가 산출물 · 성장기록(회고)*. 뺄 것·더할 것?
- **2-3.** 프라이버시: 아들 데이터는 **아들만**? Nick도 보나? (성적·회고는 민감) ★제안: *기본 아들 전용, 공유 항목만 옵트인.*

## 나머지 테마

### Q3. 허브 범위 & 기존 자산
- **3-1.** 다 한 앱에(자기관리+성장+학습+도우미) vs 모듈 분리? ★제안: *한 허브 쉘 + 내부 모듈.*
- **3-2.** 기존 자산 흡수? — `high1`(과학 수행평가·수학 오답노트) · 가족일기장 · `02_App_Eng`(app-high). ★제안: *high1·영어는 모듈로 흡수, 가족일기장은 별개 유지.*
- **3-3.** 과목 범위: 전과목 vs 핵심 몇 개부터? ★제안: *수학·과학·영어부터, 점진 확장.*

### Q4. 자기관리 & 성장기록
- **4-1.** "성장 기록"의 의미: 정량(점수·진도) / 정성(회고·소감) / 포트폴리오(만든 것·수행평가물) 중 어디에 무게?
- **4-2.** 자기관리 수준: 체크앱(루틴) 정도? 아니면 목표설정·주간계획까지?
- **4-3.** 동기 설계: streak·배지? 아니면 담백하게 기록만? ([아들] 취향 반영)

### Q5. 학습 도우미 (시험·오답·수행평가)
- **5-1.** 오답노트: LearningSystem `se_math_error_note` 패턴 재사용 + 전과목 확장? ★제안: *예.*
- **5-2.** 수행평가 도우미: `se_perf_eval_step`(Step별 사고구조) 패턴 적용? ★제안: *예.*
- **5-3.** 시험준비: 퀴즈(`quiz-publish`/study-quiz) + SR 연계? ★제안: *예.*
- **5-4.** 공부거리 탐구: 무엇을 더 팔지 **아들 관심에서 출발**? → [아들] 입력 필요(Q8).

### Q6. 기술 스택 & 수명 (몇 년)
- **6-1.** 프론트: 바닐라(읽기 쉬움) vs 프레임워크(React+Vite, 가족일기장과 일관). ★제안: *DB 붙는 큰 허브라 Vite+React, 단 단순·문서화 우선(인계 위해).*
- **6-2.** 호스팅: 아들 계정 Pages(정적) + Supabase(데이터)? 아니면 Vercel? ★제안: *Vercel + Supabase(가족일기장과 동일 — 노하우 재사용).*
- **6-3.** 공개/비공개: 아들 성장기록이라 **private-first**? ★제안: *예, 로그인 뒤. 공개는 아들이 원하는 산출물만.*

### Q7. E→F 재사용 설계
- **7-1.** E를 처음부터 **"공통 코어 + 데이터/커스텀 분리"**로 지어 F 복제 쉽게? ★제안: *예 — generator화.*
- **7-2.** 두 아이 공통(코어 기능) vs 개별(과목·학년·취향) 경계는 어디?

### Q8. [아들에게 물어볼 것] — 본인 입력
- **8-1.** 지금 공부에서 **가장 불편하거나 있었으면 하는 것** 1가지?
- **8-2.** 관심사(공부 안이라도) — 공부거리 탐구의 씨앗.
- **8-3.** 색·디자인·이름 취향 (아이 선택 존중 원칙).
