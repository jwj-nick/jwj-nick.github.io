AI가 일하는 방식: 설명 그림 네 장

일이 들어오면 AI가 받아 분류하고, 표준 workflow로 결과 패키지까지 끌고 가고, 사람은 검수와 반영에서 판정한다. 네 장은 순서대로 읽어도 되고, 필요한 장만 열어도 된다.

1

core 한 장

일 하나가 지나가는 아홉 단계, 단계마다 남는 파일, 사람이 나타나는 자리, gate의 다섯 조건, label 흐름.
2

workflow 표준화

공통 골격 → 작업 모양 일곱 → 업무별 특화. 여덟 자리, phase("원인만"·"수정만"), 상속 규칙, workflow가 없는 일의 세 경로.
3

조립과 RTL review

간선 종류와 task 경계, RTL review A~E pipeline과 preset, 리뷰 → 자동 수정, 합성 matrix의 값 출처와 낡음, 사슬 한 줄.
4

agent system

부품 지도(코드와 LLM), task 폴더 파일과 계약, 자율 선언의 두 겹 경계, 세션 수명, 세 hard-zero, 세우는 순서.
