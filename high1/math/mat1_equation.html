🧮 여러 가지 방정식과 부등식

고차·연립·절댓값도 두 무기(인수분해·대입)로

📋 더 복잡해도 원리는 같다

💥 왜 배우나
방정식이 삼차·사차로 커지고, 미지수가 둘로 늘고, 절댓값이 끼어들어도 두려워 말자. 인수분해(쪼개기)와 대입(하나로 줄이기)이라는 두 무기면 다 풀린다. 실제로 예산·시간 같은 제약(부등식) 아래 최선을 찾는 것이 세상의 문제 대부분이다.
📐
부등식 = 제약, 그리고 최적화
"예산은 100만 원 이하", "시간은 8시간 이내" — 현실의 조건은 대부분 부등식이다. 여러 부등식이 만드는 가능한 영역 안에서 최선을 찾는 것이 선형계획법이고, 물류·생산·투자의 핵심 도구다.

🔺 고차방정식 — 인수분해로

삼차·사차 방정식은 인수정리로 인수를 하나 찾아 차수를 낮춰 가며 푼다. (앞 단원 다항식의 인수분해가 여기서 쓰인다.)

문제: $x^3 - 6x^2 + 11x - 6 = 0$ 을 푸시오.
1$x=1$ 대입: $1-6+11-6 = 0$ → $(x-1)$ 이 인수 (인수정리).
2$(x-1)$ 로 나눠(조립제법) 몫: $x^2 - 5x + 6$.
3$x^2 - 5x + 6 = (x-2)(x-3)$.
$(x-1)(x-2)(x-3) = 0 \Rightarrow x = 1,\ 2,\ 3$
🔑 요령
대입할 값은 상수항의 약수 ÷ 최고차항 계수의 약수 중에서 찾는다(유리근 후보). 여기선 상수항 $-6$ 의 약수 $\pm 1, \pm 2, \pm 3, \pm 6$ 을 하나씩 넣어 본다.

🔗 연립방정식 — 하나로 줄이기

미지수가 둘이면, 한 식을 다른 식에 대입(대입법)하거나 더하고 빼서 한 변수를 없앤다(가감법). 결국 미지수 하나짜리로 줄여 푼다.

문제: $\begin{cases} x + y = 5 \\ 2x - y = 1 \end{cases}$
1두 식을 더하면 $y$ 가 사라진다: $(x+y)+(2x-y) = 5+1$ → $3x = 6$.
2$x = 2$.
3$x=2$ 를 $x+y=5$ 에 대입: $2 + y = 5$ → $y = 3$.
$x = 2,\ y = 3$
✅ 검산
$x+y = 2+3 = 5$ ✓, $2x-y = 4-3 = 1$ ✓. 두 식을 모두 만족하면 정답.

⚖️ 여러 가지 부등식

✅ 절댓값 부등식
$|x| < a$ ($a>0$) $\iff -a < x < a$ (원점에서 거리가 $a$ 보다 가까움)
$|x| > a$ ($a>0$) $\iff x < -a$ 또는 $x > a$ (거리가 $a$ 보다 멂)

연립일차부등식 — 공통 범위

두 부등식을 동시에 만족하는 $x$ = 각 해의 공통 부분(교집합). 수직선으로 보자.

⚠️ 부등식의 함정
부등식 양변에 음수를 곱하거나 나누면 부등호 방향이 바뀐다. 예: $-2x < 6$ 의 양변을 $-2$ 로 나누면 $x > -3$ (방향 반대!).

🌐 세상 속으로

📌 어른이 되어도 기억할 것
  1. 고차방정식은 인수분해(인수정리)로, 연립방정식은 대입·가감으로 푼다.
  2. 절댓값 부등식: $|x|<a \iff -a<x<a$, $|x|>a \iff x<-a$ 또는 $x>a$.
  3. 부등식 양변에 음수를 곱/나누면 부등호가 뒤집힌다. 연립부등식의 해는 공통 범위.
💡 인사이트 — 제약 속에서 최선 찾기
현실의 문제는 대부분 "여러 제약(부등식) 아래 무엇을 최대/최소로?"다. 예산·시간·자원의 부등식이 만드는 가능 영역에서 최선을 찾는 것이 최적화다. 이 사고가 경영·물류·AI를 움직인다.
