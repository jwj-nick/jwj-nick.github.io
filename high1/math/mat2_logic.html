🔀 명제

참·거짓을 따지는 법 — 논리의 문법

📋 참과 거짓의 규칙

💥 왜 배우나
명제는 참·거짓을 분명히 판별할 수 있는 문장이다. "~이면 ~이다"의 논리를 다루는 법 — 역·이·대우, 충분·필요조건, 증명 — 은 수학뿐 아니라 법률·프로그래밍·토론의 뼈대다. AI가 추론하는 방식도 이 논리 위에 있다.
🧠
아리스토텔레스 → 불 대수 → 컴퓨터
고대 아리스토텔레스의 삼단논법에서 시작한 논리는, 19세기 불(Boole)이 참=1·거짓=0의 대수로 바꿨다. 이 불 대수가 오늘날 모든 컴퓨터의 회로와 조건문이 되었다.

🔀 역 · 이 · 대우

원명제 "x = 3 이면 x² = 9 이다" 에서 만든 네 문장. 카드를 눌러 참·거짓을 확인하자.

원명제 p → q
x = 3 이면 x² = 9
눌러서 참·거짓 ▾
참 ✓ (3² = 9)
역 q → p
x² = 9 이면 x = 3
눌러서 참·거짓 ▾
거짓 ✗ (x = −3 반례)
이 ~p → ~q
x ≠ 3 이면 x² ≠ 9
눌러서 참·거짓 ▾
거짓 ✗ (x = −3 반례)
대우 ~q → ~p
x² ≠ 9 이면 x ≠ 3
눌러서 참·거짓 ▾
참 ✓ (원명제와 동치)
✅ 핵심 — 대우는 원명제와 동치
원명제와 대우는 참·거짓이 항상 같다(동치). 역과 이도 서로 동치. 그래서 어떤 명제를 직접 증명하기 어려우면 대우를 증명한다(대우법).
⚠️ 흔한 오해
원명제가 참이라고 역이 참인 것은 아니다. 위에서 "x=3 → x²=9"는 참이지만 역 "x²=9 → x=3"은 거짓(x=−3). 참·거짓을 뒤집는 건 반례 하나면 충분.

⚖️ 충분조건과 필요조건

✅ 정의
명제 $p \to q$ 가 참일 때, $p$ 는 $q$ 이기 위한 충분조건, $q$ 는 $p$ 이기 위한 필요조건. $p \to q$ 와 $q \to p$ 가 모두 참이면 $p \leftrightarrow q$ 로 필요충분조건(서로 동치).
🧭 집합으로 이해하기
조건을 만족하는 원소의 집합을 $P, Q$ 라 하면, $p \to q$ 가 참 $\iff$ $P \subset Q$. "작은 쪽이 충분, 큰 쪽이 필요" — 충분조건의 집합이 필요조건의 집합에 포함된다.
🔎 예제
$p$: "$x$ 는 $4$ 의 배수", $q$: "$x$ 는 $2$ 의 배수". $4$ 의 배수는 모두 $2$ 의 배수이므로 $P \subset Q$, 즉 $p \to q$ 참. 따라서 $p$ 는 충분조건, $q$ 는 필요조건. (역은 거짓: $6$ 은 $2$ 의 배수지만 $4$ 의 배수 아님.)
💬 일상 비유
"서울에 산다"($p$) → "한국에 산다"($q$). 서울 거주는 한국 거주의 충분조건(서울이면 반드시 한국), 한국 거주는 서울 거주의 필요조건(한국이 아니면 서울일 수 없음).

📈 절대부등식 — 산술·기하 평균

두 양수 $a, b$ 를 바꿔 보자. 산술평균 $\frac{a+b}{2}$ 은 항상 기하평균 $\sqrt{ab}$ 보다 크거나 같다. 언제 같아질까?

a2
b8
산술 (a+b)/2
5
기하 √(ab)
4
✅ 산술·기하 평균 부등식
$a > 0, b > 0$ 일 때 $\dfrac{a+b}{2} \ge \sqrt{ab}$, 즉 $a + b \ge 2\sqrt{ab}$. 등호는 $a = b$ 일 때만 성립. (양변을 이용해 최솟값·최댓값 문제를 푼다.)
✅ 자주 쓰는 절대부등식
모든 실수에서 $a^2 + b^2 \ge 2ab$ (등호 $a=b$), $a^2 \ge 0$. 절대부등식 = 문자의 값에 관계없이 항상 성립하는 부등식.

🌐 세상 속으로

📌 어른이 되어도 기억할 것
  1. 대우는 원명제와 동치 (참·거짓이 항상 같다). 증명이 막히면 대우로.
  2. $p \to q$ 참 → $p$ 는 충분, $q$ 는 필요. "작은 쪽이 충분".
  3. 산술·기하 평균: $\frac{a+b}{2} \ge \sqrt{ab}$, 등호는 $a = b$.
💡 인사이트 — 논리가 곧 코드
프로그램의 if 조건문, 회로의 논리 게이트, 법조문의 "~한 경우 ~한다"가 전부 명제 논리다. 특히 대우는 알고리즘·증명에서 문제를 뒤집어 푸는 강력한 도구다.
🌀 "이 문장은 거짓이다" — 논리가 만나는 벽
이 문장을 참이라 하면 문장 말대로 거짓이어야 하고, 거짓이라 하면 참이어야 한다 — 참·거짓을 매길 수 없는 문장이 생긴다(자기지시의 역설). 20세기 괴델은 이 아이디어를 정교하게 다듬어 불완전성 정리를 증명했다(1931) — 산술을 포함할 만큼 강력하면서 스스로 모순되지 않는 어떤 수학 체계든, 그 체계의 규칙만으로는 증명할 수 없지만 실제로는 참인 명제가 반드시 존재한다는 것이다. 명제 논리가 세상을 "참 아니면 거짓"으로 깔끔하게 나누는 도구처럼 보여도, 그 도구로 다 담을 수 없는 문장이 있다는 뜻이다.
