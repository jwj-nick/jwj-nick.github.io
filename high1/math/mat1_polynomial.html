💥 왜 배우나
복잡한 식도 곱셈 공식으로 펼치고, 인수분해로 조각내면 다룰 수 있다. 인수분해는 방정식을 푸는 만능 열쇠다. 놀랍게도 "큰 수를 소인수로 쪼개기 어렵다"는 성질은 인터넷을 지키는 암호(RSA)의 토대가 된다.
🔺
파스칼의 삼각형
$(a+b)^n$ 을 전개하면 각 항의 계수가 파스칼의 삼각형(1, 1 1, 1 2 1, 1 3 3 1 …)과 정확히 일치한다. 예: $(a+b)^2 = a^2 + 2ab + b^2$ 의 계수 1, 2, 1. 규칙을 알면 외울 필요가 줄어든다.

🧮 다항식의 연산과 곱셈 공식

다항식의 덧셈·뺄셈은 동류항끼리, 곱셈은 분배법칙으로 한다. 자주 쓰는 곱셈 공식은 외워 두면 빠르다. 카드를 눌러 전개 결과를 확인하자.

🔑 곱셈 공식은 "인수분해의 반대"
곱셈 공식은 펼치기($ (a+b)^2 \to a^2+2ab+b^2 $), 인수분해는 그 거꾸로($ a^2+2ab+b^2 \to (a+b)^2 $)다. 같은 공식을 양방향으로 쓴다.

➗ 나머지정리와 인수정리

✅ 나머지정리
다항식 $P(x)$ 를 $(x-a)$ 로 나눈 나머지는 $P(a)$ 와 같다. 즉, 직접 나눌 필요 없이 $x=a$ 를 대입하면 나머지를 안다.

아래 $P(x)$ 에 대해 $a$ 를 골라 $P(a)$(=나눈 나머지)를 계산해 보자.

$P(x) = x^3 - 2x^2 - x + 2$
✅ 인수정리
$P(a) = 0$ 이면 $(x-a)$ 는 $P(x)$ 의 인수다 (그 반대도 성립). 즉 대입해서 0이 되는 값을 찾으면 인수를 하나 찾은 것 — 이것이 고차식 인수분해의 열쇠.

🧩 인수분해 — 단계별

인수분해는 곱셈 공식을 거꾸로 쓰거나, 인수정리로 인수를 찾아 낮춰 간다. 예제를 단계별로 풀어 보자.

문제: $x^3 - 7x - 6$ 을 인수분해하시오.
1대입해서 0이 되는 값 찾기: $x=-1$ 이면 $(-1)^3-7(-1)-6 = -1+7-6 = 0$.
→ 인수정리로 $(x+1)$ 이 인수임을 알았다.
2$(x+1)$ 로 나눠(조립제법) 몫을 구하면 $x^2 - x - 6$.
→ 차수가 3에서 2로 낮아졌다.
3남은 이차식 인수분해: $x^2 - x - 6 = (x-3)(x+2)$.
→ 곱이 $-6$, 합이 $-1$ 인 두 수 $-3, +2$.
$x^3 - 7x - 6 = (x+1)(x+2)(x-3)$
⚠️ 흔한 실수
인수분해를 다 끝냈는지 확인하기. 이차식이 또 인수분해될 수 있는데 멈추면 안 된다. 각 인수가 더 쪼갤 수 없을 때까지 진행.

🌐 세상 속으로

📌 어른이 되어도 기억할 것
  1. 대표 곱셈 공식: $(a\pm b)^2 = a^2 \pm 2ab + b^2$, $(a+b)(a-b) = a^2 - b^2$.
  2. 나머지정리: $P(x)$ 를 $(x-a)$ 로 나눈 나머지 $= P(a)$. 대입 한 번으로 끝.
  3. 인수분해는 방정식을 푸는 열쇠 — 곱이 0이면 각 인수가 0(예: $(x-3)(x+2)=0 \Rightarrow x=3$ 또는 $x=-2$).
💡 인사이트 — 다음 단원의 무기
인수분해는 이차·고차 방정식을 푸는 핵심 도구다. $ (x-3)(x+2)=0 $ 처럼 인수의 곱이 0이면 해가 바로 보인다. 그래서 다항식은 방정식과 부등식 단원의 토대가 된다.

✅ 정리 — 핵심 공식

곱셈 공식
$(a+b)^2 = a^2 + 2ab + b^2$
$(a-b)^2 = a^2 - 2ab + b^2$
$(a+b)(a-b) = a^2 - b^2$
$(x+a)(x+b) = x^2 + (a+b)x + ab$
$(a+b)^3 = a^3 + 3a^2 b + 3ab^2 + b^3$
$(a+b)(a^2 - ab + b^2) = a^3 + b^3$
🔑 한 줄 요약
곱셈 공식으로 펼치고 인수분해로 쪼갠다. 나머지정리 $P(a)$ 와 인수정리로 고차식을 낮춰 인수분해하면, 방정식이 풀린다.
