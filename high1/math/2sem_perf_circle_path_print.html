1. 원형 생태공원과 산책로 설계하기
과천시는 주민들이 이용할 수 있는 원형 생태공원과 직선 모양의 산책로를 만들려고 한다. 이를 좌표평면에 나타냈을 때 원형 생태공원의 중심은 C(2, 1)이고, 반지름의 길이는 3이다. 또한 좌표평면에서 한 눈금의 실제 길이는 10 m이다. 생태공원 밖에 있는 점 A(−3, 1)에서 출발하여 공원에 닿는 직선 모양의 산책로를 만들려고 한다. 이때 산책로는 생태공원의 내부를 지나지 않고 공원의 경계와 한 점에서만 만나도록 설계한다. (단, 산책로의 폭은 생각하지 않는다.)
문제 1. 원형 생태공원의 방정식 — 중심이 C(2, 1)이고 반지름의 길이가 3인 원형 생태공원의 경계를 나타내는 원의 방정식을 구하시오.
문제 2. 산책로의 방정식 — 점 A(−3, 1)을 지나고 기울기가 m인 직선의 방정식을 y − 1 = m(x + 3)이라고 하자. 이 직선이 원형 생태공원의 경계와 한 점에서만 만나도록, 즉 원형 생태공원에 접하도록 산책로를 만들려고 한다.
1. 가능한 기울기 m의 값을 모두 구하시오.
2. 두 산책로의 방정식을 각각 구하시오.
문제 3. 산책로와 원형 생태공원이 만나는 점 — 문제 2에서 구한 두 산책로 중 기울기가 양수인 산책로를 선택하자. 이 산책로와 원형 생태공원이 만나는 점을 P라고 할 때, 점 P의 좌표를 구하시오.
문제 4. 실제 산책로의 길이 — 점 A에서 문제 3에서 구한 접점 P까지 산책로를 설치하려고 한다. 좌표평면에서 한 눈금의 실제 길이가 10 m일 때, 설치해야 하는 산책로 AP의 실제 길이를 구하시오. 풀이 과정과 단위를 함께 나타내시오.

만점 답안 예시 — 1번

문제 1. 원의 방정식
중심이 (a, b)이고 반지름의 길이가 r인 원의 방정식은 (x − a)² + (y − b)² = r² 이다.
중심이 C(2, 1), 반지름이 3이므로
(x − 2)² + (y − 1)² = 9
문제 2-1. 기울기 m
직선 y − 1 = m(x + 3)을 정리하면 mx − y + (3m + 1) = 0
직선이 원에 접하려면 원의 중심 C(2, 1)에서 이 직선까지의 거리가 반지름 3과 같아야 하므로
|2m − 1 + 3m + 1| / √(m² + 1) = 3
→ |5m| / √(m² + 1) = 3
양변을 제곱하면 25m² = 9(m² + 1)
→ 16m² = 9 → m² = 9/16
m = 3/4 또는 m = −3/4
문제 2-2. 두 산책로의 방정식
m = 3/4 : y − 1 = (3/4)(x + 3) → ▶ y = (3/4)x + 13/4 (일반형 3x − 4y + 13 = 0)
m = −3/4 : y − 1 = −(3/4)(x + 3) → ▶ y = −(3/4)x − 5/4 (일반형 3x + 4y + 5 = 0)
문제 3. 접점 P — 방법 A (대입 → 중근, 교과서 표준)
기울기가 양수인 산책로 y = (3/4)x + 13/4를 원의 방정식에 대입한다.
(x − 2)² + ((3/4)x + 13/4 − 1)² = 9
→ (x − 2)² + ((3x + 9)/4)² = 9
양변에 16을 곱하면 16(x − 2)² + (3x + 9)² = 144
전개하여 정리하면 25x² − 10x + 1 = 0
→ (5x − 1)² = 0 (접하므로 중근)
→ x = 1/5, y = (3/4)(1/5) + 13/4 = 17/5
P(1/5, 17/5)
문제 3. 접점 P — 방법 B (수선의 발, 계산이 짧다)
접점 P는 원의 중심 C에서 접선에 내린 수선의 발이다. (접선 ⊥ 반지름 CP)
접선에 수직인 직선의 기울기는 −4/3 이고 C(2, 1)을 지나므로 y − 1 = −(4/3)(x − 2) → y = −(4/3)x + 11/3
두 직선을 연립: (3/4)x + 13/4 = −(4/3)x + 11/3
양변에 12를 곱하면 9x + 39 = −16x + 44
→ 25x = 5 → x = 1/5, y = 17/5
P(1/5, 17/5) (방법 A와 일치)
검산 — P가 원 위에 있는가
(1/5 − 2)² + (17/5 − 1)² = (−9/5)² + (12/5)² = 81/25 + 144/25 = 9 = 9 ✓
문제 4. 실제 길이 — 방법 A (두 점 사이 거리)
두 점 A(−3, 1), P(1/5, 17/5) 사이의 거리는
AP = √((1/5 + 3)² + (17/5 − 1)²) = √((16/5)² + (12/5)²) = √(256/25 + 144/25) = √16 = 4
한 눈금의 실제 길이가 10 m이므로 실제 길이 = 4 × 10 = 40 m
산책로 AP의 실제 길이는 40 m
문제 4. 검산 — 방법 B (접선의 길이, 직각삼각형)
접점 P에서 반지름 CP ⊥ 접선 AP 이므로 △APC는 ∠P = 90°인 직각삼각형.
A와 C의 y좌표가 같으므로 AC = |2 − (−3)| = 5, CP = 3
AP = √(AC² − CP²) = √(25 − 9) = √16 = 4 ✓ (문제 3의 P가 틀려도 이 값은 살아남는다)
2. LED 라인의 최소 길이
한 미술관에서는 칸딘스키풍 작품을 대형 미디어아트로 제작하려고 한다. 작품 속 두 원형 무늬 C₁, C₂와 두 직선 무늬를 따라 빛이 이어지도록 일부 구간에 LED라인을 설치할 계획이다. 설계도에서 두 원은 C₁: (x − 8)² + (y − 2)² = 4, C₂: (x − 3)² + (y + 4)² = 4로 나타내고, 두 직선 무늬는 각각 x축과 직선 y = x로 나타낸다. LED 라인은 원 C₁ 위의 점 A에서 시작하여 x축 위의 점 P, 직선 y = x 위의 점 Q를 차례로 지나 원 C₂ 위의 점 B까지 연결하려고 한다.
LED 라인을 최소한으로 사용하여 설계하려고 할 때, 필요한 LED 라인의 최소 길이를 구하는 풀이 과정과 답을 논술하시오. (단, 그림은 문제의 이해를 돕기 위한 예시도이다.)

만점 답안 예시 — 2번

① P가 놓인 x축에 대하여 A를 대칭이동
원 C₁ 위의 점 A를 x축에 대하여 대칭이동한 점을 A′이라 하자. [x축 대칭: (x, y) → (x, −y)]
점 P는 x축 위의 점이고, x축은 선분 AA′의 수직이등분선이므로 AP = A′P
② Q가 놓인 직선 y = x에 대하여 B를 대칭이동
원 C₂ 위의 점 B를 직선 y = x에 대하여 대칭이동한 점을 B′이라 하자. [직선 y = x 대칭: (x, y) → (y, x)]
점 Q는 직선 y = x 위의 점이므로 같은 이유로 QB = QB′
③ 꺾인 길을 곧은 길로
AP + PQ + QB = A′P + PQ + QB′ ≥ A′B′
(두 점을 잇는 가장 짧은 길은 선분. 등호는 P, Q가 선분 A′B′ 위에 이 순서로 놓일 때)
④ 대칭이동한 원(점)의 방정식
A가 원 C₁ 위를 움직이므로 A′은 원 C₁을 x축에 대하여 대칭이동한 원 C₁′: (x − 8)² + (y + 2)² = 4 (중심 C₁′(8, −2), 반지름 2) 위를 움직인다.
B가 원 C₂ 위를 움직이므로 B′은 원 C₂를 직선 y = x에 대하여 대칭이동한 원 C₂′: (x + 4)² + (y − 3)² = 4 (중심 C₂′(−4, 3), 반지름 2) 위를 움직인다.
(원의 대칭이동 = 중심만 대칭이동, 반지름은 그대로)
⑤ 두 원 위의 점 사이의 최소 거리
C₁′C₂′ = √((8 + 4)² + (−2 − 3)²) = √(144 + 25) = √169 = 13
13 > 2 + 2 이므로 두 원은 서로 밖에 있다. 점에서 원 위의 점까지 거리의 최솟값 = (중심까지의 거리) − (반지름) 을 두 번 쓴다.
A′을 고정하면 B′이 원 C₂′ 위를 움직이므로 A′B′ ≥ A′C₂′ − 2
A′이 원 C₁′ 위를 움직이므로 A′C₂′ ≥ C₁′C₂′ − 2 = 13 − 2 = 11
A′B′의 최솟값 = 13 − 2 − 2 = 9 (등호: A′, B′이 선분 C₁′C₂′ 위에 있을 때)
⑥ 답
따라서 LED 라인의 최소 길이는 9 (좌표 단위)
순서 확인
(선택 보강 — 시간이 남으면) 최솟값을 주는 A′(80/13, −16/13), B′(−28/13, 29/13)에 대하여 선분 A′B′은 x축을 P(16/5, 0)에서, 직선 y = x를 Q(16/17, 16/17)에서 차례로 지나므로 A → P → Q → B 순서의 경로가 실제로 존재한다.
이때 A(80/13, 16/13), B(29/13, −28/13).
같은 답이 나오는 다른 방법: A를 x축에 대칭 → A′, 다시 A′을 y = x에 대칭 → A″(중심 (−2, 8)) 으로 잡고 A″C₂ 거리 13에서 4를 빼도 9. 둘 다 정답. 기본은 위 방법(양 끝점을 각각 한 번씩).

2. 답안 틀 카드 — ▢에 숫자만 갈아끼운다

카드 ① 1번형

문제 1 — 원의 방정식
중심이 (▢, ▢)이고 반지름의 길이가 ▢인 원의 방정식은
(x − ▢)² + (y − ▢)² = ▢² → ▢
문제 2-1 — 기울기 m
직선 y − ▢ = m(x − ▢)를 정리하면 mx − y + (▢m + ▢) = 0
직선이 원에 접하려면 원의 중심 C(▢, ▢)에서 이 직선까지의 거리가 반지름 ▢과 같아야 하므로
|▢m + ▢| / √(m² + 1) = ▢ → 양변 제곱 → ▢m² = ▢(m² + 1) → m² = ▢
(A와 C가 수직 배치면 m이 사라지고 상수만 남는다: |▢| / √(m² + 1) = ▢ → ▢ = ▢(m² + 1))
따라서 m = ▢ 또는 m = −▢ (둘 다 쓴다)
문제 2-2 — 두 직선
m = ▢ : y − ▢ = ▢(x − ▢) → y = ▢x + ▢
m = −▢ : y − ▢ = −▢(x − ▢) → y = −▢x + ▢
문제 3 — 접점 P (방법 A: 대입 → 중근)
기울기가 ▢수인 직선 y = ▢x + ▢ 를 원에 대입하면
(x − ▢)² + (▢x + ▢)² = ▢ → 양변에 ▢를 곱하고 전개·정리 → ▢x² + ▢x + ▢ = 0
접하므로 중근: (▢x + ▢)² = 0 → x = ▢, y = ▢
따라서 P(▢, ▢) [검산: (▢ − ▢)² + (▢ − ▢)² = ▢ ✓]
문제 3 — 접점 P (방법 B: 수선의 발)
접점은 중심 C에서 접선에 내린 수선의 발이다. 접선에 수직이고 C(▢, ▢)를 지나는 직선: y − ▢ = ▢(x − ▢)
두 직선을 연립: ▢x + ▢ = ▢x + ▢ → 양변에 ▢를 곱하면 ▢x + ▢ = ▢x + ▢ → x = ▢, y = ▢ → P(▢, ▢)
문제 4 — 실제 길이
AP = √((▢ − ▢)² + (▢ − ▢)²) = √(▢ + ▢) = √▢ = ▢
한 눈금의 실제 길이가 ▢ m이므로 실제 길이 = ▢ × ▢ = ▢ m (단위!)
[검산: CP ⊥ AP, AC = ▢, CP = ▢ → AP = √(AC² − CP²) = √(▢ − ▢) = ▢ ✓]

카드 ② 2번형

① 대칭이동 (P가 놓인 직선에 A를)
원 C₁ 위의 점 A를 ▢에 대하여 대칭이동한 점을 A′이라 하자. [▢ 대칭: (x, y) → (▢, ▢)]
점 P는 ▢ 위의 점이고 ▢은 선분 AA′의 수직이등분선이므로 AP = A′P
② 대칭이동 (Q가 놓인 직선에 B를)
원 C₂ 위의 점 B를 ▢에 대하여 대칭이동한 점을 B′이라 하자. [▢ 대칭: (x, y) → (▢, ▢)]
점 Q는 ▢ 위의 점이므로 QB = QB′
③ 부등식
AP + PQ + QB = A′P + PQ + QB′ ≥ A′B′ (등호: P, Q가 선분 A′B′ 위에 이 순서로 놓일 때)
④ 대칭이동한 원
A′은 원 C₁을 ▢에 대칭이동한 원 C₁′: (x − ▢)² + (y − ▢)² = ▢ (중심 (▢, ▢), 반지름 ▢) 위를 움직인다.
B′은 원 C₂를 ▢에 대칭이동한 원 C₂′: (x − ▢)² + (y − ▢)² = ▢ (중심 (▢, ▢), 반지름 ▢) 위를 움직인다.
⑤ 두 원 위의 점 사이 최소 거리 (점–원 최소 거리를 두 번)
C₁′C₂′ = √((▢ − ▢)² + (▢ − ▢)²) = √(▢ + ▢) = √▢ = ▢ (▢ > ▢ + ▢ 이므로 두 원은 서로 밖)
점에서 원 위의 점까지 거리의 최솟값 = (중심까지의 거리) − (반지름) 이므로 A′B′ ≥ A′C₂′ − ▢, A′C₂′ ≥ C₁′C₂′ − ▢
따라서 A′B′의 최솟값 = ▢ − ▢ − ▢ = ▢ (등호: A′, B′이 선분 C₁′C₂′ 위에 있을 때)
⑥ 답 (+ 선택 보강)
따라서 최소 길이는 ▢
(선택) 중심 C₁′(▢, ▢)과 C₂′(▢, ▢)을 잇는 선분은 ▢을 P(▢, ▢)에서, ▢을 Q(▢, ▢)에서 차례로 지나므로 A → P → Q → B 순서의 경로가 실제로 존재한다.
대칭 규칙표: x축 (x, y)→(x, −y) · y축 (x, y)→(−x, y) · y = x (x, y)→(y, x) · (참고, 범위 밖) y = −x (x, y)→(−y, −x)

원리 그림 — 왜 이 방법이 되는가

접선 = 중심에서 거리가 r인 직선

A에서 원에 그을 수 있는 접선은 두 개(실선·점선). 접점 P에서 반지름 CP ⊥ 접선이라 △APC는 직각삼각형: AC = d, CP = r, AP = ℓ = √(d² − r²). 그래서 "중심에서 직선까지의 거리 = r"이 접선 조건이고, A가 C와 수평이면 기울기는 ±r/ℓ.

대칭이동 = 꺾인 길 펴기

실선 A→P→Q→B가 실제 경로. A를 x축에, B를 y = x에 대칭이동하면(점선 원) 경로 길이는 그대로인데 모양이 직선 C₁′→C₂′(초록 점선)으로 펴진다. "점에서 원 위의 점까지 최소 거리 = 중심까지 거리 − 반지름"을 두 번 쓰면 최솟값 = 중심 거리 − r₁ − r₂ = 13 − 2 − 2 = 9.
