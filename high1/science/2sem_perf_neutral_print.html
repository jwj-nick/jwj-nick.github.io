1. 모범답안 카드 9장 (키워드 = 노란 표시)

① 중화점에서 용액의 부피
같은 농도의 묽은 염산과 수산화 나트륨 수용액은 같은 부피에 같은 수의 H⁺과 OH⁻이 들어 있고 1:1로 반응한다. 따라서 염산 20 mL의 중화점은 수산화 나트륨 수용액 20 mL를 넣었을 때이고, 혼합 용액의 전체 부피는 20 + 20 = 40 mL이다. 표·그래프에서는 온도가 가장 높은 지점이 중화점이다.
감점: 넣은 부피만 쓰고 전체 부피(합)를 안 씀 · "같은 농도" 조건 누락 · 단위 누락. → 넣은 부피와 전체 부피 둘 다 쓴다. 수업 실측 표(최고 12 mL)가 나오면 농도가 달랐다는 뜻이니 온도 최고점 근거만 쓴다.
② 혼합 용액의 액성
액성은 반응하고 남아 있는 이온으로 정한다. 염산 20 mL에 NaOH 12 mL → H⁺이 남으므로 산성(20−12 = 8 mL분). 20 mL → 모두 반응하여 중성. 28 mL → OH⁻이 남으므로 염기성(28−20 = 8 mL분).
감점: "산성이다"만 쓰고 남은 이온 근거 없음 · 부피 비교 없이 감으로 판단. → 남은 이온 = 큰 쪽 − 작은 쪽을 숫자로 적는다. Na⁺·Cl⁻은 근거가 아니다.
③ 열 출입 형태
중화 반응은 중화열이 발생하는 발열 반응이다(열을 방출한다).
감점: "온도가 올라간다"만 쓰고 발열·중화열 용어 없음.
④ 열 출입을 판단한 근거
NaOH를 넣을수록 혼합 용액의 온도가 처음보다 높아져 중화점에서 가장 높았다. H⁺과 OH⁻이 반응해 물이 생성될 때 중화열이 발생하고, 반응하는 이온 수가 많을수록 중화열이 더 많이 발생하기 때문이다. 중화점 이후에는 H⁺이 없어 중화 반응이 일어나지 않아 중화열이 발생하지 않고, 혼합 용액보다 온도가 낮은(처음 온도의) NaOH 수용액이 더해지므로 온도가 낮아진다.
감점: "온도가 올랐으니까"로 끝냄 · 이후 하강 이유에서 "온도 낮은 용액 추가"를 빠뜨림. 유형 주의: "낮은 용액 추가"는 한 비커에 계속 넣는 적정형에서만. A~E 고정형·(가)~(라) 조합형은 "반응한 이온 수가 많을수록 중화열이 많다(남는 용액은 열을 안 낸다)" 한 축으로.
⑤ 생활 속 중화 반응 사례
문장 틀 = 상황 + 무엇을 넣어 + 중화. ① 위산 과다로 속이 쓰릴 때 약한 염기성 물질이 든 제산제를 먹어 위산을 중화한다. ② 입안 세균이 만든 산성 물질이 충치를 일으키므로 염기성 물질이 든 치약으로 닦아 중화한다. ③ 생선의 비린내(염기성)를 산성인 레몬즙으로 중화한다. ④ 산성화된 토양·호수에 염기성 석회 가루를 뿌린다. ⑤ 배기가스의 황산화물을 산화 칼슘과 반응시켜 제거한다. ⑥ 벌에 쏘이면 암모니아수 약을 바른다. ⑦ 묵은 김치의 신맛을 제빵 소다로 줄인다.
감점: 단어만 씀 · 중화가 아닌 사례(하수구 세정제, 철 제련, 연소).
⑥ 사례에서 산성·염기성 물질 구분
제산제 — 산성: 위산(염산), 염기성: 제산제(수산화 마그네슘 등). 생선 — 산성: 레몬즙(시트르산), 염기성: 비린내 물질. 벌 — 산성: 벌침 독, 염기성: 암모니아수. 변기 — 산성: 구연산·산성 세제, 염기성: 변기 때. 토양 — 산성: 산성 물질, 염기성: 석회 가루. 배기가스 — 산성: 황산화물, 염기성: 산화 칼슘.
감점: 한쪽만 씀 · 방향 뒤바뀜(생선·벌·변기에서 자주). 항상 짝으로.
⑦ 중화 반응을 이용하는 까닭
문장 틀 = 원인 → 반대 성질 → 중화 → 효과. 산성(염기성) 물질이 문제를 일으키므로, 반대 성질의 물질을 넣어 중화 반응으로 그 성질을 없애거나 약하게 하기 위해서이다. 예: 위산이 과다하면 속이 쓰리고 식도가 손상되므로 염기성 제산제로 위산을 중화해 통증을 완화한다.
감점: 상황만 쓰고 왜 중화가 해결인지 없음 · "중화하기 위해서"만 되풀이.
⑧ 지시약의 특징과 액성 구분
지시약은 액성에 따라 색이 변하는 물질이다. 페놀프탈레인은 산성·중성 무색, 염기성 붉은색 → 염산에 넣고 NaOH를 가하면 중화점까지 무색이다가 염기성이 되면 붉은색. BTB는 산성 노란색·중성 초록색·염기성 파란색 → 초록색이 되는 지점이 중화점. 리트머스: 산성 푸른→붉은, 염기성 붉은→푸른.
감점: 지시약 이름 없이 색만 · 페놀프탈레인 중성을 붉은색이라 씀 · BTB와 페놀프탈레인 색을 섞음. 수업은 BTB, 교과서는 페놀프탈레인 → 이름을 밝힌다.
⑨ 중화 반응의 반응식
화학 반응식 HCl + NaOH → NaCl + H₂O (산 + 염기 → 염 + 물). 이온으로: H⁺ + Cl⁻ + Na⁺ + OH⁻ → H₂O + Na⁺ + Cl⁻. 알짜 이온 반응식 H⁺ + OH⁻ → H₂O (1:1). 수산화 칼륨이면 HCl + KOH → KCl + H₂O.
감점: 전하(⁺, ⁻) 누락 · 염(NaCl) 누락 · H2O처럼 첨자를 크게 · 화살표 대신 등호. 심화: 2HCl + Ca(OH)₂ → CaCl₂ + 2H₂O.
손글씨 기호: H⁺ / OH⁻ / H₂O(2는 작게 아래) / NaCl / Ca(OH)₂ / 화살표 →

☐② 액성: 남은 이온(큰 쪽 − 작은 쪽)으로 판단
☐③ 발열 반응, 중화열

시험장 요령

  • 문제를 읽으면 먼저 어느 체크리스트 항목인지 번호를 마음속으로 붙인다. 그 항목의 키워드를 반드시 넣는다.
  • 모든 답은 결론 + 근거. "~이다. 왜냐하면 ~이기 때문이다." 형태로.
  • 표·그래프 문제는 숫자를 답에 인용한다(예: "온도가 24.0 ℃로 가장 높은 20 mL").
  • 부피를 물으면 넣은 부피와 전체 부피 둘 다, 단위 mL까지.
  • 지시약은 이름을 먼저 쓰고 색을 쓴다.
  • 반응식은 전하(⁺ ⁻)와 아래 첨자(₂)를 또렷하게. 화살표는 →.
  • 흑색 펜·샤프만. 평가지 밖에 쓰지 않는다. 알아볼 수 있게 또박또박.
