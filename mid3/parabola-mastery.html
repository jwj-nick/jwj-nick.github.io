🎢 이차함수 그래프 이동

"y = (x − 3)² 인데 왜 오른쪽으로 3이에요?" 괄호 안은 −3인데 그래프는 +3 쪽으로 가는 것, 이 부호가 이 단원에서 가장 많이 헷갈리는 자리예요. 외우지 않을 거예요. 슬라이더로 포물선을 직접 옮겨 보고, 표에서 왜 그런지 눈으로 확인한 다음, 일반형을 꼭짓점이 보이는 꼴로 고치는 단계까지 한 번에 가요.

① 꼭짓점·축 읽기② 평행이동한 식③ 그래프 → 식④ 완전제곱식 → 꼭짓점⑤ 최댓값·최솟값

1y = ax² — a를 움직여 봐요 (공식 없이)

중2에서 직선 y = ax + b의 기울기 a를 움직여 봤죠? 이번엔 y = ax²의 a예요. 슬라이더를 끝까지 왼쪽·오른쪽으로 움직이면서 포물선이 벌어지고, 좁아지고, 뒤집히는 것을 봐요. 점선은 비교용 y = x²이에요.

a1
y = x²

정리하면 — a의 부호가 볼록 방향(a > 0 아래로 볼록 ∪, a < 0 위로 볼록 ∩), |a|의 크기가 폭(클수록 좁아요)을 정해요. 꼭짓점은 언제나 원점 (0, 0), 축은 y축이에요. 이 모양은 그래프를 옮겨도 절대 안 변해요. 다음 단계에서는 이 포물선을 통째로 들어서 옮겨요.

함께 생각하기 ①

y = ax² 의 그래프가 점 (2, −8) 을 지나요. a는 얼마일까요?

2평행이동 — 꼭짓점이 그대로 따라가요

이제 y = a(x − p)² + q예요. a는 모양, p와 q는 자리를 정해요. p와 q를 움직이면 회색 점선(y = ax²)이 어디로 가는지, 그리고 꼭짓점이 딱 (p, q)에 오는지 확인해요.

a
p3
q1

p를 오른쪽으로 밀면 그래프도 오른쪽으로, q를 올리면 그래프도 위로 가요. 그런데 식을 보면 p = 3일 때 (x − 3)², 부호가 반대예요. q는 그대로 +1인데 p만 반대인 이유, 다음 단계에서 표로 확인해요.

함께 생각하기 ②

y = 2(x + 5)² − 1 의 그래프의 꼭짓점의 x좌표는 얼마일까요?

3왜 x − p 인데 오른쪽? — 표로 납득하기, 그리고 공식은 읽는 것

y = x²과 y = (x − p)²에 같은 x를 넣어서 나란히 적어 봐요. 위 슬라이더의 p가 그대로 쓰여요(p를 바꾸면 표도 바뀌어요). 0이 어느 x에서 나오는지만 보면 돼요.

p3
⚠ 부호 함정 — 괄호 안이 x − 3이면 "3을 넣어야 0"이니 꼭짓점은 x = 3, 즉 오른쪽으로 3. 괄호 안이 x + 4면 "−4를 넣어야 0"이니 꼭짓점은 x = −4, 즉 왼쪽으로 4. 괄호 안 부호를 뒤집은 것이 이동 방향이에요. 반대로 뒤의 상수 q는 그대로 위아래 이동이에요(+1이면 위로 1).
🎢불변 앵커 — "괄호 안을 0으로 만드는 x"가 꼭짓점의 x좌표예요. 이동 방향을 외우지 말고, 언제나 괄호 안을 0으로 만드는 x를 찾아요. 그 x와 뒤의 상수 q가 꼭짓점 (p, q), 축은 그 점을 지나는 세로선 x = p예요.

이제 공식을 "읽어" 봐요. 전부 위 실험의 요약이에요.

y = ax²꼭짓점 (0, 0) · 축 x = 0 (y축)
y = ax² + q위아래로 q · 꼭짓점 (0, q) · 축 x = 0
y = a(x − p)²좌우로 p · 꼭짓점 (p, 0) · 축 x = p
y = a(x − p)² + q꼭짓점 (p, q) · 축 x = p · 모양은 a가 정해요

함께 생각하기 ③

y = −3x² 의 그래프를 x축 방향으로 −2만큼, y축 방향으로 4만큼 평행이동한 그래프의 식이 y = −3(x − m)² + n 일 때, m은 얼마일까요?

4핵심 도구 — 일반형을 꼭짓점이 보이는 꼴로

시험에는 y = 2x² − 12x + 19처럼 일반형으로 나와요. 이 꼴에서는 꼭짓점이 안 보여요. 그래서 y = a(x − p)² + q 꼴로 고쳐요. 방법은 인수분해 특강에서 본 완전제곱식 만들기예요 — (x의 계수 ÷ 2)²을 더하고 바로 빼요. ▶ 다음 단계를 한 번씩 눌러 가며 봐요.

    ⚠ a가 1이 아닐 때 — 먼저 x²과 x 항만 a로 묶고, 괄호 안에서 더하고 뺀 수가 밖으로 나올 때 a가 곱해진다는 것을 잊지 말아요. y절편은 고치기 전 일반형의 상수항이 그대로예요(x = 0을 넣으면 나머지가 다 사라지니까요).

    완전제곱식 만들기가 가물가물하면 — 🧩 인수분해 특강 ④ 완전제곱식에서 빈칸 채우기를 먼저 해요.

    5유형별 완전정복

    이제 진짜 문제로 가요. 5가지 유형만 알면 05단원 그래프 문제는 다 풀려요. 막히면 💡 힌트를 먼저 눌러 보고, 그래도 어려우면 확인을 눌러 풀이를 봐요. "다른 문제로"를 누르면 숫자가 바뀌어요.

    ①
    꼭짓점·축 읽기
    식 → 그래프 · 괄호 안을 0으로 만드는 x
    핵심 y = a(x − p)² + q의 꼭짓점은 (p, q), 축은 x = p. 괄호 안을 0으로 만드는 x가 p예요. y축과 만나는 점은 x = 0을 넣어요.
    ②
    평행이동한 식 쓰기
    x축 방향 p → x 대신 (x − p) · y축 방향 q → 끝에 + q
    핵심 꼭짓점만 따라가면 돼요. (0, 0)이 (p, q)로 가면 y = a(x − p)² + q. 괄호 안 부호는 반대, 뒤의 상수는 그대로예요. 이미 옮겨진 식은 꼭짓점을 먼저 찾고 거기서 더 옮겨요.
    ③
    그래프 보고 식 고르기
    꼭짓점 먼저, a는 다른 한 점으로
    핵심 꼭짓점 (p, q)를 읽어 y = a(x − p)² + q로 놓고, 그래프가 지나는 다른 한 점을 넣어 a를 정해요. 볼록 방향으로 a의 부호를 먼저 확인하면 실수가 줄어요.
    ④
    완전제곱식으로 고쳐 꼭짓점 구하기
    일반형 → a로 묶기 → (계수÷2)² 더하고 빼기
    핵심 y = ax² + bx + c는 꼭짓점이 안 보여요. x²·x 항을 a로 묶고, (x의 계수 ÷ 2)²을 더하고 빼서 a(x − p)² + q 꼴로 고쳐요. y절편은 상수항 c 그대로예요.
    ⑤
    최댓값·최솟값
    꼭짓점의 y좌표가 답 · a의 부호로 최대/최소 결정
    핵심 a > 0이면 아래로 볼록 → 꼭짓점이 가장 낮은 점 → 최솟값 q(최댓값은 없어요). a < 0이면 위로 볼록 → 최댓값 q(최솟값은 없어요). 값을 갖는 x는 p예요.
    6실전 총정리 — 유형 섞어서

    이번엔 어떤 유형인지 안 알려드려요. "괄호 안을 0으로 만드는 x는?"을 먼저 떠올려 풀어봐요. 5문제를 첫 시도에 모두 맞히면 완주 도장이 찍혀요. 틀리면 어느 유형인지 알려드릴게요.

    y = a(x − p)² + q — 꼭짓점 (p, q), 축 x = px축 방향 p → x 대신 (x − p) · y축 방향 q → 끝에 + q
