중3단원 4

이차방정식(quadratic equations)

x²이 들어간 방정식은 답이 둘일 수 있어요. 인수분해로, 제곱근으로, 그리고 근의 공식으로 — 세 가지 열쇠를 차례로 손에 넣어요.

1이어서

인수분해에 "= 0"을 붙이면 방정식

지난 단원에서 x² − 5x + 6 = (x − 2)(x − 3) 으로 묶는 법을 배웠어요. 이제 x² − 5x + 6 = 0 처럼 (x에 대한 이차식) = 0 꼴을 이차방정식이라 하고, 이 식을 참이 되게 하는 x를 해 또는 근이라고 해요. 일차방정식과 달리 근이 둘일 수 있어요.

x² − 5x + 6 에 x = 2 를 넣으면 값은?
2핵심

AB = 0 이면 A = 0 또는 B = 0

두 수를 곱해서 0이 되려면 적어도 하나는 0이어야 해요. 그래서 (x − 2)(x − 3) = 0 이면 x − 2 = 0 또는 x − 3 = 0, 즉 x = 2 또는 x = 3. 첫 번째 열쇠는 이거예요 —

① 모든 항을 왼쪽으로 옮겨 = 0 꼴로 만들어요.

② 왼쪽을 인수분해해요.

③ 각 인수를 0으로 놓고 x를 구해요.

x² − 7x + 12 = 0 의 두 근 중 작은 근은?
3★ 직접 움직여 봐요

근을 정하면 방정식이 나와요

근이 p, q인 이차방정식은 (x − p)(x − q) = 0. 전개하면 가운데 계수는 −(p + q), 끝 항은 pq — 인수분해로 풀 때 "곱과 합으로 두 수 찾기"가 바로 이 거꾸로예요. p = q 로 맞추면 근이 하나(중근)예요.

4두 번째 열쇠

제곱근으로 풀기 — x² = k 꼴

x² = 5 는 인수분해가 안 되지만, "제곱해서 5가 되는 수"니까 x = ±√5. 괄호가 있어도 같아요: (x − 1)² = 3 이면 x − 1 = ±√3, 그래서 x = 1 ± √3. 단원 1의 제곱근이 여기서 쓰여요. (x − 2)² = 0 이면 x = 2 하나 — 중근이에요.

(x + 2)² = 7 의 해가 x = −2 ± √k 일 때 k는?
5연결

완전제곱식으로 만들면 어떤 식도 x² = k 꼴

x² + 6x + 2 = 0 은 인수분해도 안 되고 x² = k 꼴도 아니에요. 그러면 만들어요. 상수를 넘기고(x² + 6x = −2), x 계수 6의 절반의 제곱 9를 양변에 더하면 x² + 6x + 9 = 7, 즉 (x + 3)² = 7. 이제 두 번째 열쇠로 x = −3 ± √7.

x² + 4x + 1 = 0 을 (x + 2)² = k 로 고치면 k는?
6세 번째 열쇠

근의 공식 — 완전제곱을 한 번에

위 과정을 ax² + bx + c = 0 에 대해 한 번만 해 두면 매번 안 해도 돼요. 그 결과가 근의 공식이에요.

x = −b ± √(b² − 4ac)2a

예: x² + 3x + 1 = 0 → a = 1, b = 3, c = 1 → x = (−3 ± √(9 − 4)) / 2 = (−3 ± √5) / 2. 근호 안 b² − 4ac 부터 계산하는 게 요령이에요.

2x² + 5x + 1 = 0 의 해가 x = (−5 ± √k) / 4 일 때 k는?
7근의 개수

근호 안의 부호가 개수를 정해요

근의 공식에서 근호 안 b² − 4ac 가 양수면 ± 때문에 근이 2개, 0이면 ±0 이라 1개(중근), 음수면 제곱근이 없어 근이 0개예요. 풀기 전에 이것만 계산해도 답의 모양을 알 수 있어요.

x² + 2x + 5 = 0 의 근의 개수는? 개
8활용

문장 → 방정식 → 근 → 검토

"연속한 두 자연수의 곱이 56"이면 작은 수를 x로 놓고 x(x + 1) = 56 → x² + x − 56 = 0 → (x + 8)(x − 7) = 0 → x = −8 또는 7. 그런데 자연수여야 하니 x = 7. 마지막의 검토(조건에 맞는 근만 고르기)가 활용 문제의 핵심이에요.

9내 말로

이제 직접 설명할 차례예요

정답 맞히기가 아니라, 이해한 걸 자기 말로 꺼내보는 거예요.

AB = 0 이면 A = 0 또는 이에요. 그래서 이차방정식은 먼저 꼴로 만든 뒤 인수분해해요.

AB = 0 이면 A = 0 또는 B = 0. 먼저 = 0 꼴로 만들어요.

"곱이 0"일 때만 "하나가 0"이라고 말할 수 있어요. 곱이 4라면 (1, 4), (2, 2), (−1, −4)… 경우가 너무 많아요. 그래서 4를 왼쪽으로 옮겨 (x−1)(x+2) − 4 = 0, 전개해서 x² + x − 6 = 0 → (x+3)(x−2) = 0 으로 다시 묶어야 해요.

자기 말로 설명하면 돼요. 똑같지 않아도 괜찮아요.
