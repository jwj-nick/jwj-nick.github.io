중3단원 3심화 탐구

공식은 외우는 게 아니라 보이는 것

(x + a)(x + b)도, a² − b²도 넓이 그림 한 장이면 왜 그런지 보여요. 그리고 공식은 뒤집어 쓸 때 진짜 힘이 나요.

이 페이지엔 채점 문제가 거의 없어요. 슬라이더를 움직이며 느껴 보세요. 맨 끝에 도전 문제 하나만 있어요.

1큰 그림

(x + a)(x + b) 를 직사각형으로

가로 x + a, 세로 x + b 인 직사각형의 넓이가 곧 (x + a)(x + b) 예요. 안을 네 조각으로 나누면 x², bx, ax, ab — 그래서 가운데 항이 (a + b)x, 끝 항이 ab 예요.

넓이 실험실 · a와 b를 바꿔 볼까요?

a = b 로 맞추면 (x + a)² — 직사각형 두 개가 똑같아져서 2ax 가 돼요.

2한 걸음 더

a² − b² 은 왜 (a + b)(a − b) 일까

한 변이 a인 정사각형에서 한 변이 b인 정사각형을 모서리에서 잘라내면 남는 넓이가 a² − b² 예요. 남은 ㄱ자 모양을 두 조각으로 잘라 옆으로 붙이면 가로 a + b, 세로 a − b 인 직사각형이 돼요. 넓이가 같으니 a² − b² = (a + b)(a − b).

잘라 붙이기 실험실 · b를 바꿔 볼까요?

왼쪽 ㄱ자(a² − b²)와 오른쪽 직사각형((a + b)(a − b))의 넓이가 늘 같아요.

3뒤집어 쓰기

x² + y² 을 x, y 없이 구하기

(x + y)² = x² + 2xy + y² — 곱셈공식 ①
양변에서 2xy 를 빼요: (x + y)² − 2xy = x² + y²
그래서 x + y = 5, xy = 6 이면 x² + y² = 5² − 2 × 6 = 13
x, y 가 각각 얼마인지 몰라도 돼요. 합과 곱만 알면 제곱의 합이 나와요. (같은 식으로 (x − y)² = (x + y)² − 4xy)
4도전

합차 공식을 거꾸로

x² − y² = 24 이고 x + y = 6 일 때, x의 값은?

💡 x² − y² = (x + y)(x − y) 로 인수분해해요.

💡 (x + y)(x − y) = 24 에 x + y = 6 을 넣으면 6(x − y) = 24 → x − y = 4.

💡 x + y = 6, x − y = 4 를 더하면 2x = 10.
