√는 어디에 사는 수일까요

√a는 넓이가 a인 정사각형의 한 변이에요. 그리고 자만 있으면 √2, √3, √5… 를 진짜로 그릴 수 있어요.

이 페이지엔 채점 문제가 거의 없어요. 슬라이더를 움직이며 느껴 보세요. 맨 끝에 도전 문제 하나만 있어요.

1큰 그림

넓이 a → 한 변 √a

넓이가 9인 정사각형의 한 변은 3이에요(3² = 9). 그러면 넓이가 10인 정사각형의 한 변은? 정수로는 없지만 분명히 어떤 길이예요 — 그 길이가 바로 √10이에요. √는 "제곱하면 그 수가 되는 길이"라고 생각하면 편해요.

정사각형 실험실 · 넓이를 바꿔 볼까요?

넓이가 4배가 되면 한 변은 2배가 돼요(√4 = 2). 넓이가 2배가 되면 한 변은 √2배 ≈ 1.414배 — 2배가 아니에요.

2한 걸음 더

√2, √3, √5 를 자로 그리기 — 테오도루스의 나선

중2에서 배운 피타고라스 정리를 써요. 두 변이 1, 1인 직각삼각형의 빗변은 √(1² + 1²) = √2. 그 빗변을 한 변으로, 길이 1인 변을 하나 더 세우면 새 빗변은 √(2 + 1) = √3. 계속하면 √4, √5, √6, … 이 차례로 나와요. 무리수도 자와 컴퍼스로 정확히 그릴 수 있는 길이예요.

나선 실험실 · 삼각형을 하나씩 붙여 볼까요?

n번째 빗변의 길이가 √(n+1)이에요. 초록으로 표시된 빗변(√4 = 2, √9 = 3, √16 = 4)만 정수예요.

3왜 무리수일까

√10 을 소수로 쫓아가 보기

3² = 9 < 10 < 16 = 4² → 3 < √10 < 4
3.1² = 9.61, 3.2² = 10.24 → 3.1 < √10 < 3.2
3.16² = 9.9856, 3.17² = 10.0489 → 3.16 < √10 < 3.17
√10 = 3.16227766… — 아무리 쫓아가도 끝나지도, 반복되지도 않아요. 그래서 무리수예요.

계산기가 보여 주는 3.1622…는 근삿값이에요. 정확한 값은 √10 이라는 기호로만 쓸 수 있어요 — 그래서 기호를 남겨 두는 거예요.

4도전

두 조건을 한꺼번에

√(2x) 와 √(72/x) 가 모두 자연수가 되게 하는 자연수 x 중 가장 작은 값은?

💡 근호 안이 제곱수여야 해요. 2x 가 제곱수가 되려면 x 는 2 × (제곱수) 꼴 — 2, 8, 18, 32, …

💡 72 = 2³ × 3². 72/x 가 제곱수가 되는 x 를 작은 것부터 찾으면 x = 2 → 72/2 = 36 = 6² ✓

💡 x = 2 를 첫 번째 조건에 넣으면 2x = 4 = 2² ✓. 두 조건을 동시에 만족하는 가장 작은 x예요.
