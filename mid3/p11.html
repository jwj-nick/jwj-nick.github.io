중3단원 11연습

유형별 연습 — 산포도

대푯값 복습부터 편차·분산·표준편차, 자료 비교와 변환까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

답은 수 하나로 써요. 소수는 2.8 처럼, 분수도 14/5 처럼 써도 돼요. 근호가 남으면 "근호 안의 수"만 써요.

푼 문제: 0 / 28

1대푯값 복습 — 평균·중앙값
기본기본

평균 = 합 ÷ 개수. 중앙값은 크기순으로 놓고 가운데(짝수 개면 가운데 둘의 평균).

(1)자료 3, 7, 8, 8, 9 의 평균은?

(2)자료 5, 1, 9, 3, 7 의 중앙값은?

(3)자료 2, 4, 4, 6, 8, 10 의 중앙값은?

왜?6개라 가운데 두 수 4와 6의 평균 5. (최빈값은 4)
심화도전

(4)자료 4, x, 7, 9, 10 의 평균이 8 일 때 x는?

왜?합 = 8 × 5 = 40 → x = 40 − (4 + 7 + 9 + 10) = 10.
2편차 — 합은 0
핵심보통

편차 = 변량 − 평균. 편차의 합은 항상 0.

(1)평균이 6인 자료에서 변량 9의 편차는?

(2)편차가 −2, 1, 3, x 일 때 x 는?

(3)평균이 10인 자료의 편차가 −3, 2, x, 4, −1 일 때, 편차가 x 인 변량은?

왜?합 0 → x = −2 → 변량 = 평균 + 편차 = 10 + (−2) = 8.
심화도전

(4)5개 변량의 편차가 −4, 3, x, 2x, 4 일 때 x는?

왜?편차의 합 = 0 → −4 + 3 + x + 2x + 4 = 3x + 3 = 0 → x = −1.
3분산 구하기
핵심보통

평균 → 편차 → 제곱 → 개수로 나눠 평균.

(1)자료 1, 2, 3, 4, 5 의 분산은?

(2)자료 2, 4, 6, 8, 10 의 분산은?

(3)자료 4, 7, 7, 8, 9 의 분산은?

왜?평균 7 → 편차 −3, 0, 0, 1, 2 → 제곱 9, 0, 0, 1, 4 → 합 14 ÷ 5 = 2.8.
심화도전

(4)평균이 5 인 자료 3, x, 5, 8, 6 의 분산은?

왜?x = 25 − 22 = 3 → 편차 −2, −2, 0, 3, 1 → 제곱 4, 4, 0, 9, 1 → 합 18 ÷ 5 = 3.6.
4표준편차 구하기
핵심보통

표준편차 = √분산. 근호가 안 벗겨지면 그대로 둬요.

(1)분산이 16인 자료의 표준편차는?

(2)자료 4, 4, 8, 8 의 표준편차는?

(3)자료 1, 3, 7, 9 의 표준편차는 √□ — 근호 안의 수는?

왜?평균 5 → 편차 −4, −2, 2, 4 → 제곱 합 40 ÷ 4 = 분산 10 → 표준편차 √10.
심화도전

(4)자료 1, 5, 5, 9 의 표준편차가 a√2 일 때 a는?

왜?평균 5 → 편차 −4, 0, 0, 4 → 분산 32 ÷ 4 = 8 → 표준편차 √8 = 2√2.
5편차 표에서 분산
활용보통

빈칸은 합 = 0으로 먼저 채우고, 제곱 → 개수로 나눠요.

(1)편차가 −2, −1, 0, 1, 2 인 자료의 분산은?

(2)편차가 −3, x, 1, 2, 0 인 자료의 분산은?

(3)편차가 x, −1, 3, −2 인 자료(변량 4개)의 분산은?

왜?x = 0 → 제곱 0, 1, 9, 4 → 합 14 ÷ 4 = 3.5.
심화도전

(4)편차가 −2, x, 3, 1, x 인 자료의 분산은?

왜?합 0 → 2 + 2x = 0 → x = −1 → 제곱 4, 1, 9, 1, 1 → 합 16 ÷ 5 = 3.2.
6자료 비교 — 표준편차의 뜻
개념보통

표준편차가 작을수록 고르다. 표준편차 0 = 모든 변량이 평균과 같다.

(1)평균이 같은 두 반 — A반 표준편차 5, B반 표준편차 8. 성적이 더 고른 반은?

(2)표준편차가 3인 자료의 분산은?

(3)표준편차가 0인 자료에 대한 옳은 설명은?

왜?표준편차 0 → 분산 0 → 편차 제곱이 전부 0 → 편차가 전부 0 → 모든 변량 = 평균.
심화도전

(4)평균이 같은 두 반 A, B 의 분산이 각각 9, 4 일 때, 두 반의 표준편차의 차는?

왜?표준편차는 √9 = 3, √4 = 2 → 차 1. (B반이 더 고르게 모여 있어요)
7자료를 변환하면
활용보통

모든 변량에 같은 수를 더하면 분산 그대로. 모든 변량을 k배 하면 분산은 k²배, 표준편차는 k배.

(1)평균 5, 분산 4인 자료의 모든 변량에 2를 더하면 분산은?

(2)평균 5, 분산 4인 자료의 모든 변량을 2배 하면 분산은?

(3)평균 5, 분산 4인 자료의 모든 변량을 3배 하면 표준편차는?

왜?표준편차 2 → 3배 하면 편차도 3배 → 표준편차 6. (분산은 9배인 36)
심화도전

(4)평균 6, 표준편차 2 인 자료의 각 변량을 3배 한 뒤 1 을 뺀 새 자료의 평균과 분산의 합은?

왜?평균 6 × 3 − 1 = 17, 표준편차 2 × 3 = 6 → 분산 36 → 17 + 36 = 53.
