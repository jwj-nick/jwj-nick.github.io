중3단원 9연습

유형별 연습 — 원과 직선

현의 수직이등분선부터 접선·내접원·외접사각형까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

답은 숫자 하나로 써요. 그림이 없으면 머릿속에 그리고 반지름을 먼저 그어요.

푼 문제: 0 / 21

1현의 수직이등분 — 현의 길이·거리
기본기본

중심에서 현에 내린 수선은 현을 이등분해요. 빗변 = 반지름, 두 변 = 중심 거리 · 현의 절반.

(1)반지름 5인 원에서 중심으로부터 거리가 3인 현의 길이는?

(2)반지름 10인 원에서 중심으로부터 거리가 6인 현의 길이는?

(3)반지름 13인 원에서 길이가 24인 현은 중심에서 얼마나 떨어져 있나요?

왜?현의 절반 12, 반지름 13 → 거리 = √(13² − 12²) = 5.
2현의 수직이등분 — 반지름 구하기
핵심보통

반지름² = (중심 거리)² + (현의 절반)². 호의 일부만 주어지면 중심 거리 = r − (활꼴의 높이).

(1)길이 8인 현이 중심에서 3만큼 떨어져 있을 때 원의 반지름은?

(2)길이 12인 현이 중심에서 8만큼 떨어져 있을 때 원의 반지름은?

(3)원의 일부에서 현 AB = 16 이고, AB의 중점에서 호까지의 거리가 4 일 때 원의 반지름은?

왜?반지름 r, 중심 거리 r − 4: r² = 8² + (r − 4)² → 8r = 80 → r = 10.
3현의 길이와 중심까지의 거리
개념보통

같은 거리 ⇔ 같은 길이. 중심에 가까울수록 긴 현이에요.

(1)중심 O에서 두 현 AB, CD 까지의 거리가 같고 AB = 10 일 때 CD 는?

(2)반지름 5인 원에서 중심으로부터 같은 거리에 있는 두 현 중 하나의 길이가 6 일 때 다른 현의 길이는?

(3)반지름 5인 원에서 중심으로부터 거리가 3, 4인 두 현 중 더 긴 현의 길이는?

왜?가까운 쪽(거리 3)이 더 길어요: 절반 = √(25 − 9) = 4 → 8. (거리 4인 현은 6)
4접선과 반지름은 수직
핵심보통

직각은 접점 T에. 빗변은 OP: OP² = r² + PT².

(1)OP = 10, 반지름 6 일 때 접선 PT 의 길이는?

(2)접선 PT = 12, 반지름 5 일 때 OP 의 길이는?

(3)OP = 17, 접선 PT = 15 일 때 원의 반지름은?

왜?r = √(17² − 15²) = √64 = 8.
5두 접선의 길이
핵심보통

원 밖 한 점에서 그은 두 접선의 길이는 같아요 (PA = PB). 삼각형 PAB는 이등변삼각형이에요.

(1)점 P에서 원에 그은 두 접선의 접점이 A, B 이고 PA = 9 일 때 PB 는?

(2)PA = 2x + 1, PB = 9 가 두 접선의 길이일 때 x는?

(3)두 접선이 이루는 각 ∠APB = 60°, PA = 6 일 때 AB 의 길이는?

왜?PA = PB 인 이등변삼각형의 꼭지각이 60° → 정삼각형 → AB = PA = 6.
6삼각형의 내접원
활용보통

각 꼭짓점에서 나온 두 접선의 길이가 같아요 (AD = AF, BD = BE, CE = CF). 직각삼각형의 내접원 반지름 r = (a + b − c)/2.

(1)삼각형 ABC의 내접원이 AB, BC와 만나는 점을 각각 F, D라 할 때, AB = 7, AF = 3 이면 BD 는?

(2)AB = 8, BC = 9, CA = 7 인 삼각형의 내접원이 BC와 만나는 점을 D라 할 때 BD 는?

(3)세 변이 6, 8, 10 인 직각삼각형의 내접원의 반지름은?

왜?r = (6 + 8 − 10) ÷ 2 = 2. (직각 꼭짓점 쪽 접선 길이가 r 이라서요)
7원에 외접하는 사각형
활용보통

마주 보는 두 변의 합이 같아요: AB + CD = AD + BC.

(1)원에 외접하는 사각형 ABCD에서 AB = 5, CD = 7, AD = 4 일 때 BC 는?

(2)원에 외접하는 사각형 ABCD에서 AB = 6, BC = 9, CD = 8 일 때 AD 는?

(3)원에 외접하는 사각형의 둘레가 30 일 때 AB + CD 는?

왜?AB + CD = AD + BC 이고 둘을 더하면 둘레 30 → 각각 15.
