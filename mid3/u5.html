중3단원 5

이차함수와 그래프(quadratic functions)

직선만 그리다가 처음으로 굽은 그래프를 만나요. 포물선 — 던진 공이 그리는 바로 그 곡선이에요.

1이어서

y = x² 의 표를 찍어 보면

중2에서 y = 2x + 1 같은 일차함수는 직선이었죠. 이번엔 y = x². x에 −2, −1, 0, 1, 2 를 넣으면 y는 4, 1, 0, 1, 4. 점을 찍고 부드럽게 이으면 U자 곡선이 나와요. 이 곡선을 포물선이라고 해요.

y = x² 에서 x = −3 일 때 y는?
2핵심

y = ax² — a가 모양을 정해요

y = ax² + bx + c (a ≠ 0) 꼴을 이차함수라 해요. 가장 단순한 y = ax² 의 그래프는 —

✔ 꼭짓점은 원점 (0, 0), 축은 y축 — 축을 기준으로 좌우 대칭이에요.

✔ a > 0 이면 아래로 볼록(U), a < 0 이면 위로 볼록(∩).

✔ |a| 가 클수록 폭이 좁아요(y가 빨리 커지니까요). y = ax² 과 y = −ax² 은 x축에 대해 대칭이에요.

y = −2x² 의 그래프가 점 (1, k) 를 지날 때 k는?
3★ 직접 움직여 봐요

a를 바꾸면 포물선이 어떻게 변할까요

a를 0 쪽으로 보내면 폭이 넓어지고(납작), 크게 하면 좁아져요(뾰족). 부호를 바꾸면 x축에 대칭으로 뒤집혀요. 회색은 비교용 y = x².

4평행이동 ①

y = ax² + q — 위아래로 옮기기

y = x² + 3 은 y = x² 의 모든 y값에 3을 더한 것 — 그래프 전체가 위로 3 올라가요. 꼭짓점은 (0, 3). q가 음수면 아래로 내려가요. 모양은 그대로, 자리만 바뀌어요.

y = 2x² − 5 의 꼭짓점의 y좌표는?
5평행이동 ②

y = a(x − p)² — 좌우로 옮기기, 부호 주의

y = (x − 3)² 은 x = 3 을 넣어야 0이 돼요. 즉 꼭짓점이 (3, 0) — 그래프가 오른쪽으로 3 옮겨진 거예요. 괄호 안이 −3 인데 오른쪽, 이게 헷갈리는 자리예요. "괄호 안을 0으로 만드는 x"가 꼭짓점의 x좌표라고 기억해요. y = (x + 4)² 은 x = −4 에서 0 → 왼쪽으로 4.

y = (x + 4)² 의 꼭짓점의 x좌표는?
6합치기

y = a(x − p)² + q — 꼭짓점 (p, q), 축 x = p

좌우로 p, 위아래로 q 옮기면 y = a(x − p)² + q. 꼭짓점은 (p, q), 축은 x = p, 볼록 방향과 폭은 a가 정해요. 예: y = −(x − 1)² + 2 → 꼭짓점 (1, 2), 위로 볼록. 이 꼴을 알면 그래프를 바로 그릴 수 있어요.

y = 3(x − 2)² + 1 의 축은 직선 x = ?
7거꾸로

그래프를 보고 식 세우기

꼭짓점이 (1, 2)면 일단 y = a(x − 1)² + 2. a는 그래프가 지나는 다른 한 점으로 정해요 — (0, 4) 를 지난다면 4 = a(0 − 1)² + 2 → a = 2. 꼭짓점 하나 + 점 하나면 포물선이 하나로 정해져요.

꼭짓점이 (0, −1) 이고 점 (1, 2) 를 지나는 이차함수 y = ax² − 1 의 a는?
8내 말로

이제 직접 설명할 차례예요

정답 맞히기가 아니라, 이해한 걸 자기 말로 꺼내보는 거예요.

y = (x − 3)² 의 그래프는 y = x² 을 으로 3만큼 옮긴 것이고, 꼭짓점은 (, 0) 이에요.

y = x² 을 오른쪽으로 3 옮긴 것, 꼭짓점 (3, 0).

y = x² 에서 가장 낮은 곳은 x = 0 일 때예요. y = (x − 3)² 에서 가장 낮은 곳은 괄호 안이 0이 되는 x = 3 일 때 — 그러니 "낮은 곳"이 0에서 3으로, 오른쪽으로 옮겨간 거예요. 괄호 안 부호는 "어디서 0이 되나"를 말해 줄 뿐이에요.

자기 말로 설명하면 돼요. 똑같지 않아도 괜찮아요.
