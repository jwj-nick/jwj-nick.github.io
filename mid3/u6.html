중3단원 6

이차함수의 활용(y = ax² + bx + c)

식이 y = ax² + bx + c 꼴로 주어지면 꼭짓점이 안 보여요. 완전제곱식으로 다시 쓰면 보이고 — 그러면 가장 큰 값·가장 작은 값도 알 수 있어요.

1이어서

y = x² + 4x + 1 의 꼭짓점은 어디?

단원 5에서는 y = a(x − p)² + q 꼴이라 꼭짓점 (p, q)가 바로 보였어요. 그런데 y = x² + 4x + 1 은? 단원 4의 완전제곱식 만들기를 쓰면 돼요: x² + 4x + 4 − 4 + 1 = (x + 2)² − 3. 꼭짓점 (−2, −3). 한편 x = 0 을 넣으면 y = 1 — 상수항 c는 y축과 만나는 점(y절편)이에요.

y = x² + 6x + 5 의 그래프의 y절편은?
2핵심

일반형 → 표준형, 세 단계

① x² 의 계수 a로 x², x 항만 묶어요: y = 2x² − 8x + 3 = 2(x² − 4x) + 3

② 괄호 안에 (x 계수 절반)²을 더하고 빼요: 2(x² − 4x + 4 − 4) + 3

③ 뺀 수는 괄호 밖으로(a를 곱해서!): 2(x − 2)² − 8 + 3 = 2(x − 2)² − 5 → 꼭짓점 (2, −5)

③에서 −4 를 밖으로 뺄 때 a = 2 를 곱해 −8이 되는 것, 여기가 가장 많이 틀리는 곳이에요.

y = x² − 4x + 1 = (x − 2)² + q 일 때 q는?
3★ 직접 움직여 봐요

b와 c를 바꾸면 꼭짓점이 어디로 갈까요

b를 바꾸면 꼭짓점이 좌우와 상하로 동시에 움직여요(x좌표 −b/2). c를 바꾸면 그래프 전체가 위아래로만. y축과 만나는 점(초록)은 늘 (0, c)예요.

4읽기

축, y절편, x절편

표준형으로 고치면 축은 x = −b/2a(꼭짓점의 x좌표)예요. y절편은 x = 0 을 넣은 c. x절편은 y = 0 을 넣은 것 — 즉 이차방정식 ax² + bx + c = 0 의 근이에요(단원 4!). 예: y = x² − 5x + 6 → x절편은 (x − 2)(x − 3) = 0 에서 2, 3.

y = x² − 6x + 8 의 그래프의 두 x절편의 합은?
5그리기

네 가지만 찍으면 그래프가 돼요

① 꼭짓점(표준형에서) ② y절편 (0, c) ③ y절편의 대칭점(축을 기준으로 반대편, 같은 높이) ④ x절편(있으면). 이 점들을 부드럽게 이으면 끝. 볼록 방향은 a의 부호로 확인해요.

6새로 배우는 것

최댓값과 최솟값 — 꼭짓점의 y좌표

포물선은 한쪽으로만 끝없이 뻗어요. 그래서 a > 0(아래로 볼록)이면 꼭짓점이 가장 낮은 점 → 최솟값 q, 최댓값은 없어요. a < 0(위로 볼록)이면 꼭짓점이 가장 높은 점 → 최댓값 q, 최솟값은 없어요. "값"은 y좌표, "그때 x"는 p — 둘을 구분해요. 예: y = −x² + 4x + 1 = −(x − 2)² + 5 → x = 2 일 때 최댓값 5.

y = −x² + 2x + 3 의 최댓값은?
7활용

"가장 클 때"는 꼭짓점을 찾으라는 말

둘레가 20인 직사각형의 가로를 x라 하면 세로는 10 − x, 넓이는 S = x(10 − x) = −x² + 10x = −(x − 5)² + 25. 그래서 x = 5 일 때 최대 넓이 25 — 정사각형일 때예요. 위로 던진 공의 높이 h = −5t² + 20t = −5(t − 2)² + 20 이면 2초 뒤 최고 높이 20 m. 문장에 "최대·최소"가 있으면 이차함수를 세우고 표준형으로 고치면 돼요.

둘레가 20인 직사각형의 넓이의 최댓값은?
8내 말로

이제 직접 설명할 차례예요

정답 맞히기가 아니라, 이해한 걸 자기 말로 꺼내보는 거예요.

이차함수가 최댓값을 가지려면 a의 부호가 여야 하고, 그 최댓값은 꼭짓점의 좌표예요.

a가 음수(위로 볼록)여야 하고, 최댓값은 꼭짓점의 y좌표예요.

y = x² + 2x 는 a = 1 > 0 이라 아래로 볼록 — 양쪽 팔이 위로 끝없이 올라가요. 아무리 큰 y를 말해도 더 큰 y가 있으니 최댓값이 없어요. 대신 가장 낮은 점(꼭짓점 (−1, −1))은 있어서 최솟값 −1이에요.

자기 말로 설명하면 돼요. 똑같지 않아도 괜찮아요.
