중3단원 3

다항식의 곱셈과 인수분해(expansion & factoring)

괄호를 펼치는 것과 다시 묶는 것 — 서로 반대 방향의 두 기술이에요. 넓이 그림 하나면 공식이 저절로 나와요.

1이어서

분배법칙 — 괄호를 펼치는 법

중2에서 a(b + c) = ab + ac 를 배웠어요. 괄호가 두 개면 앞 괄호의 항 하나하나를 뒤 괄호에 나눠 곱해요: (a + b)(c + d) = ac + ad + bc + bd. 이렇게 괄호를 펼쳐 정리하는 걸 전개라고 해요. 예: (x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6.

(x + 1)(x + 4) 를 전개하면 x의 계수는?
2핵심

곱셈공식 — 자주 나오는 전개는 외워 두면 빨라요

① (a + b)² = a² + 2ab + b²

② (a − b)² = a² − 2ab + b²

③ (a + b)(a − b) = a² − b² — 합과 차의 곱, 가운데 항이 사라져요

④ (x + a)(x + b) = x² + (a + b)x + ab — 가운데는 합, 끝은 곱

①에서 가장 많이 틀리는 곳이 2ab예요. (a + b)²은 a² + b²이 아니에요 — 아래 넓이 그림에서 그 이유를 봐요.

(x + 4)² = x² + ax + 16 일 때 a는?
3★ 직접 움직여 봐요

(x + a)² 을 넓이로 보면

한 변이 x + a인 정사각형 = x² 한 칸 + ax 두 칸 + a² 한 칸. 그래서 가운데 항이 2ax예요 — 직사각형이 두 개니까요.

4합과 차

(a + b)(a − b) = a² − b² — 암산 무기

전개하면 a² − ab + ab − b² 에서 가운데 두 항이 서로 지워져요. 이 공식은 수 계산에서 빛나요: 101 × 99 = (100 + 1)(100 − 1) = 10000 − 1 = 9999. 곱셈 없이 답이 나와요.

(x + 5)(x − 5) = x² − a 일 때 a는?
5거꾸로

인수분해 — 펼친 것을 다시 곱으로 묶기

전개의 반대 방향이에요. x² + 6x + 9 를 보고 (x + 3)² 으로 되돌리는 것. 방법은 순서대로 —

① 공통인수부터 묶어요: 2x² + 4x = 2x(x + 2)

② 완전제곱식인지: x² + 6x + 9 = (x + 3)² — 끝 항이 제곱수(9 = 3²)이고 가운데가 그 두 배(2 × 3 = 6)

③ 합차 꼴인지: x² − 25 = (x + 5)(x − 5)

x² + 10x + 25 = (x + a)² 일 때 a는?
6두 수 찾기

x² + (합)x + (곱) — 곱부터 찾아요

x² + 5x + 6 을 인수분해하려면 곱해서 6, 더해서 5인 두 수를 찾아요. 곱이 6인 짝은 (1, 6), (2, 3) — 그중 합이 5인 건 2와 3. 그래서 (x + 2)(x + 3). 요령: 곱이 되는 짝을 먼저 나열하고 그중 합을 골라요. 부호도 짝에 넣어요 — x² − x − 6 은 곱이 −6, 합이 −1 → (−3, 2).

x² + 7x + 12 = (x + a)(x + b) 일 때 작은 수 a는?
7활용

공식을 뒤집어 쓰기

(a + b)² = a² + 2ab + b² 을 옮기면 a² + b² = (a + b)² − 2ab. 그래서 x + y = 5, xy = 6 만 알아도 x² + y² = 25 − 12 = 13 이 나와요. x, y를 몰라도 돼요. 수 계산도 마찬가지: 51² = (50 + 1)² = 2500 + 100 + 1 = 2601.

x + y = 4, xy = 3 일 때 x² + y² 의 값은?
8내 말로

이제 직접 설명할 차례예요

정답 맞히기가 아니라, 이해한 걸 자기 말로 꺼내보는 거예요.

(a + b)² = a² + ab + b² 예요. 가운데 항이 생기는 이유는 넓이 그림에서 직사각형이 개이기 때문이에요.

(a + b)² = a² + 2ab + b² — 직사각형이 2개예요.

한 변이 a + b인 정사각형을 그려 보면, 큰 정사각형(a²)과 작은 정사각형(b²) 사이에 가로 a·세로 b인 직사각형이 위와 옆에 하나씩 있어요. 그 둘의 넓이 ab + ab = 2ab 를 빠뜨리면 정사각형에 구멍이 나요.

자기 말로 설명하면 돼요. 똑같지 않아도 괜찮아요.
