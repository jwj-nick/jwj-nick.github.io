근호를 포함한 식의 계산(operations with radicals)

√끼리 곱하고, 나누고, 더해요. 규칙은 딱 두 가지 — 곱셈은 근호 안에서, 덧셈은 근호 밖에서.

1이어서

√2 × √2 = 2 — 그럼 √2 × √3 은?

지난 단원에서 (√2)² = √2 × √2 = 2 를 배웠어요. 그러면 근호 안이 다른 √2 × √3 은 뭘까요? 근삿값으로 확인해 봐요 — 1.414 × 1.732 ≈ 2.449, 그리고 2.449² ≈ 6. 그러니까 √2 × √3 = √6 이에요. 근호 안끼리 곱하면 돼요.

√3 × √5 = √n 일 때 n은?
2핵심

곱셈·나눗셈은 근호 안에서 해요

a > 0, b > 0 일 때 √a × √b = √(ab), √a ÷ √b = √(a/b) 예요. 예를 들어 √2 × √8 = √16 = 4, √12 ÷ √3 = √4 = 2. 근호 안에서 곱하고 나눈 다음, 근호가 벗겨지는지 꼭 확인해요.

3★ 직접 움직여 봐요

√n 을 가장 간단한 꼴 a√b 로

근호 안에서 제곱수(4, 9, 16, 25, …)를 찾아 밖으로 꺼내요. 제곱수의 제곱근만 밖으로 나올 수 있어요 — √12 = √(4 × 3) = √4 × √3 = 2√3.

4드나들기

근호 밖으로, 근호 안으로

밖으로: √18 = √(9 × 2) = 3√2. 안으로: 2√5 = √4 × √5 = √20 — 계수는 제곱해서 들어가요. 2√5 = √10 이 아니에요.

√18 = a√2 일 때 a는?
5분모의 유리화

분모에 근호가 있으면 없애요

1/√3 은 값이 얼마쯤인지 가늠하기 어려워요 (1 ÷ 1.732…). 분모와 분자에 똑같이 √3 을 곱하면 — 1을 곱한 셈이라 값은 그대로 — √3/3 이 돼요. 이제 1.732 ÷ 3 ≈ 0.577, 쉽게 보이죠. 이걸 분모의 유리화라고 해요.

1/√7 = √7/n 일 때 n은?
6덧셈·뺄셈

근호 안이 같은 것끼리만 — 동류항처럼

2√3 + 5√3 = 7√3 — √3 이 2개에 5개를 더해 7개예요. 문자 x 처럼 다루면 돼요(2x + 5x = 7x). 그런데 √2 + √3 은 더 이상 줄일 수 없어요. √5 가 아니에요 — 1.414 + 1.732 = 3.146 인데 √5 ≈ 2.236 이니까요. 근호 안이 달라 보여도 먼저 정리하면 같아지기도 해요: √8 + √2 = 2√2 + √2 = 3√2.

3√5 + 2√5 = k√5 일 때 k는?
√8 + √2 = k√2 일 때 k는?
7섞인 계산

괄호는 분배법칙으로

√2(√6 − 1) = √2 × √6 − √2 × 1 = √12 − √2 = 2√3 − √2. 괄호 안 모든 항에 곱하고, 곱한 결과는 가장 간단한 꼴로 정리해요. 정리하고 나면 근호 안이 같은 것끼리 모아요.

√3(√3 + 2) = a + 2√3 일 때 a는?
8내 말로

이제 직접 설명할 차례예요

정답 맞히기가 아니라, 이해한 걸 자기 말로 꺼내보는 거예요.

√2 × √3 은 √6 이지만, √2 + √3 은 √5 가 . 곱셈은 근호 안에서, 덧셈은 끼리만.

√2 + √3 은 √5 가 아니에요. 덧셈은 근호 안이 같은 것끼리만 계수를 더해요.

근삿값으로 보면 바로 알아요 — √2 + √3 ≈ 1.41 + 1.73 = 3.14 인데, √5 ≈ 2.24 예요. 곱셈은 근호 안에서 해도 되지만(√2 × √3 = √6 ≈ 2.45 ✓), 덧셈은 안 돼요.

자기 말로 설명하면 돼요. 똑같지 않아도 괜찮아요.
