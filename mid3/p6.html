유형별 연습 — 이차함수의 활용

표준형 고치기부터 절편·최댓값·최솟값·활용까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

답은 숫자 하나로 써요. 문제에서 묻는 자리(q, 좌표 한 쪽, 값)만 답하면 돼요. 음수는 −(마이너스)를 붙여서요.

푼 문제: 0 / 28

1일반형 → 표준형
핵심기본

x 계수 절반의 제곱을 더하고 빼요. a로 묶었으면 뺀 수에 a를 곱해서 밖으로 내요.

(1)y = x² + 2x + 3 = (x + 1)² + q 일 때 q는?

(2)y = x² − 8x + 10 = (x − 4)² + q 일 때 q는?

(3)y = 2x² + 4x − 1 = 2(x + 1)² + q 일 때 q는?

왜?2(x² + 2x + 1 − 1) − 1 = 2(x + 1)² − 2 − 1 → q = −3.
심화도전

(4)y = −2x² + 8x − 5 = −2(x − p)² + q 일 때 p + q 는?

왜?−2(x² − 4x) − 5 = −2(x − 2)² + 8 − 5 = −2(x − 2)² + 3 → p + q = 2 + 3 = 5.
2꼭짓점과 축
핵심기본

표준형으로 고치면 꼭짓점 (p, q), 축 x = p. 축은 x = −b/2a 로도 바로 나와요.

(1)y = x² − 6x + 2 의 그래프의 축이 직선 x = m 일 때 m은?

(2)y = −x² + 4x 의 꼭짓점의 y좌표는?

(3)y = 3x² − 6x + 7 의 꼭짓점의 x좌표와 y좌표의 합은?

왜?3(x − 1)² + 4 → 꼭짓점 (1, 4) → 1 + 4 = 5.
심화도전

(4)y = x² + bx + 1 의 그래프의 꼭짓점의 x좌표가 −3 일 때, 꼭짓점의 y좌표는?

왜?축 x = −b/2 = −3 → b = 6 → y = (x + 3)² − 8 → y좌표 −8.
3y절편과 x절편
연결보통

y절편은 x = 0 (상수항), x절편은 y = 0 으로 놓은 이차방정식의 근이에요.

(1)y = x² + 3x − 4 의 그래프의 y절편은?

(2)y = x² − 5x + 6 의 그래프의 x절편 중 큰 것은?

(3)y = x² − 2x − 8 의 그래프가 x축과 만나는 두 점 사이의 거리는?

왜?(x − 4)(x + 2) = 0 → x절편 4, −2 → 거리 4 − (−2) = 6.
심화도전

(4)y = x² + ax − 6 의 그래프가 점 (1, 0) 을 지날 때, 다른 x절편은?

왜?1 + a − 6 = 0 → a = 5 → x² + 5x − 6 = (x + 6)(x − 1) → 다른 x절편 −6.
4최댓값·최솟값 (표준형)
핵심보통

a > 0 이면 최솟값 q, a < 0 이면 최댓값 q. 값은 꼭짓점의 y좌표예요.

(1)y = (x − 1)² + 2 의 최솟값은?

(2)y = −2(x + 3)² + 5 의 최댓값은?

(3)y = x² − 4x + 7 의 최솟값은?

왜?(x − 2)² + 3 → x = 2 일 때 최솟값 3.
심화도전

(4)y = −(x − 2)² + k 의 최댓값이 5 일 때, 이 그래프의 y절편은?

왜?위로 볼록이라 최댓값 = k = 5 → y = −(x − 2)² + 5 → x = 0: −4 + 5 = 1.
5최댓값·최솟값 (일반형)
핵심보통

먼저 표준형으로 고쳐요. 상수항은 최댓값·최솟값이 아니라 y절편이에요.

(1)y = −x² + 6x − 4 의 최댓값은?

(2)y = −x² − 2x + 3 의 최댓값은?

(3)y = 2x² − 8x + k 의 최솟값이 1일 때 k는?

왜?2(x − 2)² − 8 + k → 최솟값 k − 8 = 1 → k = 9.
심화도전

(4)y = ax² − 4x + 1 (a > 0) 의 최솟값이 −7 일 때 a는?

왜?y = a(x − 2/a)² + 1 − 4/a → 최솟값 1 − 4/a = −7 → 4/a = 8 → a = 1/2.
6조건으로 계수 구하기
종합보통

축 → −b/2a, 지나는 점 → 대입, 최솟값·최댓값 → 표준형의 q.

(1)y = x² + bx + 5 의 그래프의 축이 직선 x = 2 일 때 b는?

(2)y = ax² + 2x + 1 의 그래프가 점 (1, 4) 를 지날 때 a는?

(3)y = x² − 2x + c 의 최솟값이 −3 일 때 c는?

왜?(x − 1)² + c − 1 → 최솟값 c − 1 = −3 → c = −2.
심화도전

(4)y = x² + bx + c 의 그래프의 꼭짓점이 (2, −1) 일 때 b + c 는?

왜?y = (x − 2)² − 1 = x² − 4x + 3 → b + c = −4 + 3 = −1.
7최대·최소의 활용
실생활보통

모르는 것을 x로 놓고 이차함수를 세운 뒤 표준형으로 고쳐요. 꼭짓점의 y좌표가 답이에요.

(1)둘레가 20인 직사각형의 넓이의 최댓값은?

(2)위로 던진 공의 t초 후 높이가 h = −5t² + 20t (m) 일 때, 공이 올라가는 최고 높이는 몇 m인가요?

m

(3)합이 8인 두 수의 곱의 최댓값은?

왜?한 수를 x → 곱 x(8 − x) = −(x − 4)² + 16 → x = 4 일 때 최대 16.
심화도전

(4)길이 40 m 인 울타리로 벽에 붙여 직사각형 화단을 만들어요(벽 쪽엔 울타리 없음). 화단 넓이의 최댓값은 몇 m² 인가요?

왜?벽과 수직인 변을 x 라 하면 나머지 변은 40 − 2x → 넓이 −2x² + 40x = −2(x − 10)² + 200 → 최댓값 200.
