유형별 연습 — 이차방정식

인수분해·제곱근·근의 공식으로 풀기부터 근의 개수·활용까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

답은 숫자 하나로 써요. 근이 둘이면 문제에서 말한 쪽(작은 근·큰 근)만, 근호가 있으면 묻는 자리(k)만 답해요.

푼 문제: 0 / 21

1인수분해로 풀기
기본기본

= 0 꼴로 만들고 인수분해한 뒤, 각 인수를 0으로 놓아요. AB = 0 이면 A = 0 또는 B = 0.

(1)x² − 5x + 6 = 0 의 두 근 중 작은 근은?

(2)x² + 3x − 10 = 0 의 두 근 중 큰 근은?

(3)2x² − 7x + 3 = 0 의 두 근 중 큰 근은?

왜?(2x − 1)(x − 3) = 0 → x = 1/2 또는 x = 3.
2제곱근으로 풀기
기본기본

x² = k 이면 x = ±√k, (x − p)² = k 이면 x = p ± √k 예요.

(1)x² = 16 의 두 근 중 양수인 근은?

(2)(x − 3)² = 25 의 두 근 중 큰 근은?

(3)3(x + 1)² = 12 의 두 근 중 작은 근은?

왜?양변을 3으로 나누면 (x + 1)² = 4 → x + 1 = ±2 → x = 1 또는 x = −3.
3완전제곱식으로 만들기
핵심보통

x 계수의 절반의 제곱을 양변에 더하면 (x + ▢)² = k 꼴이 돼요.

(1)x² + 6x + k 가 완전제곱식이 되게 하는 k는?

(2)x² − 8x + 3 = 0 을 (x − 4)² = k 로 고치면 k는?

(3)x² + 2x − 4 = 0 의 해가 x = −1 ± √k 일 때 k는?

왜?x² + 2x = 4 → 양변에 1을 더해 (x + 1)² = 5 → x = −1 ± √5.
4근의 공식으로 풀기
핵심보통

x = (−b ± √(b² − 4ac)) / 2a. 근호 안 b² − 4ac 부터 계산해요.

(1)x² + 3x + 1 = 0 의 해가 x = (−3 ± √k) / 2 일 때 k는?

(2)2x² − 3x − 1 = 0 의 해가 x = (3 ± √k) / 4 일 때 k는?

(3)x² − 4x + 1 = 0 의 해가 x = 2 ± √k 일 때 k는?

왜?x = (4 ± √(16 − 4)) / 2 = (4 ± √12) / 2 = (4 ± 2√3) / 2 = 2 ± √3.
5근의 개수
개념보통

b² − 4ac 가 양수면 2개, 0이면 1개(중근), 음수면 0개예요.

(1)x² − 6x + 9 = 0 의 근의 개수는?

개

(2)x² + x + 3 = 0 의 근의 개수는?

개

(3)x² + 4x + k = 0 이 중근을 가질 때 k는?

왜?중근 ⇔ b² − 4ac = 0 → 16 − 4k = 0 → k = 4. (x + 2)² = 0.
6근이 주어진 이차방정식
종합보통

근을 알면 (x − 근)(x − 근) = 0 으로 만들 수 있고, 한 근을 대입하면 미지의 계수가 나와요.

(1)두 근이 2, 5인 이차방정식이 x² + ax + 10 = 0 일 때 a는?

(2)x² − 5x + 6 = 0 의 두 근의 합은?

(3)x = 3 이 x² + ax − 12 = 0 의 한 근일 때 a는?

왜?x = 3 대입: 9 + 3a − 12 = 0 → 3a = 3 → a = 1.
7이차방정식의 활용
실생활보통

모르는 것을 x로 놓고 식을 세워요. 근을 구한 뒤 조건(자연수·양수)에 맞는 것만 골라요.

(1)연속한 두 자연수의 곱이 56일 때, 작은 수는?

(2)어떤 양수를 제곱한 것이 그 수의 3배보다 10만큼 클 때, 그 수는?

(3)가로가 세로보다 3 cm 긴 직사각형의 넓이가 40 cm² 일 때, 세로의 길이는?

cm
왜?세로 x → x(x + 3) = 40 → x² + 3x − 40 = 0 → (x + 8)(x − 5) = 0 → 길이니까 x = 5.
✓
이차방정식 7가지 유형을 마쳤어요
세 가지 풀이법부터 근의 개수·활용까지 다뤘어요.
