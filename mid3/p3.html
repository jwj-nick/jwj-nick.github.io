유형별 연습 — 다항식의 곱셈과 인수분해

곱셈공식 전개부터 인수분해·수 계산·식의 값까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

답은 숫자 하나로 써요. 문제에서 묻는 자리(계수 a, 상수 b)만 답하면 돼요. 음수는 −(마이너스)를 붙여서요.

푼 문제: 0 / 21

1곱셈공식 — 완전제곱
기본기본

(a ± b)² = a² ± 2ab + b². 가운데 항은 두 항의 곱의 2배예요.

(1)(x + 3)² = x² + ax + 9 일 때 a는?

(2)(x − 5)² = x² − 10x + b 일 때 b는?

(3)(2x + 3)² = 4x² + ax + 9 일 때 a는?

왜?가운데 항 = 2 × 2x × 3 = 12x. (2x)² = 4x² 도 잊지 마세요.
2곱셈공식 — 합차와 (x+a)(x+b)
기본기본

(a + b)(a − b) = a² − b². (x + a)(x + b) = x² + (a + b)x + ab — 가운데는 합, 끝은 곱.

(1)(x + 6)(x − 6) = x² − b 일 때 b는?

(2)(x + 2)(x + 7) = x² + ax + 14 일 때 a는?

(3)(x − 3)(x + 5) = x² + ax − 15 일 때 a는?

왜?합 = (−3) + 5 = 2, 곱 = (−3) × 5 = −15.
3인수분해 — 공통인수와 완전제곱식
핵심보통

먼저 공통인수를 묶고, 끝 항이 제곱수이면서 가운데가 그 두 배인지 봐요.

(1)3x² + 6x = 3x(x + a) 일 때 a는?

(2)x² + 8x + 16 = (x + a)² 일 때 a는?

(3)4x² − 12x + 9 = (2x − a)² 일 때 a는?

왜?(2x)² = 4x², 3² = 9, 가운데 2 × 2x × 3 = 12x ✓ 부호는 −.
4인수분해 — 곱과 합으로 두 수 찾기
핵심보통

곱이 끝 항, 합이 가운데 계수인 두 수를 찾아요. 곱의 짝을 먼저 나열하고 합을 골라요.

(1)x² + 5x + 6 = (x + a)(x + b) 일 때 작은 수 a는?

(2)x² − x − 12 = (x + 3)(x − a) 일 때 a는?

(3)x² − 7x + 10 = (x − 2)(x − a) 일 때 a는?

왜?곱이 10이고 합이 −7인 두 수는 −2, −5.
5인수분해 — 합차와 x² 계수가 있을 때
핵심보통

a² − b² = (a + b)(a − b). x² 계수가 1이 아니면 (ax + b)(cx + d) 꼴로 맞춰 봐요.

(1)x² − 49 = (x + 7)(x − a) 일 때 a는?

(2)9x² − 4 = (3x + 2)(3x − a) 일 때 a는?

(3)2x² + 7x + 3 = (2x + 1)(x + a) 일 때 a는?

왜?(2x + 1)(x + 3) = 2x² + 6x + x + 3 = 2x² + 7x + 3 ✓
6곱셈공식으로 수 계산
활용보통

100이나 50 근처의 수는 (100 ± a) 꼴로 바꿔 공식을 써요.

(1)102² 의 값은?

(2)99 × 101 의 값은?

(3)51² − 49² 의 값은?

왜?51² − 49² = (51 + 49)(51 − 49) = 100 × 2 = 200.
7곱셈공식의 변형 — 식의 값
종합보통

a² + b² = (a + b)² − 2ab = (a − b)² + 2ab, (a − b)² = (a + b)² − 4ab.

(1)x + y = 4, xy = 3 일 때 x² + y² 의 값은?

(2)a − b = 3, ab = 2 일 때 a² + b² 의 값은?

(3)x + y = 6, xy = 5 일 때 (x − y)² 의 값은?

왜?(x − y)² = (x + y)² − 4xy = 36 − 20 = 16.
✓
다항식의 곱셈과 인수분해 7가지 유형을 마쳤어요
