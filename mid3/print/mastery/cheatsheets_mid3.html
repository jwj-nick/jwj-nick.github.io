🧩 인수분해·전개 한 장 요약

(a + b)² = a² + 2ab + b²(a − b)² = a² − 2ab + b² · 2ab는 직사각형 두 개
(a + b)(a − b) = a² − b²가운데 항이 사라져요 · 101 × 99 = 10000 − 1
(x + a)(x + b) = x² + (a + b)x + ab가운데는 합, 끝은 곱
(ax + b)(cx + d) = acx² + (ad + bc)x + bd바깥끼리 + 안쪽끼리
인수분해 순서① 공통인수 → ② 완전제곱식? → ③ 합차? → ④ 곱해서 c·더해서 b
🔁 검산은 전개답을 쓰고 3초, 다시 곱해 보면 스스로 채점돼요

🌱 제곱근·무리수 한 장 요약

√a = 넓이 a인 정사각형의 한 변제곱하면 a가 되는 양수 · 수직선 위의 분명한 한 점
a의 제곱근 = ±√a (두 개)제곱근 a = √a (하나) · 0의 제곱근은 0 · 음수의 제곱근은 없어요
√(a²) = |a|√((−3)²) = 3 · a < 0이면 √(a²) = −a · 근호 밖의 −는 그대로
🌱 제곱수 사다리에 끼우기n² < a < (n+1)² → n < √a < n+1 · 비교·정수 부분·근삿값 전부 이 동작
③ 비교정수는 √(n²)으로 바꿔 근호 안끼리 · 음수는 반대
⑤ 자연수 만들기√(ax): a의 홀수 지수 소인수를 x로 · √(a+x): 다음 제곱수까지
무리수근호가 안 벗겨지는 수(√2, √3, √5 …)와 π · 끝없고 반복 없는 소수 · 유리수 + 무리수 = 실수

🎢 이차함수 그래프 이동 한 장 요약

y = ax² — 모양은 a가 정해요a > 0 아래로 볼록 ∪ · a < 0 위로 볼록 ∩ · |a| 클수록 좁아요 · 옮겨도 모양은 그대로
y = a(x − p)² + q — 꼭짓점 (p, q), 축 x = px축 방향 p → x 대신 (x − p) · y축 방향 q → 끝에 + q
🎢 괄호 안을 0으로 만드는 x가 p예요(x − 3)² → x = 3 → 오른쪽 3 · (x + 4)² → x = −4 → 왼쪽 4 · q는 그대로 위아래
③ 그래프 → 식꼭짓점 (p, q)로 y = a(x − p)² + q 놓고, 지나는 다른 한 점을 넣어 a
④ 일반형 → 완전제곱식a로 묶기 → (x의 계수 ÷ 2)² 더하고 빼기 → 밖으로 나올 때 a 곱하기 · y절편 = 상수항 c
⑤ 최댓값·최솟값a > 0 → 최솟값 q(x = p일 때) · a < 0 → 최댓값 q · 반대쪽 값은 없어요

📏 삼각비 한 장 요약

먼저 이름 붙이기빗변 = 직각의 맞은편 · 높이 = 기준각과 마주 보는 변 · 밑변 = 기준각에 붙은 변
sin A높이 ÷ 빗변
cos A밑변 ÷ 빗변
tan A높이 ÷ 밑변
특수각 30°sin 1/2 · cos √3/2 · tan √3/3
45°sin √2/2 · cos √2/2 · tan 1
60°sin √3/2 · cos 1/2 · tan √3
한 비로 나머지sin A = a/c → 남은 변은 피타고라스로 · 그다음 그냥 읽어요
변의 길이높이 = 빗변 × sin A · 밑변 = 빗변 × cos A · 높이 = 밑변 × tan A
⚠ 기준각이 바뀌면높이와 밑변이 자리를 바꿔요 · sin A = cos B (A + B = 90°)
⚠ 값의 범위sin·cos는 항상 1보다 작거나 같아요(빗변이 제일 길어서요)

⭕ 원의 성질 한 장 요약

🌱 뿌리중심에서 원 위 어느 점까지나 거리가 같아요 → 반지름 두 개면 이등변삼각형
중심 → 현 수선현을 이등분 · 반지름² = (중심~현 거리)² + (현÷2)²
같은 거리 = 같은 길이중심에서 같은 거리인 두 현은 길이가 같아요
접선 ⊥ 반지름접선 길이² = (중심까지 거리)² − 반지름²
두 접선의 길이원 밖 한 점에서 그은 두 접선은 길이가 같아요
원주각 = 중심각 ÷ 2같은 호를 보면 어디서 보아도 같은 각 · 지름을 보면 90°
내접사각형마주 보는 각의 합 180° · 한 외각 = 마주 보는 내각
🧭 푸는 순서이등변삼각형 찾기 → 접선이면 직각 표시 → 같은 호면 원주각 → 네 점이 원 위면 내접사각형
