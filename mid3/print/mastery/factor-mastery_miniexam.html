해답

1.다음을 전개하면? (x + 8)(x − 8)

2.다음을 인수분해하면? 4x² − 9
정답은 (2x + 3)(2x − 3)예요. 전개해서 검산해 보면 왜 그런지 보여요.
3.다음을 인수분해하면? 4x² + 4x − 3
답은 (2x + 1)(2x + 3)이에요.
4.x² − 10x + □가 완전제곱식이 되도록 □에 알맞은 수는?
정답은 25이에요.
5.다음을 인수분해하면? x² − 4x − 21
정답은 (x + 3)(x − 7)예요. 전개해서 검산해 보면 왜 그런지 보여요.
6.다음을 전개하면? (x + 7)(x − 7)
정답은 x² − 49예요. 전개해서 검산해 보면 왜 그런지 보여요.
7.다음을 인수분해하면? x(x − 1) + 4(x − 1)
답은 (x − 1)(x − 4)이에요.
8.다음을 인수분해하면? x² − 4y²
정답은 (x + 2y)(x − 2y)예요. 전개해서 검산해 보면 왜 그런지 보여요.
9.다음을 인수분해하면? 4x² + 4x − 3
정답은 (2x − 1)(2x + 3)예요. 전개해서 검산해 보면 왜 그런지 보여요.
10.x² + 16x + 64 = (x + a)²일 때 a의 값은?
정답은 8이에요.
