중3단원 6심화 탐구

가장 클 때를 찾아서

a, b, c 세 손잡이로 일반형 포물선을 조종하고, 둘레가 같은 직사각형 중 가장 넓은 것을 직접 찾아봐요.

이 페이지엔 채점 문제가 거의 없어요. 슬라이더를 움직이며 느껴 보세요. 맨 끝에 도전 문제 하나만 있어요.

1큰 그림

y = ax² + bx + c 를 조종하면

a는 모양, c는 y절편, b는 꼭짓점을 비스듬히 옮겨요. 세 수를 바꾸면서 표준형·꼭짓점·최댓값(최솟값)이 함께 바뀌는 걸 봐요.

일반형 조종실 · a, b, c 를 바꿔 볼까요?
2한 걸음 더

둘레가 20인 직사각형 — 어떤 모양이 가장 넓을까

가로 x, 세로 10 − x. 넓이 S = x(10 − x) 는 x에 대한 이차함수예요. 가로를 바꿔 가며 넓이가 어떻게 오르내리는지, 그래프 위 점이 어디서 가장 높은지 확인해 봐요.

넓이 실험실 · 가로 x 를 바꿔 볼까요?

S = −x² + 10x = −(x − 5)² + 25. x = 5, 즉 정사각형일 때 넓이가 가장 커요.

3유도

일반형에서 꼭짓점 공식이 나오기까지

y = ax² + bx + c = a(x² + (b/a)x) + c — x², x 항만 a로 묶어요.
괄호 안에 (b/2a)² 을 더하고 빼요: a{(x + b/2a)² − (b/2a)²} + c
뺀 것을 밖으로(a 곱): y = a(x + b/2a)² − b²/4a + c
그래서 축은 x = −b/2a, 꼭짓점의 y좌표는 c − b²/4a. 매번 완전제곱을 안 해도 축은 −b/2a 로 바로 나와요.
4도전

최댓값이 정해져 있을 때

y = −x² + 2kx − 3 의 최댓값이 6 일 때, 양수 k의 값은?

💡 표준형으로: −(x² − 2kx) − 3 = −(x − k)² + k² − 3.

💡 위로 볼록이니 최댓값은 꼭짓점의 y좌표 k² − 3. 이것이 6.

💡 k² = 9, k > 0.
