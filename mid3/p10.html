유형별 연습 — 원주각

원주각과 중심각부터 내접사각형·접선과 현까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

답은 각도의 숫자만 써요(° 없이). 그림이 없으면 머릿속에 원을 그리고, 어느 호를 보는 각인지 먼저 정해요.

푼 문제: 0 / 28

1원주각과 중심각
기본기본

원주각 = ½ × 중심각. 점 P가 작은 호 위에 있으면 P가 보는 건 반대쪽 큰 호예요.

(1)호 AB에 대한 중심각이 80° 일 때 원주각 ∠APB 는?

(2)호 AB에 대한 원주각이 55° 일 때 중심각 ∠AOB 는?

(3)∠AOB = 140° (작은 호 쪽)이고, 점 P가 작은 호 AB 위에 있을 때 ∠APB 는?

왜?P가 보는 호는 큰 호 AB — 중심각 360° − 140° = 220° → 원주각 110°.
심화도전

(4)원 O 위의 두 점 A, B에 대하여 ∠AOB = (2x + 20)°, 큰 호 위의 점 P에 대하여 ∠APB = (3x − 10)° 일 때 x는?

왜?중심각 = 2 × 원주각 → 2x + 20 = 2(3x − 10) = 6x − 20 → 4x = 40 → x = 10.
2같은 호의 원주각 · 반원
핵심보통

같은 호를 보는 원주각은 모두 같아요. 지름이 보이면 90°.

(1)원 위의 점 P, Q가 호 AB의 같은 쪽에 있고 ∠APB = 40° 일 때 ∠AQB 는?

(2)AB가 지름인 원 위의 점 C에 대하여 ∠BAC = 25° 일 때 ∠ABC 는?

(3)원 위에 네 점 A, B, C, D가 순서대로 있고 AC와 BD의 교점을 P라 하자. ∠DAC = 30°, ∠ACB = 40° 일 때 ∠APB 는?

왜?∠DBC = ∠DAC = 30°(호 DC) → 삼각형 PBC에서 ∠BPC = 180° − 30° − 40° = 110° → ∠APB = 70°.
심화도전

(4)AB가 지름인 원 위의 점 C에 대하여 ∠ABC = 2∠BAC 일 때 ∠BAC 는?

왜?∠ACB = 90° → ∠BAC + ∠ABC = 90° → x + 2x = 90 → 30°.
3원주각과 호의 길이
개념보통

호의 길이는 원주각에 정비례. 원 한 바퀴는 원주각으로 180°.

(1)호 AB : 호 CD = 1 : 2 이고 ∠APB = 20° 일 때 호 CD에 대한 원주각 ∠CQD 는?

(2)원주를 12등분한 점들 중 이웃한 두 점 사이의 호에 대한 원주각은?

(3)호 AB에 대한 원주각이 30° 이고 호 AB의 길이가 6 일 때 이 원의 둘레(원주)는?

왜?원주각 30° ↔ 중심각 60° = 원의 1/6 → 원주 = 6 × 6 = 36.
심화도전

(4)원주를 5등분한 점을 차례로 이은 정오각형의 한 내각은?

왜?한 호의 중심각 = 360° ÷ 5 = 72°. 한 내각은 호 3개를 보는 원주각 = ½ × 216° = 108°.
4내접사각형 — 마주 보는 각
핵심보통

∠A + ∠C = 180°, ∠B + ∠D = 180°.

(1)원에 내접하는 사각형 ABCD에서 ∠A = 70° 일 때 ∠C 는?

(2)원에 내접하는 사각형 ABCD에서 ∠B = 3x°, ∠D = (2x + 30)° 일 때 x는?

(3)원에 내접하는 사각형 ABCD에서 ∠A = 85°, ∠B = 105° 일 때 ∠D 는?

왜?∠D의 짝은 ∠B: 180° − 105° = 75°. (∠A는 ∠C의 짝이라 여기선 안 써요)
심화도전

(4)원에 내접하는 사각형 ABCD에서 ∠A : ∠C = 2 : 3, ∠B = 100° 일 때 ∠A + ∠D 는?

왜?∠A + ∠C = 180° → ∠A = 72°. ∠D = 180° − 100° = 80° → 합 152°.
5내접사각형 — 외각과 내대각
핵심보통

한 외각 = 마주 보는 내각(내대각). 변 BC의 연장선 위 점 E에 대해 ∠DCE = ∠A.

(1)원에 내접하는 사각형 ABCD에서 ∠A = 75° 일 때, 변 BC의 연장선 위의 점 E에 대한 외각 ∠DCE 는?

(2)원에 내접하는 사각형 ABCD에서 외각 ∠DCE = 110°, ∠B = 95° 일 때 ∠D 는?

(3)원에 내접하는 사각형 ABCD에서 변 AB의 연장선 위의 점 E에 대하여 ∠CBE = (3x − 10)°, ∠D = (2x + 20)° 일 때 x는?

왜?외각 ∠CBE = 내대각 ∠D → 3x − 10 = 2x + 20 → x = 30.
심화도전

(4)원에 내접하는 사각형 ABCD의 두 변 AB, DC 의 연장선이 점 E에서 만나요. ∠E = 30°, ∠ADC = 70° 일 때 ∠BAD 는?

왜?외각 ∠EBC = ∠ADC = 70° → 삼각형 EBC 에서 ∠ECB = 80° → ∠BCD = 100° → ∠BAD = 180° − 100° = 80°.
6접선과 현이 이루는 각
활용보통

접선과 현이 이루는 각 = 그 각 안의 호에 대한 원주각. ∠BAT = ∠ACB.

(1)점 A에서의 접선 AT와 현 AB가 이루는 각 ∠BAT = 65° 일 때 ∠ACB 는?

(2)∠BAT = 40°, ∠ABC = 70° 일 때 ∠BAC 는?

(3)점 T에서의 접선 PQ와 두 현 TA, TB에 대하여 ∠ATP = 50°, ∠BTQ = 60° 일 때 ∠TAB 는?

왜?∠TAB는 호 TB의 원주각 = 접선과 현 TB가 이루는 각 ∠BTQ = 60°. (∠TBA = ∠ATP = 50°)
심화도전

(4)접선 AT 와 현 AB 가 이루는 각 ∠BAT = 70°, ∠ABC = 55° 일 때 ∠ACB 와 ∠BAC 의 차는?

왜?∠ACB = ∠BAT = 70°, ∠BAC = 180° − 55° − 70° = 55° → 차 15°.
7원주각 종합
활용보통

중심이 나오면 반지름 이등변삼각형, 네 점이 나오면 같은 호 찾기.

(1)원 O 위의 세 점 A, B, C에 대하여 ∠ACB = 30° 일 때 ∠OAB 는?

(2)원 O 위의 세 점 A, B, C에 대하여 ∠OBA = 20° 일 때, 작은 호 AB에 대한 원주각 ∠ACB 는?

(3)원에 내접하는 사각형 ABCD의 두 대각선의 교점을 P라 하자. ∠ABD = 40°, ∠BDC = 50° 일 때 ∠APB 는?

왜?∠BAC = ∠BDC = 50°(호 BC) → 삼각형 ABP에서 ∠APB = 180° − 50° − 40° = 90°.
심화도전

(4)원 O에 내접하는 삼각형 ABC에서 ∠OBC = 25° 일 때 ∠BAC 는?

왜?OB = OC → ∠OCB = 25° → ∠BOC = 130° → 원주각 ∠BAC = ½ × 130° = 65°.
