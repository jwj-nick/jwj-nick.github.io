근의 공식은 어디서 왔나

완전제곱식 만들기를 넓이로 보고, 근의 공식이 그 과정을 딱 한 번 해 둔 것임을 확인해요. 그리고 계산기 하나를 손에 넣어요.

이 페이지엔 채점 문제가 거의 없어요. 슬라이더를 움직이며 느껴 보세요. 맨 끝에 도전 문제 하나만 있어요.

1큰 그림

x² + bx 에 뭘 더해야 정사각형이 될까

x² + bx 는 한 변이 x인 정사각형에 가로 b·세로 x인 직사각형을 붙인 모양이에요. 그 직사각형을 반으로 잘라 정사각형의 오른쪽과 아래에 하나씩 붙이면, 모서리에 (b/2)² 짜리 빈칸이 생겨요. 그 빈칸을 채우면 한 변이 x + b/2 인 정사각형 — 그래서 "절반의 제곱을 더한다"예요.

정사각형 완성 실험실 · b를 바꿔 볼까요?

x² + bx + (b/2)² = (x + b/2)². 빈칸(초록)의 넓이가 바로 양변에 더하는 수예요.

2유도

ax² + bx + c = 0 에 한 번만 해 두면

양변을 a로 나누고 상수를 넘겨요: x² + (b/a)x = −c/a
x 계수의 절반의 제곱 (b/2a)² 을 양변에 더해요: (x + b/2a)² = b²/4a² − c/a = (b² − 4ac)/4a²
제곱근을 씌워요: x + b/2a = ±√(b² − 4ac) / 2a
정리하면 x = (−b ± √(b² − 4ac)) / 2a — 근의 공식이에요. 매번 완전제곱을 만드는 대신, 한 번 만든 결과를 쓰는 거예요.
3한 걸음 더

근의 공식 계산기 — b² − 4ac 가 모든 걸 말해요

a, b, c를 바꾸면 근호 안 값과 근의 개수·모양이 어떻게 달라지는지 봐요. 근호 안이 제곱수면 근이 유리수(인수분해로도 풀림), 아니면 무리수, 음수면 근이 없어요.

4도전

중근의 조건을 거꾸로

x² − 6x + k = 0 이 중근을 가질 때, 그 중근의 값은?

💡 중근 ⇔ b² − 4ac = 0. 여기서 a = 1, b = −6 이니 36 − 4k = 0.

💡 k = 9 → 방정식은 x² − 6x + 9 = 0, 즉 (x − 3)² = 0.

💡 중근은 (x − 3)² = 0 을 만족하는 x 하나예요.
