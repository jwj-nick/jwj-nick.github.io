중3 수학제곱근·무리수 감 잡기

🌱 제곱근·무리수 감 잡기

"루트 2가 도대체 얼마예요?" 기호 √가 갑자기 나타나서 막막했나요? 괜찮아요 — √는 새로운 계산이 아니라 "넓이가 2인 정사각형의 한 변"에 붙인 이름일 뿐이에요. 공식부터 외우지 않을 거예요. 정사각형을 직접 잘라 보면서 시작해요.

① 제곱근 구하기② √a² 벗기기③ 대소 비교④ 정수 부분⑤ 자연수 만들기
1넓이가 2인 정사각형 만들기 (공식 없이)

넓이가 4인 정사각형은 한 변이 2, 넓이가 9면 한 변이 3이죠. 그럼 넓이가 2인 정사각형의 한 변은 얼마일까요? 정수로는 안 되지만, 그런 정사각형은 분명히 있어요. ▶ 재생을 눌러 직접 만들어 봐요.

네 귀퉁이를 잘라 냈더니 넓이 4의 딱 절반, 넓이 2인 정사각형이 남았어요. 이 정사각형의 한 변은 1보다 길고 2보다 짧아요. 이 길이에 √2(루트 2)라는 이름을 붙여요. 그러니까 √2 = "제곱하면 2가 되는 양수"예요.

함께 생각하기 ①

넓이가 25인 정사각형의 한 변의 길이는 얼마일까요?

2√2는 수직선 위 어디에? — 컴퍼스로 찍어 봐요

두 변이 1, 1인 직각삼각형의 빗변은 피타고라스 정리로 1² + 1² = 2, 그러니까 빗변의 길이가 √2예요. 이 빗변을 컴퍼스로 돌려서 수직선에 내리면 √2가 정확히 어디인지 찍을 수 있어요. 근호 안의 수를 골라 ▶ 재생을 눌러 보세요.

찍을 수

√2, √5, √10 … 전부 수직선 위의 분명한 한 점이에요. 눈금 사이에 있어서 낯설 뿐이에요. 이렇게 수직선을 빈틈없이 채우는 수를 통틀어 실수라고 불러요.

함께 생각하기 ②

직각을 낀 두 변의 길이가 1과 3인 직각삼각형의 빗변은 √? 이에요. 물음표에 들어갈 수는 얼마일까요?

3√2는 얼마쯤? — 제곱해서 좁혀가기, 그리고 이름 정리

√2를 소수로 쓰면 얼마일까요? 계산기 없이도 찾을 수 있어요. 제곱해서 2보다 작은지 큰지만 보면 돼요. 자릿수를 늘려 보세요.

수 소수 자릿수 1자리

자릿수를 아무리 늘려도 끝나지 않고, 같은 숫자가 반복되지도 않아요. 이런 수를 무리수라고 해요. √2 = 1.41421356… 처럼요. 반대로 √9 = 3, √0.25 = 0.5처럼 근호가 벗겨지는 수는 유리수예요.

이제 이름을 정확히 정리해요.

x² = a 이면 x는 a의 제곱근제곱해서 a가 되는 수 · 양수 a면 두 개(양수·음수)
a의 제곱근 = ±√a"제곱근 a" = √a 는 그중 양수 하나
√(a²) = |a|근호를 벗기면 항상 0 이상 · a가 음수면 −a
⚠ 가장 흔한 함정 — "16의 제곱근"은 제곱해서 16이 되는 수 전부, 그러니까 4와 −4(±4) 두 개예요. "제곱근 16"은 √16 하나, 그러니까 4예요. 조사 "의"가 있으면 두 개, 없으면 하나예요. 시험에서 가장 많이 틀리는 한 줄이에요.
⚠ 근호를 벗길 때 — √((−3)²) = √9 = 3이에요. −3이 아니에요. 근호 안이 먼저 계산돼서 9가 되고, √9는 양수 3이니까요. 그래서 a가 음수이면 √(a²) = −a(부호를 뒤집어 양수로) 예요.

함께 생각하기 ③

√((−7)²) 의 값은 얼마일까요?

4핵심 도구 — 제곱수 사다리에 끼우기

√가 나오는 문제의 절반은 이 표 하나로 풀려요. 1부터 15까지의 제곱수예요. 근호 안의 수를 이웃한 두 제곱수 사이에 끼우면 √가 어느 정수 사이에 있는지 바로 보여요.

근호 안의 수를 넣어 보세요. 어느 두 제곱수 사이에 끼는지 표에 표시돼요.

√
🌱불변 앵커 — √는 "넓이", 답은 "변의 길이"예요. √a가 얼마쯤인지 궁금하면 언제나 a를 이웃한 제곱수 사이에 끼워요: n² < a < (n+1)² 이면 n < √a < n+1. 비교도, 정수 부분도, 근삿값도 전부 이 한 동작이에요.

연습을 몇 개 더 해볼까요? 두 칸을 채워요.

5유형별 완전정복

이제 진짜 문제로 가요. 5가지 유형만 알면 01단원 전반부는 다 풀려요. 막히면 💡 힌트를 먼저 눌러 보고, 그래도 어려우면 확인을 눌러 풀이를 봐요. "다른 문제로"를 누르면 숫자가 바뀌어요.

①
제곱근 구하기
"a의 제곱근"은 두 개 · "제곱근 a"는 하나
핵심 제곱해서 a가 되는 수를 찾아요. 양수 a의 제곱근은 부호만 다른 두 개예요. (√a)²과 (−√a)²은 둘 다 a예요.
②
√a² 벗기기
근호를 벗기면 항상 0 이상 · 음수면 부호를 뒤집어요
핵심 √(a²) = |a|. 안이 음수면 벗길 때 부호를 뒤집어요(−a). 근호 밖의 −는 그대로 남아요.
③
대소 비교
근호 안으로 넣어서 넓이끼리 비교해요
핵심 정수 n은 √(n²)으로 바꿔서 근호 안끼리 비교해요. 양수는 안이 클수록 크고, 음수는 반대예요.
④
정수 부분 · 개수 세기
제곱수 사다리에 끼우면 끝
핵심 n² ≤ a < (n+1)² 이면 √a의 정수 부분은 n이에요. "m < √x < n인 자연수 x"는 m² < x < n²으로 바꿔서 세요.
⑤
자연수 만들기
근호 안을 제곱수로 · 소인수분해가 열쇠
핵심 √(ax)가 자연수가 되려면 ax가 제곱수여야 해요. a를 소인수분해해서 지수가 홀수인 소인수를 x로 채워요. √(a+x)는 a보다 큰 가장 가까운 제곱수를 찾아요.
6실전 총정리 — 유형 섞어서

이번엔 어떤 유형인지 안 알려드려요. "의 제곱근인가, 제곱근 a인가", "근호 안에 넣어서 비교"를 먼저 떠올려 풀어봐요. 틀리면 어느 유형인지 알려드릴게요.

7마무리 치트시트

🌱 제곱근·무리수 한 장 요약

√a = 넓이 a인 정사각형의 한 변제곱하면 a가 되는 양수 · 수직선 위의 분명한 한 점
a의 제곱근 = ±√a (두 개)제곱근 a = √a (하나) · 0의 제곱근은 0 · 음수의 제곱근은 없어요
√(a²) = |a|√((−3)²) = 3 · a < 0이면 √(a²) = −a · 근호 밖의 −는 그대로
🌱 제곱수 사다리에 끼우기n² < a < (n+1)² → n < √a < n+1 · 비교·정수 부분·근삿값 전부 이 동작
③ 비교정수는 √(n²)으로 바꿔 근호 안끼리 · 음수는 반대
