유형별 연습 — 근호를 포함한 식의 계산

곱셈·나눗셈부터 유리화·덧셈뺄셈·근삿값까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

답은 숫자 하나로 써요. 문제에서 묻는 자리(계수 a, 근호 안 n, 분모 n)만 답하면 돼요.

푼 문제: 0 / 21

1제곱근의 곱셈과 나눗셈
기본기본

√a × √b = √(ab), √a ÷ √b = √(a/b). 계산한 뒤 근호가 벗겨지는지 확인해요.

(1)√2 × √7 = √n 일 때 n은?

(2)√3 × √12 의 값은?

(3)√48 ÷ √3 의 값은?

왜?√48 ÷ √3 = √(48 ÷ 3) = √16 = 4.
2근호 밖으로 꺼내기 (a√b 꼴)
핵심기본

근호 안에서 제곱수를 찾아 그 제곱근을 밖으로 꺼내요. √(a²b) = a√b.

(1)√20 = a√5 일 때 a는?

(2)√72 = a√2 일 때 a는?

(3)2√3 × √6 = a√2 일 때 a는?

왜?2√3 × √6 = 2√18 = 2 × 3√2 = 6√2.
3근호 안으로 넣기 (√n 꼴)
핵심보통

계수는 제곱해서 근호 안으로 들어가요. a√b = √(a²b).

(1)3√2 = √n 일 때 n은?

(2)5√3 = √n 일 때 n은?

(3)2√5 × 3√2 = √n 일 때 n은?

왜?2√5 × 3√2 = 6√10 = √(36 × 10) = √360.
4분모의 유리화
핵심보통

분모의 근호를 분모·분자에 똑같이 곱해 없애요. 곱한 뒤 약분할 수 있으면 약분해요.

(1)1/√5 = √5/n 일 때 n은?

(2)6/√3 = a√3 일 때 a는?

(3)3/(2√3) = √3/n 일 때 n은?

왜?3/(2√3) = 3√3/(2 × 3) = √3/2 — 분모·분자에 √3을 곱한 뒤 3으로 약분해요.
5제곱근의 덧셈과 뺄셈
핵심보통

근호 안이 같은 것끼리 계수를 더하고 빼요. 먼저 a√b 꼴로 정리하면 같은 것이 보여요.

(1)4√3 + 2√3 = k√3 일 때 k는?

(2)√27 − √12 = k√3 일 때 k는?

(3)√50 + √8 − √18 = k√2 일 때 k는?

왜?5√2 + 2√2 − 3√2 = 4√2.
6분배법칙과 섞인 계산
종합보통

괄호 안 모든 항에 곱하고, 결과를 가장 간단한 꼴로 정리한 뒤 같은 것끼리 모아요.

(1)√2(√3 + √2) = √6 + a 일 때 a는?

(2)√3(2√3 − √6) = a − 3√2 일 때 a는?

(3)√8 ÷ √2 + √3 × √27 의 값은?

왜?√8 ÷ √2 = √4 = 2, √3 × √27 = √81 = 9 → 2 + 9 = 11.
7근삿값 구하기와 활용
실생활보통

√2 ≈ 1.414, √3 ≈ 1.732 로 계산해요. 먼저 a√b 꼴로 정리한 뒤 곱해요. (소수 둘째 자리까지)

(1)√8 의 값은 약 얼마인가요?

(2)√300 의 값은 약 얼마인가요?

(3)넓이가 50 cm² 인 정사각형의 한 변의 길이는 약 몇 cm 인가요?

cm
왜?한 변 = √50 = 5√2 ≈ 5 × 1.414 = 7.07.
