🧩 인수분해·전개 스피드 완성

"(x + 3)² = x² + 9"라고 쓴 적 있나요? 그럴 수 있어요 — 공식을 글자로만 외우면 그렇게 돼요. 이 특강은 공식을 직사각형의 넓이로 보고, 인수분해를 타일 퍼즐로 풀어요. 그다음엔 스피드 드릴로 손이 저절로 움직이게 만들어요. 이건 중3의 관문이자 고등 수학 전체의 기초 체력이에요.

① 전개② 공통인수③ x² + bx + c④ 완전제곱식⑤ a² − b²⑥ acx² + bx + d
1전개는 직사각형의 넓이예요 (공식 없이)

가로가 x + b, 세로가 x + a인 직사각형이 있어요. 넓이는 (세로) × (가로) = (x + a)(x + b)죠. 그런데 이 직사각형은 네 조각으로 나뉘어요. 슬라이더로 a, b를 바꿔 보면서 네 조각의 넓이를 더해 보세요.

2
3

네 조각을 더한 게 곧 전개예요. x² 한 개, x 조각이 (a + b)개, 그리고 a × b짜리 작은 조각. 그래서 (x + a)(x + b) = x² + (a + b)x + ab — "가운데는 합, 끝은 곱"이라는 말이 이 그림이에요.

함께 생각하기 ①

(x + 2)(x + 5)를 전개하면 x의 계수는 얼마일까요? (그림에서 x 조각이 몇 개인지 세어 봐도 돼요.)

2곱셈공식은 외우는 게 아니라 그림에서 읽는 것

가로와 세로가 똑같이 a + b인 정사각형이면 어떻게 될까요? ▶ 재생을 눌러 네 조각이 채워지는 걸 보세요.

⚠ 가장 흔한 실수 — (a + b)² = a² + b²가 아니에요. 그림을 보면 ab짜리 직사각형이 두 개 더 있죠? 그래서 a² + 2ab + b²예요. 가운데 2ab를 빼먹으면 직사각형 두 개를 잃어버리는 거예요.

이번엔 (a + b)(a − b)예요. 한 변이 a인 정사각형에서 한 변이 b인 작은 정사각형을 잘라 내면 넓이가 a² − b²죠. 남은 ㄱ자 조각을 잘라서 옮기면 가로 a − b, 세로 a + b인 직사각형이 돼요. ▶ 재생을 눌러 보세요.

이제 공식을 "읽어" 볼까요? 다섯 개뿐이에요. 전부 위의 그림 하나에서 나와요.

(a + b)² = a² + 2ab + b²정사각형 = 큰 정사각형 + 직사각형 2개 + 작은 정사각형
(a − b)² = a² − 2ab + b²b 자리에 −b를 넣은 것 · 끝 항은 (−b)² = +b²
(a + b)(a − b) = a² − b²ㄱ자 조각 옮기기 · 가운데 항이 사라져요
(x + a)(x + b) = x² + (a + b)x + ab가운데는 합, 끝은 곱
(ax + b)(cx + d) = acx² + (ad + bc)x + bd바깥끼리·안쪽끼리 곱한 걸 더해요

함께 생각하기 ②

(x + 3)(x − 3) = x² − □에서 □는 얼마일까요?

3인수분해는 거꾸로 — 타일로 직사각형 만들기

전개가 "직사각형 → 조각"이었다면, 인수분해는 "조각 → 직사각형"이에요. x² + bx + c는 x² 타일 1개, x 타일 b개, 1짜리 타일 c개예요. 이 타일을 빈틈없이 직사각형으로 놓을 수 있으면 그 가로·세로가 답이에요. x 타일을 위아래로 몇 개씩 나눌지 골라 보세요.

타일이 딱 맞으려면 x 타일을 나눈 두 수의 곱이 1짜리 타일의 개수여야 해요. 그래서 인수분해는 "곱해서 c, 더해서 b"인 두 수 찾기예요. 요령은 곱이 c가 되는 짝을 먼저 다 적고, 그중 합이 b인 짝을 고르는 거예요. 부호도 짝에 넣어요 — 곱이 −6이면 (−3, 2)처럼요.

🔁불변 앵커 — 인수분해 답은 다시 전개해서 검산해요. 답을 쓴 다음 3초만 들여 곱해 보면 스스로 채점이 돼요. 시험에서 이 3초가 점수를 지켜요. (검산은 "전개", 전개의 반대가 "인수분해" — 두 기술은 한 쌍이에요.)
4유형별 완전정복

여섯 가지 유형이면 중3 인수분해는 전부예요. 순서가 중요해요 — 인수분해 문제를 보면 ① 공통인수 → ② 완전제곱식? → ③ 합차? → ④ 두 수 찾기 순서로 확인해요. 각 카드의 "다른 문제로"를 눌러 손에 익을 때까지 반복해요.

①
전개
공식 5개 · 넓이 그림으로 검산
핵심 가운데 항은 "바깥끼리 + 안쪽끼리". 제곱은 2ab를 절대 빼먹지 않아요. 합차는 가운데 항이 없어져요.
②
공통인수 묶기
모든 항에 들어 있는 것부터 밖으로
핵심 숫자는 최대공약수, 문자는 모든 항에 있는 문자의 가장 낮은 차수만큼 묶어요. 묶고 남은 괄호 안을 다시 확인해요 — 더 묶을 게 없어야 끝이에요.
③
x² + bx + c
곱해서 c, 더해서 b인 두 수
핵심 곱이 c가 되는 짝을 먼저 전부 적어요(부호 포함). 그중 합이 b인 짝 하나를 골라요. c가 양수면 두 수의 부호가 같고, c가 음수면 부호가 달라요.
④
완전제곱식
끝 항이 제곱수, 가운데가 그 두 배
핵심 x² + 2ax + a²이면 (x + a)²이에요. 빈칸 문제는 "가운데 계수의 절반을 제곱"(끝 항) 또는 "끝 항의 제곱근의 두 배"(가운데)예요.
⑤
a² − b² 합차
제곱 빼기 제곱은 (합)(차)
핵심 항이 두 개이고 빼기이고 둘 다 제곱수이면 바로 (합)(차)예요. 4x²는 (2x)², 9y²는 (3y)²라는 걸 알아보는 게 전부예요.
⑥
acx² + bx + d
x² 계수가 1이 아닐 때 — 가로세로 대각선
핵심 x² 계수를 두 수의 곱으로, 상수항을 두 수의 곱으로 나눠 놓고 대각선끼리 곱해서 더한 게 가운데 계수가 되는 짝을 찾아요. 안 되면 짝을 바꿔요. 다 됐으면 반드시 전개해서 검산해요.
5실전 총정리 — 유형 섞어서

이번엔 어떤 유형인지 안 알려드려요. 공통인수 → 완전제곱식 → 합차 → 두 수 찾기 순서로 스스로 판단해서 풀어봐요. 틀리면 어느 유형인지 알려드릴게요.
