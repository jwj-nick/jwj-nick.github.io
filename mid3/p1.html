유형별 연습 — 제곱근과 실수

제곱근 구하기부터 크기 비교까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

답은 숫자로 써요. 소수는 0.4처럼, 분수는 2/5처럼, 음수는 −(마이너스)를 붙여서요.

푼 문제: 0 / 21

1제곱근 구하기
기본기본

"제곱해서 a가 되는 수"를 찾아요. 양수 a의 제곱근은 부호만 다른 두 개예요.

(1)36의 제곱근 중 양수인 것은?

(2)0.16의 양의 제곱근은?

(3)(−9)²의 제곱근 중 양수인 것은?

왜?먼저 (−9)² = 81. 81의 제곱근은 ±9이고, 그중 양수는 9예요.
2"a의 제곱근"과 "제곱근 a"
핵심기본

"a의 제곱근"은 ±√a 두 개, "제곱근 a"는 √a 하나예요.

(1)제곱근 64 의 값은?

(2)100의 제곱근 중 음수인 것은?

(3)제곱근 0.25 의 값은?

왜?"제곱근 0.25" = √0.25. 0.5² = 0.25이므로 0.5예요.
3제곱근의 성질
원리보통

(√a)² = a, (−√a)² = a, 그리고 √(a²) = a, √((−a)²) = a — 근호를 벗기면 늘 양수예요.

(1)(√5)² 의 값은?

(2)√((−6)²) 의 값은?

(3)√(2²) − √((−4)²) + (−√3)² 의 값은?

왜?√(2²) = 2, √((−4)²) = 4, (−√3)² = 3 → 2 − 4 + 3 = 1.
4근호 안을 제곱수로 만들기
핵심보통

√(ax)가 자연수가 되려면 ax가 제곱수여야 해요. a를 소인수분해해서 지수가 홀수인 소인수를 x로 채워요.

(1)√(8x) 가 자연수가 되게 하는 가장 작은 자연수 x는?

(2)√(45x) 가 자연수가 되게 하는 가장 작은 자연수 x는?

(3)√(60/x) 가 자연수가 되게 하는 가장 작은 자연수 x는?

왜?60 = 2² × 3 × 5. 지수가 홀수인 3과 5를 나눠 없애야 하니 x = 15, 그러면 √4 = 2.
5유리수·무리수 판별
개념보통

근호 안이 제곱수(또는 제곱수/제곱수)면 근호가 벗겨져 유리수예요. 아니면 무리수.

(1)√25 는 유리수인가요, 무리수인가요?

(2)√0.4 는 유리수인가요, 무리수인가요?

(3)√1.44 는 유리수인가요, 무리수인가요?

왜?1.2² = 1.44 → √1.44 = 1.2, 분수 6/5으로 쓸 수 있으니 유리수예요.
6제곱근의 대소 비교
핵심보통

양수끼리는 근호 안이 클수록 커요. 근호 없는 수는 근호 안에 넣어서(3 = √9) 비교해요. 음수는 반대예요.

(1)√7 과 √5 중 큰 수는?

(2)3 과 √10 중 큰 수는?

(3)−√5 와 −2 중 큰 수는?

왜?2 = √4 이고 √4 < √5. 음수는 절댓값이 작을수록 크니까 −2 > −√5.
7√a 의 정수 부분
종합보통

제곱수 두 개 사이에 근호 안의 수를 끼워 넣어요. n² < a < (n+1)² 이면 n < √a < n+1.

(1)√10 은 어느 두 정수 사이에 있나요? (작은 쪽 정수)

(2)√50 의 정수 부분은?

(3)3 < √x < 4 를 만족하는 자연수 x는 모두 몇 개인가요?

개
왜?각 변을 제곱하면 9 < x < 16 → x = 10, 11, 12, 13, 14, 15 → 6개.
✓
