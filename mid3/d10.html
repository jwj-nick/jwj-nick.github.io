중3단원 10심화 탐구

어디서 봐도 같은 각

호를 키우고 P를 옮기며 원주각이 어떻게 따라오는지, 내접사각형의 마주 보는 각이 왜 늘 180°인지 눈으로 확인해요.

이 페이지엔 채점 문제가 거의 없어요. 슬라이더를 움직이며 느껴 보세요. 맨 끝에 도전 문제 하나만 있어요.

1큰 그림

호를 키우면 중심각도 원주각도 함께 커져요

호 AB의 크기(중심각)를 바꾸고 점 P를 옮겨 봐요. P를 옮겨도 ∠APB는 꿈쩍 않고, 호를 키우면 ∠APB가 중심각의 절반을 정확히 따라가요. 중심각이 180°가 되는 순간 — 지름 — 원주각은 90°.

원주각 실험실 · 호와 P를 바꿔 볼까요?
2한 걸음 더

내접사각형 — 두 호를 합치면 원 하나

원 위의 네 점 A, B, C, D. ∠A는 호 BCD를, ∠C는 호 DAB를 보는 원주각이에요. 두 호를 합치면 원 전체(중심각 360°)라서 원주각의 합은 180°. 점 B, D를 어디로 옮겨도 ∠A + ∠C = 180° 가 유지돼요.

내접사각형 실험실 · B와 D를 옮겨 볼까요?
3유도

원주각이 중심각의 절반인 이유 (중심이 한 변 위에 있을 때)

점 P에서 중심 O를 지나는 지름을 그어 그 끝을 B라 하고, 호 AB의 원주각 ∠APB와 중심각 ∠AOB를 비교해요.
OP = OA (반지름) → 삼각형 OPA는 이등변삼각형 → ∠OPA = ∠OAP. 이 각을 x 라 해요.
∠AOB는 삼각형 OPA의 꼭짓점 O에서의 외각 → 마주 보지 않는 두 내각의 합 = x + x = 2x.
즉 ∠APB = x = ½ ∠AOB. (중심이 안이나 밖에 있을 땐 지름으로 둘로 쪼개서 이 경우를 두 번 써요.)
4도전

비로 주어진 내접사각형

원에 내접하는 사각형 ABCD에서 ∠A : ∠C = 2 : 3 일 때, ∠C 는 몇 도인가요?

💡 내접사각형: ∠A + ∠C = 180°.

💡 ∠A = 2k, ∠C = 3k 로 놓으면 5k = 180°.

💡 k = 36° → ∠C = 3k.
