유형별 연습 — 삼각비

삼각비의 값부터 특수각·0°와 90°·삼각비의 표까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

분수 답은 3/5 처럼 써요(소수도 돼요). 근호가 있으면 묻는 자리(k)만, 각은 숫자만 써요.

푼 문제: 0 / 28

1삼각비의 값 구하기
기본기본

기준각 A에서: sin = 높이/빗변, cos = 밑변/빗변, tan = 높이/밑변. 세 변 중 모르는 변은 피타고라스로 먼저 구해요. · 어느 변이 높이인지 헷갈리면 📏 삼각비 특강 →

(1)밑변 4, 높이 3, 빗변 5인 직각삼각형에서 sin A 는?

(2)밑변 12, 높이 5, 빗변 13인 직각삼각형에서 cos A 는?

(3)빗변 10, 밑변 6인 직각삼각형에서 tan A 는?

왜?높이 = √(10² − 6²) = 8 → tan A = 8/6 = 4/3.
심화도전

(4)밑변 8, 높이 15 인 직각삼각형에서 sin A + cos A 의 값은? (분수로)

왜?빗변 = √(8² + 15²) = 17 → sin A = 15/17, cos A = 8/17 → 합 23/17.
2한 삼각비로 다른 삼각비 구하기
핵심보통

주어진 비로 직각삼각형을 그려요(예: sin A = 3/5 → 높이 3, 빗변 5). 남은 변을 피타고라스로 구한 뒤 읽어요.

(1)sin A = 3/5 일 때 cos A 는?

(2)cos A = 5/13 일 때 tan A 는?

(3)sin A = 1/3 일 때 cos A = √k / 3 이에요. k는?

왜?높이 1, 빗변 3 → 밑변 = √(9 − 1) = √8 → cos A = √8/3 → k = 8 (= 2√2/3).
심화도전

(4)tan A = 3/4 일 때 sin A × cos A 의 값은? (분수로)

왜?높이 3, 밑변 4 → 빗변 5 → sin A = 3/5, cos A = 4/5 → 곱 12/25.
3특수각의 삼각비
핵심기본

30°-60°-90° 는 1 : √3 : 2, 45° 는 1 : 1 : √2. 삼각형을 그려서 읽어요.

(1)sin 30° 의 값은?

(2)cos 45° = √k / 2 일 때 k는?

(3)tan 60° = √k 일 때 k는?

왜?60°와 마주 보는 변 √3, 붙은 변 1 → tan 60° = √3/1.
심화도전

(4)sin 60° ÷ cos 30° + tan 45° 의 값은?

왜?sin 60° = cos 30° = √3/2 → 나누면 1. tan 45° = 1 → 1 + 1 = 2.
4특수각 삼각비의 계산
계산보통

값을 하나씩 대입한 뒤 근호 계산(단원 2)을 해요.

(1)sin 30° + cos 60° 의 값은?

(2)tan 45° × cos 60° 의 값은?

(3)sin 60° × tan 30° 의 값은?

왜?(√3/2) × (√3/3) = 3/6 = 1/2.
심화도전

(4)sin 60° × cos 30° − sin 30° × cos 60° 의 값은? (분수로)

왜?(√3/2)(√3/2) − (1/2)(1/2) = 3/4 − 1/4 = 1/2.
5특수각으로 변의 길이 구하기
활용보통

아는 변과 구할 변이 들어 있는 삼각비를 골라 식을 세워요. 높이 = 빗변 × sin A, 밑변 = 빗변 × cos A, 높이 = 밑변 × tan A.

(1)빗변이 10 이고 A = 30° 인 직각삼각형의 높이는?

(2)밑변이 6 이고 A = 45° 인 직각삼각형의 높이는?

(3)높이가 3 이고 A = 60° 인 직각삼각형의 빗변이 a√3 일 때 a는?

왜?빗변 = 높이 ÷ sin 60° = 3 ÷ (√3/2) = 6/√3 = 2√3.
심화도전

(4)A = 30° 이고 높이가 4 인 직각삼각형의 둘레가 a + b√3 일 때 a + b 는?

왜?빗변 = 4 ÷ sin 30° = 8, 밑변 = 4 ÷ tan 30° = 4√3 → 둘레 12 + 4√3 → a + b = 16.
60°, 90°의 삼각비와 대소
개념보통

sin 0° = 0, cos 0° = 1, tan 0° = 0, sin 90° = 1, cos 90° = 0. 각이 커지면 sin·tan 은 커지고 cos 은 작아져요.

(1)sin 90° 의 값은?

(2)cos 0° + tan 0° 의 값은?

(3)0° < A < 90° 에서 A가 커질수록 값이 작아지는 것은?

왜?사분원에서 cos A 는 가로 길이 — 점이 위로 갈수록 짧아져요.
심화도전

(4)sin 90° × cos 0° − tan 0° + sin 30° 의 값은?

왜?1 × 1 − 0 + 1/2 = 3/2.
