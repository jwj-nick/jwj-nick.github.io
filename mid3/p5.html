중3단원 5연습

유형별 연습 — 이차함수와 그래프

함숫값부터 y = ax² 의 성질·평행이동·식 세우기까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

답은 숫자 하나로 써요. 좌표를 물으면 문제에서 말한 쪽(x좌표·y좌표)만, 음수는 −(마이너스)를 붙여서요.

푼 문제: 0 / 21

1이차함수의 뜻과 함숫값
기본기본

x 자리에 수를 넣으면 y가 나와요. 그래프가 점 (m, n)을 지난다는 건 x = m 일 때 y = n 이라는 뜻이에요.

(1)y = 2x² 에서 x = 3 일 때 y의 값은?

(2)y = −x² + 4 에서 x = 2 일 때 y의 값은?

(3)y = ax² 의 그래프가 점 (2, 12) 를 지날 때 a는?

왜?x = 2, y = 12 대입: 12 = a × 4 → a = 3.
2y = ax² 그래프의 성질
핵심기본

a의 부호 → 볼록 방향, |a| → 폭. y = ax² 과 y = −ax² 은 x축 대칭이에요.

(1)y = 2x² 의 그래프와 x축에 대하여 대칭인 그래프의 식이 y = ax² 일 때 a는?

(2)y = x², y = 3x², y = ½x² 중 그래프의 폭이 가장 좁은 것의 a는?

(3)y = ax² 의 그래프가 점 (−2, −8) 을 지날 때 a는?

왜?−8 = a × (−2)² = 4a → a = −2. 위로 볼록한 그래프예요.
3y = ax² + q — 위아래 평행이동
핵심보통

y = ax² 을 y축 방향으로 q만큼 옮기면 y = ax² + q. 꼭짓점은 (0, q).

(1)y = x² + 5 의 꼭짓점의 y좌표는?

(2)y = −2x² − 3 의 꼭짓점의 y좌표는?

(3)y = x² 을 y축 방향으로 −4 만큼 평행이동한 그래프가 점 (2, k) 를 지날 때 k는?

왜?옮긴 식은 y = x² − 4. x = 2 → 4 − 4 = 0.
4y = a(x − p)² — 좌우 평행이동
핵심보통

y = ax² 을 x축 방향으로 p만큼 옮기면 y = a(x − p)². 꼭짓점 (p, 0), 축 x = p. 괄호 안 부호가 반대예요.

(1)y = (x − 4)² 의 꼭짓점의 x좌표는?

(2)y = 2(x + 3)² 의 그래프의 축이 직선 x = m 일 때 m은?

(3)y = −(x − 1)² 의 그래프가 점 (3, k) 를 지날 때 k는?

왜?x = 3 → y = −(3 − 1)² = −4.
5y = a(x − p)² + q — 꼭짓점과 축
핵심보통

꼭짓점 (p, q), 축 x = p. y축과 만나는 점은 x = 0 을 넣어서 구해요.

(1)y = (x − 2)² + 3 의 꼭짓점의 x좌표와 y좌표의 합은?

(2)y = −3(x + 1)² − 2 의 그래프의 축이 직선 x = m 일 때 m은?

(3)y = 2(x − 1)² − 3 의 그래프가 y축과 만나는 점의 y좌표는?

왜?y축 위의 점은 x = 0: y = 2(0 − 1)² − 3 = 2 − 3 = −1.
6평행이동한 식 구하기
종합보통

x축 방향 p → x 대신 (x − p), y축 방향 q → 식 끝에 + q.

(1)y = 2x² 을 y축 방향으로 3만큼 평행이동한 식이 y = 2x² + k 일 때 k는?

(2)y = x² 을 x축 방향으로 −2 만큼 평행이동한 식이 y = (x + a)² 일 때 a는?

(3)y = −x² 을 x축 방향으로 3, y축 방향으로 −1 만큼 평행이동한 식이 y = −(x − p)² + q 일 때 q는?

왜?식은 y = −(x − 3)² − 1. p = 3, q = −1.
7꼭짓점과 한 점으로 식 세우기
종합보통

꼭짓점 (p, q) → y = a(x − p)² + q 로 놓고, 지나는 점을 대입해 a를 구해요.

(1)꼭짓점이 (0, 2) 이고 점 (1, 5) 를 지나는 이차함수 y = ax² + 2 의 a는?

(2)꼭짓점이 (2, 0) 이고 점 (0, 4) 를 지나는 이차함수 y = a(x − 2)² 의 a는?

(3)꼭짓점이 (1, −3) 이고 점 (2, −1) 을 지나는 이차함수 y = a(x − 1)² − 3 의 a는?

왜?(2, −1) 대입: −1 = a(2 − 1)² − 3 → a = 2.
