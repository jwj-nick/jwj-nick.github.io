편집 모드

아래 문서에서 고치고 싶은 문단·표 칸을 바로 클릭해서 타이핑하세요 (빈칸 포함). Enter = 줄바꿈, 칸 밖 클릭 = 반영. Ctrl+Z 실행취소 · Ctrl+S 저장.

저장하면 새 .hwpx 파일로 다운로드됩니다 — 원본 파일은 절대 바뀌지 않습니다. 수정된 문단의 줄배치 캐시는 규격에 맞게 제거되고 한글이 다시 계산합니다.
