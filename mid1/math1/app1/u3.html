중1단원 3

문자와 식(algebraic expressions)

숫자 대신 문자를 쓰면, 어떤 값이 들어와도 통하는 식이 돼요.

1이어서

문자를 쓰는 이유 — 수량 관계를 한 번에

단원 2에서 수를 음수까지 넓혔죠. 이제 문자로 수 자체를 대신해요. "1개에 500원인 물건 x개의 값"은 물건 수가 몇 개든 500x원으로 한 번에 나타낼 수 있어요. 문자는 아직 정해지지 않은 수를 대표해요.

한 개에 a원인 물건 5개의 값을 문자식으로 쓰면? (공백 없이)
2약속대로 줄여 쓰기

곱셈·나눗셈 기호 생략 규칙

곱셈 기호는 생략해요 — 숫자는 문자 앞에(3a), 계수 1과 −1은 숫자를 아예 안 써요(a, −a), 같은 문자를 거듭 곱하면 거듭제곱으로(a×a=a²). 나눗셈은 분수로 바꿔 써요 — a÷b=a/b.

(−1) × x를 기호 생략으로 나타내면?
3★ 직접 움직여 봐요

x를 바꾸면 식의 값도 바뀌어요

식 2x + 1에 x 대신 값을 대입하면 식의 값이 나와요. 음수를 대입할 땐 꼭 괄호를 써야 부호가 안 섞여요.

4식을 뜯어보면

항·계수·상수항, 단항식과 다항식

항은 +, − 로 끊은 조각, 계수는 항에서 문자에 곱해진 수, 상수항은 문자 없이 수만 있는 항이에요. 항이 1개면 단항식, 2개 이상이면 다항식이고, 가장 높은 차수가 1인 다항식을 일차식이라 불러요.

3x − 5의 상수항은?
5같은 무리끼리

동류항 — 문자와 차수가 같은 항

동류항은 문자와 차수가 둘 다 같은 항이에요. 동류항끼리는 계수만 더하거나 빼서 합칠 수 있어요 — 3x + 5x = 8x. 문자가 다르거나 차수가 다르면 절대 합칠 수 없어요.

3x + 2y − x + y를 정리하면?
6계산의 완성

괄호를 풀고, 동류항을 모아요

일차식끼리 더하고 뺄 땐 괄호를 먼저 풀고(빼기 괄호는 안의 부호가 전부 뒤집혀요) 동류항끼리 모아요. 일차식에 수를 곱할 땐 분배법칙 — 괄호 안 모든 항에 곱해요: a(bx+c)=abx+ac.

3(2x − 1)은?
7내 말로

이제 직접 설명할 차례예요

정답 맞히기가 아니라, 이해한 걸 자기 말로 꺼내보는 거예요.

−(x − 4)를 괄호 없이 쓰면 예요. 앞의 마이너스가 괄호 안 모든 항의 부호를 뒤집으니까요.

−(x − 4)를 괄호 없이 쓰면 −x + 4예요. 앞의 마이너스가 괄호 안 모든 항의 부호를 뒤집으니까요.

−(x−4)는 (−1)×(x−4)와 같아요. 분배법칙으로 −1을 괄호 안 x에도, −4에도 각각 곱하면 −x와 +4가 나와요.

자기 말로 설명하면 돼요. 똑같지 않아도 괜찮아요.
