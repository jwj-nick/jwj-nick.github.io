유형별 연습 — 소인수분해

소수·합성수부터 최대공약수·최소공배수 관계식까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

거듭제곱은 유니코드로 입력해요 (예: 2² → "2제곱" 또는 "4"로 답해도 확인돼요).

푼 문제: 0 / 28

1소수·합성수 판별
기본기본

소수는 약수가 2개, 합성수는 3개 이상. 1은 둘 다 아니에요.

(1)2는 소수인가요, 합성수인가요?

(2)1은 소수인가요, 합성수인가요, 둘 다 아닌가요?

(3)27은 소수인가요, 합성수인가요?

심화도전

(4)90보다 크고 100보다 작은 자연수 중에서 소수는 모두 몇 개인가요?

개
2거듭제곱 표기와 계산
기본기본

aⁿ = a를 n번 곱한 것. 지수는 곱하는 횟수예요.

(1)3³은 얼마?

(2)3⁴와 4³ 중 어느 것이 더 큰가요?

(3)10⁵은 얼마?

심화도전

(4)2⁶과 6²의 차이는 얼마인가요?

3소인수분해 실행
공식보통

작은 소수부터 나눠요. 결과는 오름차순 + 거듭제곱으로.

(1)60을 소인수분해하면? (예: 2²×3×5 꼴로)

(2)48 = 6×8은 소인수분해로 올바른가요?

(3)72를 소인수분해하면? (예: 2³×3² 꼴로)

심화도전

(4)90을 소인수분해했을 때, 서로 다른 소인수의 합은 얼마인가요?

4약수의 개수
공식보통

pᵃ×qᵇ의 약수 개수 = (a+1)(b+1). 지수에 1을 더하는 걸 잊지 마요.

(1)2⁴의 약수는 몇 개?

개

(2)2²×3의 약수는 몇 개?

개

(3)2³×5의 약수는 몇 개?

개
왜?(3+1)×(1+1)=8.

5최대공약수
공식보통

공통 소인수를 작은 지수로 곱해요. 최대공약수 1이면 서로소.

(1)36과 48의 최대공약수는?

(2)2³×5²과 2²×5의 최대공약수는?

(3)15와 28은 서로소인가요?

심화도전

(4)세 수 44, 66, 110의 최대공약수는?

6최소공배수
공식보통

모든 소인수를 큰 지수로 곱해요. 한쪽에만 있는 소인수도 빠뜨리지 않아요.
