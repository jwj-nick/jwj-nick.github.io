유형별 연습 — 일차방정식

방정식·항등식 판별부터 활용 문제까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

특별한 안내가 없으면 숫자만 답해요.

푼 문제: 0 / 28

1방정식 / 항등식 판별
기본기본

특정 값에서만 참이면 방정식, 모든 값에서 참이면 항등식이에요.

(1)x + 2 = 5는 방정식인가요, 항등식인가요?

(2)3(x − 1) = 3x − 3은 방정식인가요, 항등식인가요?

(3)ax + 7 = 3x + b가 항등식이 되려면 a의 값은?

(4)3(2x − a) = bx − 15가 x에 대한 항등식일 때, a − b의 값은?

양변에 같은 수를 더하거나 빼거나 곱하거나(0 제외) 나눠도 등식은 그대로예요.

(1)a = b일 때, a + 9 = b + 9는 항상 성립하나요?

(2)x − 6 = 11에서 x만 남기려면 양변에 무엇을 더해야 하나요?

(3)5x = 35의 양변을 5로 나누면 x는?

(4)a = b일 때, 3a − 5 = 3b + k가 항상 성립하도록 하는 k의 값은?

4괄호·분수·소수 계수 방정식
핵심보통

괄호는 분배법칙으로, 분수·소수는 정수로 바꿔서 풀어요.

(1)3(x − 2) = 9의 해는?

(2)x/2 + 1 = 4의 해는?

(3)0.2x + 0.4 = 1의 해는?

(4)(x − 1)/2 − (x − 4)/3 = 1의 해는?

(1)3x + a = 11의 해가 x = 3일 때, a의 값은?

(2)ax − 4 = 8의 해가 x = 4일 때, a의 값은?

(3)2x + 5 = a의 해가 x = 6일 때, a의 값은?

(4)3x + a = 2a − x의 해가 x = 5일 때, a의 값은?

6일차방정식의 활용 (수·나이·도형)
종합보통

무엇을 x로 놓을지 먼저 정하고, 문제가 진짜 묻는 값이 x와 같은지 마지막에 확인해요.

(1)연속하는 두 자연수의 합이 25일 때, 두 수 중 작은 수는?

(2)현재 아버지 나이는 딸 나이의 3배이고, 두 사람 나이의 합이 52살일 때 딸의 나이는?

살

(3)세로가 x cm인 직사각형의 가로가 세로보다 4cm 길고, 둘레가 28cm일 때 가로의 길이는?

cm

(4)현재 삼촌의 나이는 조카 나이의 6배입니다. 10년 후에는 삼촌의 나이가 조카 나이의 3배보다 4살 많아진다고 해요. 현재 조카의 나이는?

심화도전
살
7일차방정식의 활용 (거리·속력·시간·농도)
종합보통

거리=속력×시간, 소금의 양=농도×소금물의 양÷100. 단위를 통일해요.

(1)시속 4km로 걷다가 시속 6km로 뛰어서 총 5km를 1시간 만에 갔을 때, 걸은 거리는?

km

(2)농도 8%인 소금물 250g에 물을 더 넣어 농도를 5%로 만들려면 물을 몇 g 더 넣어야 할까요?

g

(3)A는 시속 60km, B는 시속 40km로 같은 지점에서 반대 방향으로 동시에 출발했을 때, 200km 떨어지는 데 걸리는 시간은?

시간
