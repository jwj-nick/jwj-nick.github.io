유형별 연습 — 입체도형의 겉넓이와 부피

각기둥부터 복합 입체까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

π가 들어간 답은 계수만 입력해요 (예: 10π는 10으로).

푼 문제: 0 / 28

1각기둥의 겉넓이·부피
기본기본

부피 = 밑넓이×높이. 겉넓이 = 2×밑넓이 + (밑면 둘레×높이).

(1)가로 4cm, 세로 5cm, 높이 3cm인 직육면체의 부피는?

cm³

(2)한 모서리 4cm인 정육면체의 겉넓이는?

cm²

(3)밑넓이 12cm², 옆넓이 40cm²인 각기둥의 겉넓이는?

cm²
심화도전

(4)밑면이 한 변 5cm인 정사각형인 사각기둥의 겉넓이가 210cm²일 때, 이 사각기둥의 부피는?

cm³
왜?밑넓이=5×5=25, 옆넓이=210−2×25=160, 밑면 둘레=20이므로 높이=160÷20=8, 부피=25×8=200.
2각뿔의 겉넓이·부피 (★ 1／3)
핵심보통

부피 = (1／3)×밑넓이×높이. 겉넓이 = 밑넓이(1개) + 옆넓이.

(1)밑넓이 18cm², 높이 6cm인 각뿔의 부피는?

cm³

(2)밑넓이 9cm², 옆넓이 24cm²인 각뿔의 겉넓이는?

cm²

(3)밑면이 한 변 6cm인 정사각형, 높이가 4cm인 사각뿔의 부피는?

cm³
왜?밑넓이=6×6=36, (1/3)×36×4=48.
심화도전

(4)밑면이 한 변 3cm인 정사각형이고 부피가 27cm³인 사각뿔의 높이는?

cm
왜?밑넓이=3×3=9, 27=(1/3)×9×h → 3h=27 → h=9.
3원기둥의 겉넓이·부피
공식보통

부피 = πr²h. 겉넓이 = 2πr² + 2πrh.

(1)반지름 3cm, 높이 5cm인 원기둥의 부피는? (계수만)

π cm³

(2)반지름 4cm, 높이 6cm인 원기둥의 옆넓이는? (계수만)

π cm²

(3)반지름 2cm, 높이 5cm인 원기둥의 겉넓이는? (계수만)

π cm²
왜?2π×2²+2π×2×5=8π+20π=28π.
심화도전

(4)밑면의 반지름이 4cm인 원기둥의 겉넓이가 88π cm²일 때, 이 원기둥의 부피는? (계수만)

π cm³
왜?밑넓이=π×4²=16π, 옆넓이=88π−2×16π=56π, 밑면 둘레=2π×4=8π이므로 높이=56π÷8π=7, 부피=π×16×7=112π.
4원뿔의 겉넓이·부피 (★ h vs l)
핵심보통

부피엔 높이 h, 겉넓이(옆면)엔 모선 l. 겉넓이 = πr² + πrl.

(1)반지름 3cm, 높이 4cm인 원뿔의 부피는? (계수만)

π cm³

(2)반지름 3cm, 모선 5cm인 원뿔의 옆넓이는? (계수만)

π cm²

(3)반지름 3cm, 높이 4cm, 모선 5cm인 원뿔의 겉넓이는? (계수만)

π cm²
왜?π×3²+π×3×5=9π+15π=24π (높이 4는 안 씀).
심화도전

(4)밑면의 반지름이 5cm인 원뿔의 부피가 100π cm³일 때, 이 원뿔의 겉넓이는? (계수만)

π cm²
왜?100π=(1/3)×π×25×h → h=12. 모선 l=√(5²+12²)=13. 겉넓이=π×5²+π×5×13=25π+65π=90π.
5구의 겉넓이·부피
공식보통

겉넓이 = 4πr². 부피 = (4／3)πr³. 반구 부피 = 구의 절반, 반구 겉넓이 = 곡면+평면원.

(1)반지름 3cm인 구의 겉넓이는? (계수만)

π cm²

(2)반지름 6cm인 구의 부피는? (계수만)

π cm³

(3)반지름 3cm인 반구의 부피는? (계수만)

π cm³
심화도전

(4)겉넓이(곡면+평면)가 243π cm²인 반구의 부피는? (계수만)

π cm³
왜?3πr²=243π → r²=81 → r=9. 구의 부피=(4/3)π×729=972π, 반구는 절반이므로 486π.
6회전체의 부피 (단원 11 연계)
종합보통

회전축을 확인하고, r과 h를 정확히 읽은 뒤 원기둥·원뿔·구 공식을 그대로 적용해요.

(1)가로 3cm, 세로 4cm인 직사각형을 세로변을 축으로 1회전시키면 생기는 원기둥의 부피는? (계수만)

π cm³

(2)밑변 3cm, 높이 4cm인 직각삼각형의 직각을 낀 변을 축으로 1회전시키면 생기는 원뿔의 부피는? (계수만)

π cm³

(3)반지름 3cm인 반원을 지름을 축으로 1회전시키면 생기는 구의 부피는? (계수만)

π cm³
심화도전

(4)가로 2cm, 세로 5cm인 직사각형 위에 밑변 2cm, 높이 6cm인 직각삼각형을 반지름이 같도록 포개어 만든 오각형이 있어요. 이 오각형을 세로변을 축으로 1회전시키면 원기둥과 원뿔이 결합된 입체가 생겨요. 이 입체 전체의 부피는? (계수만)

π cm³
왜?원기둥(r=2,h=5) 부피=π×4×5=20π, 원뿔(r=2,h=6) 부피=(1/3)×π×4×6=8π. 합=20π+8π=28π.
7복합 입체 (★)
종합보통

복합 입체는 단순 입체의 합·차로 나눠요. 맞닿은 면은 겉넓이에서 빼요.

(1)반지름 3cm, 높이 6cm인 원기둥 안에 반지름 3cm인 구가 꼭 맞게 들어있을 때, 구를 뺀 나머지 부분의 부피는? (계수만)

π cm³
왜?원기둥(π×9×6=54π) − 구((4/3)π×27=36π)=18π.

(2)반지름 r, 높이 2r인 원기둥 안에 원뿔과 구가 꼭 맞게 들어있을 때, 원뿔:구:원기둥의 부피 비는?

(3)겉넓이 각각 24π cm², 18π cm²인 두 입체를 넓이 4π cm²인 면끼리 붙이면 겉넓이는? (계수만)

π cm²
왜?24π+18π−2×4π=34π (맞닿은 면 2개는 겉에서 안 보임).
심화도전

(4)밑면의 반지름이 6cm인 원뿔(높이 4cm) 위에 반지름 6cm인 반구를 얹어 만든 아이스크림콘 모양 입체의 부피는? (계수만)

π cm³
왜?원뿔 부피=(1/3)×π×36×4=48π, 반구 부피=(2/3)×π×216=144π. 합=48π+144π=192π.
✓
입체도형의 겉넓이와 부피 7가지 유형을 마쳤어요
