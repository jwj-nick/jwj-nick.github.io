유형별 연습 — 좌표와 그래프

순서쌍과 좌표부터 그래프 해석까지, 시험에 나오는 7가지 유형을 하나씩 다뤄 볼까요?

사분면은 번호만(1~4), 축 위의 점은 0으로 답해요.

푼 문제: 0 / 28

1순서쌍과 좌표
기본기본

순서쌍은 (x좌표, y좌표) 순서. 순서를 바꾸면 다른 점이에요.

(1)점 A(3, −5)의 x좌표는?

(2)원점에서 왼쪽으로 4, 아래로 2만큼 간 점의 좌표는? (예: (2,3) 꼴로)

(3)점 (5, 2)와 점 (2, 5)는 같은 점인가요, 다른 점인가요?

(4)원점에서 오른쪽으로 7, 위로 3만큼 이동한 뒤, 다시 왼쪽으로 10, 아래로 8만큼 이동했다면 최종 위치의 좌표는? (예: (2,3) 꼴로)

2사분면 판별 (수치 좌표)
기본기본

x, y의 부호 조합으로 사분면이 정해져요. 축 위의 점은 0으로 답해요.

(1)점 (−3, 5)는 몇 사분면 위의 점인가요?

(2)점 (4, −6)은 몇 사분면 위의 점인가요?

(3)점 (0, 8)은 몇 사분면 위의 점인가요? (사분면이 아니면 0으로 답)

심화도전

(4)점 (3−7, (−2)×4)는 몇 사분면 위의 점인가요?

3사분면 판별 (문자 부호 조건)
핵심보통

−a는 "음수"가 아니라 "a의 부호를 반대로"라는 뜻이에요.

(1)a > 0, b < 0일 때 점 (a, b)는 몇 사분면 위의 점인가요?

(2)a < 0, b > 0일 때 점 (a, b)는 몇 사분면 위의 점인가요?

(3)a > 0이고 −a < 0일 때, 점 (a, −a)는 몇 사분면 위의 점인가요?

심화도전

(4)ab < 0이고 a < b일 때, 점 (a, b)는 몇 사분면 위의 점인가요?

(2)네 점 (0,0), (5,0), (5,3), (0,3)을 꼭짓점으로 하는 직사각형의 넓이는?

(3)두 점 (2, 3)과 (2, −4) 사이의 거리는?

(4)세 점 (−2, −3), (4, −3), (−2, 5)를 꼭짓점으로 하는 삼각형의 넓이는?

5그래프 읽기 — 변량의 변화
핵심보통

어떤 물통에 물을 받는 상황이에요 — 0~4분엔 빠르게, 4~6분엔 멈춤(평평), 6~10분엔 느리게 물의 높이가 늘어요(0분에 0cm, 4분에 16cm, 6분에도 16cm, 10분에 18cm).

(1)3분일 때 물의 높이는 몇 cm인가요?

cm

(2)4분부터 6분 사이에는 무슨 일이 있었을까요?

(3)물의 높이가 더 빠르게 늘어난 구간은 0~4분과 6~10분 중 어느 쪽인가요?

심화도전

(4)0~4분과 6~10분 중, 물의 높이가 늘어난 양(cm)의 차이는 얼마인가요?

cm

(1)자전거를 타다가 신호등에 걸려 잠깐 멈췄다가 다시 달린 상황의 시간-거리 그래프는 A, B, C 중 어느 것에 가장 가까울까요?

(3)뜨거운 물이 식으면서 처음엔 빠르게 온도가 떨어지다가 점점 천천히 떨어지는 시간-온도 그래프는 A, B, C 중 어느 것에 가까울까요?

(4)세 친구가 그래프 모양 A, B, C 중 하나에 해당하는 자신의 이동 상황을 설명했어요. ① 민준: "처음엔 천천히 움직이다가 점점 더 빨라졌어요." ② 서연: "달리다가 신호에 걸려 잠깐 멈췄다가 다시 달렸어요." ③ 태호: "내내 같은 빠르기로 움직였어요." 이 중 A, B, C 어디에도 맞지 않는 설명을 한 사람은 누구인가요?
