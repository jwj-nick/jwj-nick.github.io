중2-1단원 2

식의 계산

문자가 든 식도 숫자처럼 — 특히 '거듭제곱(power)'엔 규칙이 있어요.

1이어서

작년에 이미 절반은 했어요

작년에 동류항(like terms)을 모으는 걸 배웠죠. 2x + 3x = 5x — 같은 문자 x끼리, 앞의 수(계수, coefficient)만 더한 거예요. x가 몇 개 있느냐를 센 거죠.

4a + 2a는 □a — □에 들어갈 수는?

올해는 여기서 한 걸음 더 — x를 여러 번 곱한 것, 즉 지수(exponent)를 다뤄요. 더하기가 아니라 곱하기 이야기예요.

2왜 궁금하냐면

종이를 42번 접으면 달에 닿아요

종이 한 장을 반으로 접으면 2겹. 또 접으면 4겹, 8겹, 16겹… 접을 때마다 2배가 돼요.

믿기 어렵지만, 이렇게 42번만 접으면 그 두께가 달까지 닿아요. 2를 42번 곱한 수(242)가 그만큼 어마어마하거든요.

접은 횟수 10번

같은 수를 여러 번 곱한 걸 짧게 쓴 게 바로 지수예요. 그럼 a3 × a2는 어떻게 될까요? 직접 움직여 봐요.

3직접 움직여 봐요

지수를 손으로 바꿔보기

a3 × a2 = a5

블록 한 칸이 a 하나예요. 앞의 a3과 뒤의 블록을 이어 붙이면, 결국 a를 죽 늘어놓은 것 — 그래서 지수를 더해요.

4내 말로

이제 직접 설명할 차례예요

움직여 봤으니 알 거예요. 정답 맞히기가 아니라, 직접 이해한 걸 꺼내보는 거예요.

같은 수의 거듭제곱을 곱할 때는 지수를 해요.

더해요. am × an = am+n. a를 m번, 또 n번 곱하면 결국 (m+n)번 곱한 거니까요.

설명이 이거랑 똑같을 필요는 없어요. 자기 말로 설명하면 돼요.

5규칙 넓히기

지수법칙 네 가지

곱셈 규칙(지수 더하기)을 알았으니, 나머지도 같은 원리에서 자연스럽게 나와요.

① 곱셈 — am × an = am+n (이어 곱하니 더함)

② 거듭제곱의 거듭제곱 — (am)n = amn (m번 묶음을 n번 반복 → 곱함)

③ 나눗셈 — am ÷ an = am−n (반대로 빼기, m > n)

④ 곱의 거듭제곱 — (ab)n = anbn (안의 것 각각 제곱)

규칙 ②로 (a2)3 = a□ — □는?
6식끼리 계산

계수는 계수끼리, 문자는 문자끼리

단항식(항이 하나)을 곱하거나 나눌 땐, 계수는 계수끼리 계산하고 같은 문자는 지수법칙으로 다뤄요. 예: 2a × 3a2 = 6a3.

다항식(항이 여러 개)의 덧셈·뺄셈은 작년처럼 동류항끼리 모으고, 괄호 앞에 수가 있으면 분배법칙으로 각 항에 곱해요. 예: 2(3x + 4) = 6x + 8.

(2x + 3) + (4x − 1) 을 정리하면 □x + 2 — □는?
7수를 넣어보기

식의 값 — 문자 자리에 수를 대입

식은 결국 "수를 넣으면 값이 나오는 틀"이에요. 문자 자리에 주어진 수를 그대로 넣는 것을 대입(substitution)이라고 해요.

예: 2a + 1 에 a = 3 을 넣으면 2×3 + 1 = 7. 음수를 넣을 땐 괄호로 감싸서 넣어야 부호 실수를 안 해요 — a = −2 면 2×(−2) + 1 = −3.

a = 3 일 때 2a + 1 의 값은?
8직접 문제 내보기

출제자가 되어보기

문제를 만드는 사람이 되면 이해가 굳어져요. 지수를 직접 정해 봐요.

a를 번 곱하고, 또 번 곱하면?

내 문제: a3 × a2 = a?
지수를 직접 맞혀 봐요 — a의 몇 제곱?

방금 직접 문제를 만들고, 직접 풀었어요. 이게 진짜 이해예요.
