세계 최고의 실험실에서 직접 만져보기

여긴 콜로라도대학교가 만든 무료 수학 시뮬레이션(PhET)이에요. 슬라이더를 밀고 선을 끌면서, 일차함수가 어떻게 움직이는지 손으로 발견해 볼까요?

채점하는 문제는 없어요. 아래 질문을 마음에 품고, 직접 움직여 보면서 답을 찾아보세요.

📱 가로로 돌리면 훨씬 잘 보여요. 잘 안 보이면 “전체화면으로 열기”를 눌러요.
1기울기와 절편

그래프 기울기-절편

Graphing Slope-Intercept 딱 맞아요

y = ax + b에서 a(기울기)와 b(y절편)를 밀어 보면, 선이 어떻게 가팔라지고 어디서 세로축을 지나는지 한눈에 보여요.

  • a를 크게 하면 선은 더 가팔라질까요, 완만해질까요?
  • a를 음수로 만들면 선의 방향은 어떻게 바뀌나요?
  • b만 바꾸면 선이 세로축과 만나는 곳이 어디로 가나요?

2선을 거꾸로 끌어보기

그래프에 선 그리기

Graphing Lines 딱 맞아요

이번엔 선을 직접 끌어 보세요. 선을 움직이면 식이 저절로 바뀌어요. x절편, 두 점, 그리고 마지막엔 식만 보고 선을 맞히는 게임까지 있어요.

  • 선을 끌면 y = ax + b의 숫자가 어떻게 따라 바뀌나요?
  • 선이 가로축과 만나는 곳(x절편)은 어디인가요?
  • “선 맞히기” 게임에서 식만 보고 선을 그려볼까요?

3함수가 뭔지 감 잡기

함수 제조기

Function Builder 가볍게

숫자를 기계에 넣으면 규칙대로 바뀐 값이 나와요. 넣는 값(x)과 나오는 값(y)이 짝을 이루는 것 — 이게 바로 함수예요.

  • 같은 수를 넣으면 항상 같은 값이 나오나요?
  • 기계 규칙을 “×2 그리고 +1”로 바꾸면 y = 2x + 1과 같아질까요?
