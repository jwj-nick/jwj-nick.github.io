⚖️ 부등식 방향 감각

"−2x < 6을 풀면 x < −3? 아니면 x > −3?" 여기서 매번 멈칫했다면, 그건 실력이 아니라 규칙을 그림 없이 외웠기 때문이에요. 일차부등식 단원 전체는 딱 한 가지 위에 서 있어요 — 음수를 곱하거나 나누면 부등호 방향이 뒤집혀요. 왜 그런지 수직선에서 한 번 눈으로 보고 나면, 다시는 안 헷갈려요.

① 부등식의 성질② 일차부등식 풀기③ 분수·소수 계수④ 수직선에 나타내기⑤ 자연수 해 · 활용
1수직선에서 감 잡기 (규칙 없이)

수직선 위에 두 점 A, B를 놓아요. 왼쪽에 있는 수가 더 작으니까, 처음엔 A < B예요. 이제 양변에 똑같은 일을 해 볼게요 — 더하기, 빼기, 양수 곱하기, 음수 곱하기. 넷 중에 순서가 바뀌는 건 딱 하나예요. 무엇을 할지 고르고 ▶ 재생을 눌러 점이 어떻게 움직이는지 보세요.

점 A1
점 B4
수 c2

음수를 곱하는 건 0을 거울 삼아 반대편으로 보내는 일이에요. 거울에 비추면 왼쪽에 있던 점이 오른쪽으로 가니까, 작던 수가 커져요. 그래서 순서가 뒤집혀요. 더하기·빼기는 둘 다 같은 방향으로 밀기, 양수 곱하기는 0에서 멀어지게 늘리기라서 순서는 그대로예요.

함께 생각하기 ①

a < b 일 때, −3a와 −3b 사이에는 어떤 부등호가 들어갈까요? (a = 1, b = 2를 넣어 보면서 생각해도 좋아요.)

2부등식의 성질 — 외우는 규칙이 아니라 관찰의 요약

방금 수직선에서 본 것을 문장으로 적으면 교과서의 "부등식의 성질" 네 개가 돼요. a < b에서 출발해요.

a + c < b + c같은 수 더하기 → 그대로
a − c < b − c같은 수 빼기 → 그대로
c > 0 이면 ac < bc양수 곱하기·나누기 → 그대로
c < 0 이면 ac > bc음수 곱하기·나누기 → 뒤집혀요
⚠ 가장 흔한 실수 — −2x < 6의 해를 x < −3이라고 쓰는 거예요. 양변을 −2로 나누는 순간 음수로 나눴으니까 부등호를 뒤집어야 해요 → x > −3. 헷갈리면 숫자를 하나 넣어서 확인해요. 아래 슬라이더로 x를 골라 보세요.

3핵심 도구 — 풀이 단계 위젯

일차부등식은 방정식과 똑같이 풀어요. 이항 → 정리 → x의 계수로 나누기. 딱 한 군데, 나누는 수가 음수일 때만 부등호를 뒤집어요. 👉 버튼으로 한 단계씩 진행해 보세요. 뒤집히는 순간이 눈에 보여요.

⚖️불변 앵커 — 뒤집는 순간은 딱 하나, 음수로 곱하거나 나눌 때뿐이에요. 더하기·빼기·이항에서는 절대 안 바뀌어요. 이항은 "양변에 같은 수를 더하거나 빼는 것"이라서, −3x를 반대쪽으로 옮긴다고 부등호가 뒤집히지 않아요. 그리고 답을 쓰고 나면 숫자 하나를 넣어서 확인해요.

수직선에 나타낼 때는 두 가지만 봐요. 등호가 있으면(≤, ≥) 경계점을 채운 점 ●, 없으면(<, >) 빈 점 ○. 그리고 >, ≥는 오른쪽, <, ≤는 왼쪽으로 색칠해요.

4유형별 완전정복

이제 진짜 문제로 가요. 5가지 유형만 알면 03단원은 다 풀려요 — 부등식 → 단계 → 풀이 순서예요. 각 유형의 👉 버튼으로 이항·정리까지는 먼저 보여 드리고, 나누기부터는 직접 풀어 본 뒤에 열려요. 답은 확인 전까지 안 보여 줘요.

①
부등식의 성질
무엇을 곱했는지만 보면 돼요
핵심 a < b에서 출발해 양변에 한 일을 순서대로 따라가요. 음수를 곱하거나 나눈 순간에만 뒤집혀요. 등호(≤, ≥)는 뒤집혀도 등호로 남아요.
②
일차부등식 풀기
이항 → 정리 → 나누기 (음수면 뒤집기)
핵심 정리했을 때 x의 계수가 음수면, 그때가 뒤집는 순간이에요. 답을 쓰고 나서 숫자 하나를 넣어 확인해요.
③
분수·소수 계수
먼저 분모를 없애요
핵심 분모의 최소공배수(소수는 10, 100)를 양변에 곱해요. 양수를 곱하니까 부등호는 그대로예요. 그다음은 ②와 똑같아요.
④
수직선에 나타내기
● 인지 ○ 인지 · 오른쪽인지 왼쪽인지
핵심 등호가 있으면 ●, 없으면 ○. >, ≥는 오른쪽, <, ≤는 왼쪽. 그림을 고르기 전에 먼저 해를 x □ 수 꼴로 적어요.
⑤
자연수 해 · 활용
풀고 나서 정수를 세어요
핵심 부등식을 세우고 풀어서 x의 범위를 구한 뒤, 그 안의 자연수를 직접 세어요. "최대"는 내림, "이상"은 올림이에요. 경계값이 소수여도 당황하지 않아요.
5실전 총정리 — 유형 섞어서

이번엔 어떤 유형인지 안 알려드려요. 나누는 수의 부호를 먼저 보고 풀어 봐요. 틀리면 어느 유형인지 알려드릴게요. 부등호는 고르고, 경계값은 숫자로 적어요.
