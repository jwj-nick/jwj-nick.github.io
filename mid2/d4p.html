중2-1단원 4심화 문제

도전 — 두 조건을 세워서 풀기

문장에서 식 두 개를 뽑아내는 게 절반이에요. 대입법으로 풀고 과정을 글로 적어 보세요.

각 문제에 단계별 힌트와 풀이 보기가 있어요. 먼저 두 식을 세워 보고, 막히면 열어요.

도전 1 · 실생활

동생이 집에서 분속 50m로 걸어 나갔어요. 5분 뒤, 형이 분속 75m로 같은 길을 따라 출발했죠.

형이 출발한 지 몇 분 뒤에 동생을 따라잡을까요? (형 출발 시각을 0분으로 둬요)
형이 출발 후 t = 분
힌트 1동생은 5분 먼저 갔으니 형 출발 시점에 이미 50×5 = 250m 앞. 형 출발 후 t분이면 동생 위치 = 250 + 50t.
힌트 2형의 위치 = 75t. 따라잡는 순간 두 위치가 같아요: 75t = 250 + 50t.
힌트 375t − 50t = 250 → 25t = 250 → t = 10.

✓ 풀이

  1. 형 출발 시점, 동생은 50×5 = 250m 앞서 있음
  2. 형 출발 t분 후 — 동생: 250 + 50t, 형: 75t
  3. 따라잡음 ⇔ 75t = 250 + 50t → 25t = 250 → t = 10
  4. ∴ 형이 출발한 지 10분 뒤 (검산: 형 750m, 동생 250+500=750m ✓)
도전 2 · 복합

대입법으로 정확히 풀고, 매 단계 무엇을 어디에 대입했는지 글로 설명해 보세요.

2x + y = 12　…①
x − y = 3　…②
x = y =
힌트 1②를 정리: x = y + 3.
힌트 2①의 x 자리에 (y+3) 대입: 2(y+3) + y = 12.
힌트 32y + 6 + y = 12 → 3y = 6 → y = 2, 그리고 x = 2+3 = 5.

✓ 풀이

  1. ②를 x에 대해 정리: x = y + 3
  2. ①의 x 자리에 대입: 2(y + 3) + y = 12
  3. 괄호 풀고 정리: 3y + 6 = 12 → y = 2
  4. 다시 대입: x = 2 + 3 = 5 → 답 (5, 2)
도전 3 · 실생활

문구점에서 공책과 펜을 샀어요.

공책 1권 1000원, 펜 1자루 500원. 공책을 펜보다 2개 더 샀고(공책 = 펜 + 2), 총액은 8000원. 공책과 펜을 각각 몇 개 샀을까요?
공책 =권 펜 =자루
힌트 1공책 x, 펜 y → 1000x + 500y = 8000, x = y + 2.
힌트 2대입: 1000(y+2) + 500y = 8000 → 1500y + 2000 = 8000.
힌트 31500y = 6000 → y = 4, x = 4+2 = 6.

✓ 풀이

  1. 공책 x, 펜 y: 1000x + 500y = 8000, x = y + 2
  2. 대입: 1000(y+2) + 500y = 8000
  3. 1500y + 2000 = 8000 → 1500y = 6000 → y = 4
  4. x = 6 → 공책 6권, 펜 4자루 (검산: 6000+2000 = 8000 ✓)
도전 4 · 특수한 해

연립방정식이 해가 무수히 많다는 건, 두 식이 사실 같은 직선이라는 뜻이에요.

연립방정식 [ 2x + y = 5, 4x + 2y = k ] 의 해가 무수히 많으려면 상수 k는?
k =
힌트 1둘째 식 4x + 2y 는 첫째 식 2x + y 의 2배예요.
힌트 2그러니 우변도 2배여야 완전히 같은 식: k = 2 × 5.
힌트 3k = 10 이면 둘째 식이 4x+2y=10 = 첫째 식의 2배 → 완전히 포개져요.

✓ 풀이

  1. 4x + 2y = 2(2x + y) 이므로 첫째 식의 2배
  2. 완전히 같은 직선이 되려면 우변도 2배: k = 2 × 5 = 10

만약 k ≠ 10 이면 두 직선이 평행해서 해가 없어요. 딱 k=10 일 때만 무수히 많아요.

도전 5 · 공통해·문자계수

먼저 두 식의 공통해를 구한 뒤, 그 해가 또 다른 식도 만족한다는 조건으로 상수를 찾아요.

연립방정식 [ 3x − y = 7, x + y = 5 ] 의 해가 2x + ay = 8 도 만족할 때, 상수 a는?
a =
힌트 1두 식을 더하면 4x = 12 → x = 3, y = 2. 공통해 (3, 2).
힌트 2이 해를 2x + ay = 8 에 대입: 2×3 + a×2 = 8.
힌트 36 + 2a = 8 → 2a = 2 → a = 1.

✓ 풀이

  1. 공통해: 3x − y = 7 과 x + y = 5 를 더하면 4x = 12 → x = 3, y = 2
  2. 세 번째 식에 대입: 2×3 + a×2 = 8 → 6 + 2a = 8
  3. 2a = 2 → a = 1

공통해를 먼저 구하는 게 핵심이에요. 그 뒤엔 상수 하나짜리 일차방정식일 뿐이에요.

도전 6 · 농도(섞기)

과학 실험에서 소금물을 섞어요.

5% 소금물 x g과 10% 소금물 y g을 섞어 8% 소금물 500g을 만들려고 해요. 각각 몇 g씩 필요할까요?
5% 소금물 x =g
10% 소금물 y =g
힌트 1전체 양: x + y = 500. 소금 양: 0.05x + 0.10y = 0.08×500 = 40.
힌트 2둘째 식 ×100 → 5x + 10y = 4000 → ÷5 → x + 2y = 800.
힌트 3x + 2y = 800 에서 x + y = 500 을 빼면 y = 300, x = 200.

✓ 풀이

  1. 전체 양: x + y = 500
  2. 소금 양: 0.05x + 0.10y = 40 → x + 2y = 800
  3. 두 식을 빼면 y = 300, x = 200
  4. ∴ 5% 소금물 200g, 10% 소금물 300g (검산: 소금 10+30 = 40g ✓)

농도 문제는 "전체 양"과 "녹아 있는 소금 양" 두 가지로 식을 세우면 늘 풀려요.

✓
연립방정식 심화를 마쳤어요
특수해·공통해·농도까지 풀었어요.
