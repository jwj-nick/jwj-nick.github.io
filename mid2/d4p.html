중2-1단원 4심화 문제

도전 — 두 조건을 세워서 풀기

문장에서 식 두 개를 뽑아내는 게 절반이야. 대입법으로 풀고 과정을 글로 적어봐.

각 도전엔 단계별 힌트와 풀이 전체 보기가 있어. 먼저 두 식을 세워봐.

도전 1 · 실생활

동생이 집에서 분속 50m로 걸어 나갔어. 5분 뒤, 형이 분속 75m로 같은 길을 따라 출발했지.

형이 출발한 지 몇 분 뒤에 동생을 따라잡을까? (형 출발 시각을 0분으로 두자)
형이 출발 후 t = 분
힌트 1동생은 5분 먼저 갔으니 형 출발 시점에 이미 50×5 = 250m 앞. 형 출발 후 t분이면 동생 위치 = 250 + 50t.
힌트 2형의 위치 = 75t. 따라잡는 순간 두 위치가 같아: 75t = 250 + 50t.
힌트 375t − 50t = 250 → 25t = 250 → t = 10.

✓ 풀이

  1. 형 출발 시점, 동생은 50×5 = 250m 앞서 있음
  2. 형 출발 t분 후 — 동생: 250 + 50t, 형: 75t
  3. 따라잡음 ⇔ 75t = 250 + 50t → 25t = 250 → t = 10
  4. ∴ 형이 출발한 지 10분 뒤 (검산: 형 750m, 동생 250+500=750m ✓)
도전 2 · 복합

대입법으로 정확히 풀고, 매 단계 무엇을 어디에 대입했는지 글로 설명해봐.

2x + y = 12　…①
x − y = 3　…②
x = y =
힌트 1②를 정리: x = y + 3.
힌트 2①의 x 자리에 (y+3) 대입: 2(y+3) + y = 12.
힌트 32y + 6 + y = 12 → 3y = 6 → y = 2, 그리고 x = 2+3 = 5.

✓ 풀이

  1. ②를 x에 대해 정리: x = y + 3
  2. ①의 x 자리에 대입: 2(y + 3) + y = 12
  3. 괄호 풀고 정리: 3y + 6 = 12 → y = 2
  4. 다시 대입: x = 2 + 3 = 5 → 답 (5, 2)
도전 3 · 실생활

문구점에서 공책과 펜을 샀어.

공책 1권 1000원, 펜 1자루 500원. 공책을 펜보다 2개 더 샀고(공책 = 펜 + 2), 총액은 8000원. 공책과 펜을 각각 몇 개 샀을까?
공책 =권 펜 =자루
힌트 1공책 x, 펜 y → 1000x + 500y = 8000, x = y + 2.
힌트 2대입: 1000(y+2) + 500y = 8000 → 1500y + 2000 = 8000.
힌트 31500y = 6000 → y = 4, x = 4+2 = 6.

✓ 풀이

  1. 공책 x, 펜 y: 1000x + 500y = 8000, x = y + 2
  2. 대입: 1000(y+2) + 500y = 8000
  3. 1500y + 2000 = 8000 → 1500y = 6000 → y = 4
  4. x = 6 → 공책 6권, 펜 4자루 (검산: 6000+2000 = 8000 ✓)
