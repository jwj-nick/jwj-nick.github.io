📈 기울기 완전정복

"두 점을 지나는 직선의 기울기를 구하시오." 여기서 어느 걸 어느 것으로 나누는지 헷갈리나요? 그럴 수 있어요 — 기울기는 공식이 아니라 "오른쪽으로 1칸 갈 때 몇 칸 오르나"라는 그림이에요. 계단부터 올라 보면서 시작해요.

① 두 점 → 기울기② 기울기 + 한 점 → 식③ 그래프 → 식④ 평행 · 절편⑤ 문장 → 변화율
1기울기가 뭔지 감 잡기 (공식 없이)

계단을 생각해 봐요. 한 칸 앞으로 갈 때마다 몇 칸 올라가느냐가 계단의 급한 정도예요. 슬라이더로 계단을 바꿔 보고 ▶ 재생을 눌러 올라가 보세요.

내리막 급함 ↑2

이번엔 좌표평면이에요. 두 점을 직접 끌어서 옮겨 보세요. 오른쪽으로 간 칸 수(x의 증가량)와 위로 오른 칸 수(y의 증가량)가 바로바로 바뀌어요.

점 B를 A보다 아래로 내려 보세요. y의 증가량이 음수가 되면서 기울기도 음수가 되죠? 그게 내리막이에요. 같은 높이에 두면 0 — 평평한 길이에요.

함께 생각하기 ①

두 점 (1, 3)과 (4, 9)를 지나는 직선이 있어요. 오른쪽으로 3칸 갈 때 위로 몇 칸 올랐을까요? 그러면 오른쪽으로 1칸당 몇 칸일까요? (그 수가 기울기예요.)

2공식은 외우는 게 아니라 읽는 것

방금 한 생각 "오른쪽으로 간 칸 수로 위로 오른 칸 수를 나눈다"를 그대로 식으로 쓰면 이렇게 돼요.

기울기 = (y의 증가량) ÷ (x의 증가량)위로 오른 칸 ÷ 오른쪽으로 간 칸 = 1칸당 오르는 칸
🚗 속력 특강에서 이 그림을 봤어요. 시간이 가로, 거리가 세로인 그래프에서 "1시간에 몇 km 가나"가 속력이었죠. 그게 바로 기울기예요 — 기울기는 속력의 친척이에요. 잊었으면 여기서 다시 봐요 → 속력·거리·시간 특강

부호도 그림으로 읽어요. 오른쪽으로 갈수록 올라가면 양수, 평평하면 0, 내려가면 음수예요.

"어느 두 점을 잡아야 해요?"라는 질문이 많아요. 답은 아무 두 점이나예요. 같은 직선 위라면 계단 삼각형의 크기만 다르고 모양은 똑같아서, 나누면 항상 같은 수가 나와요. 버튼을 눌러 확인해 보세요.

⚠ 가장 흔한 실수 — 뺄셈 순서예요. y는 (B − A)로 빼고 x는 (A − B)로 빼면 부호가 뒤집혀요. 두 좌표 모두 같은 순서(B − A)로 빼요. 그리고 나누는 건 언제나 y ÷ x, 거꾸로 x ÷ y가 아니에요.

함께 생각하기 ②

x의 값이 2에서 6까지 증가할 때 y의 값은 10에서 2까지 변했어요. 기울기는 얼마일까요? (y는 늘었나요, 줄었나요?)

3핵심 도구 — 식 읽기 + 변화량 표

일차함수의 식 y = ax + b에서 a가 기울기, b가 y절편(x = 0일 때의 y, 그래프가 y축과 만나는 높이)이에요. a와 b를 손으로 움직여 보면서 식·표·그래프가 함께 바뀌는 걸 보세요.

a 기울기2
b y절편1

두 점이 주어지는 문제는 전부 이 변화량 표로 정리해요. 아는 건 파란색, 구하는 건 입력칸이에요. 증가량은 언제나 (B − A)예요.

📈불변 앵커 — 기울기 = y의 증가량 ÷ x의 증가량. 뺄 때는 둘 다 같은 순서(B − A)로. 두 점 문제, 그래프 문제, 문장 문제 전부 결국 이 한 줄이에요. "오른쪽으로 1칸 갈 때 몇 칸 오르나"를 잊지 않으면 부호도 절대 안 틀려요.

연습을 몇 개 더 해볼까요? 매번 다른 점이에요.

4유형별 완전정복

이제 진짜 문제로 가요. 5가지 유형만 알면 다 풀려요 — 그림 → 표 → 식 → 풀이 순서예요. 각 유형의 "▶ 재생"을 눌러서 계단이 어떻게 생기는지 눈으로 먼저 확인해요.

①
두 점 → 기울기
변화량 표 한 번이면 끝
핵심 두 점을 표에 넣고 (B − A)로 증가량을 구한 다음, y의 증가량을 x의 증가량으로 나눠요. 분수가 나오면 약분까지.
②
기울기 + 한 점 → 식
a는 이미 있으니 b만 찾으면 돼요
핵심 y = ax + b에 기울기 a를 먼저 넣고, 지나는 점 (p, q)를 x, y 자리에 괄호로 넣으면 b가 나와요. b = q − a × p.
③
그래프 → 식
y축과 만나는 점 + 격자점 하나
핵심 그래프가 y축과 만나는 높이가 b예요. 거기서 격자점 하나까지 계단을 세면 a가 나와요. 오르막이면 +, 내리막이면 −.
④
평행 · 절편
평행 = 기울기가 같아요 · 절편 = 축과 만나는 곳
핵심 평행한 직선은 기울기가 같아요(b만 달라요). y절편은 x = 0을 넣고, x절편은 y = 0을 넣어서 구해요.
⑤
문장 → 변화율
물탱크 · 용수철 · 택시 · 양초
핵심 문장에서 처음 값이 b, 매번 변하는 양이 a예요. 줄어들면 a가 음수. 식 y = ax + b를 세우면 나머지는 대입이에요.
5실전 총정리 — 유형 섞어서

이번엔 어떤 유형인지 안 알려드려요. 문제를 읽고 "오른쪽으로 1칸 갈 때 몇 칸"을 먼저 생각해서 풀어봐요. 틀리면 어느 유형인지 알려드릴게요. 분수 답은 3/2처럼 써도 돼요.

6마무리 치트시트

📈 기울기 한 장 요약

기울기 = y의 증가량 ÷ x의 증가량오른쪽으로 1칸 갈 때 오르는 칸 수 · 두 좌표 모두 (B − A)로
부호오르막 + · 평평 0 · 내리막 −
y = ax + ba = 기울기 · b = y절편(x = 0일 때) · x절편은 y = 0 넣기
① 두 점변화량 표 → y증가량 ÷ x증가량
② 기울기 + 점b = q − a × p (점을 괄호로 대입)
③ 그래프y축 높이 = b · 격자점까지 계단 = a
④ 평행 · 절편평행 = 기울기 같음 · 절편 = 0 넣기
⑤ 문장처음 값 = b · 매번 변하는 양 = a (줄면 음수)
