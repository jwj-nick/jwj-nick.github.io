중2-1단원 1심화 문제

도전 — 순환소수의 비밀

답만 맞히는 게 아니라 이유를 글로 써보는 문제예요. 막히면 힌트를 한 칸씩 열어 보세요.

각 문제에 단계별 힌트와 풀이 보기가 있어요. 먼저 스스로 풀어 보고, 막히면 열어요.

도전 1 · 서술형

친구가 이렇게 우겨요. "0.999999… 는 1보다 아주 조금 작아!" 정말 그럴까요?

x = 0.999… 라고 두고, 이 x가 얼마인지 계산으로 밝혀서 친구를 설득해 볼까요?
계산해서: 9x = 9 라면 x = ?
힌트 1x = 0.999… 의 양변에 10을 곱하면 10x는 얼마가 될까요?
힌트 210x = 9.999… 이에요. 꼬리(0.999…)가 x랑 똑같죠? 그럼 10x − x 를 해 볼까요?
힌트 39.999… − 0.999… = 9. 그래서 9x = 9. 이제 x는?

✓ 풀이

  1. x = 0.999… 로 둬요.
  2. 양변 ×10 → 10x = 9.999…
  3. 아래에서 위를 빼기: 10x − x = 9.999… − 0.999… → 무한 꼬리가 서로 사라져 9x = 9
  4. ∴ x = 1

그러니까 0.999… = 1. "아주 조금 작은" 게 아니라 정확히 같아요. 둘 사이엔 어떤 수도 낄 수 없거든요. 친구가 틀렸어요 🙂

도전 2 · 복합

1/7 = 0.142857142857… — 여섯 자리 142857이 계속 반복돼요.

① 소수점 아래 100번째 자리 숫자는?
② 순환마디 142857 여섯 숫자를 모두 더하면?
① 100번째 자리 숫자:
② 여섯 숫자의 합:
힌트 1마디가 6자리니까, 자리 번호를 6으로 나눈 나머지가 마디 안에서 몇 번째인지 알려 줘요.
힌트 2100 ÷ 6 = 16 … 나머지 4. 그러니 마디의 4번째 숫자예요.
힌트 3마디 1·4·2·8·5·7 의 4번째 = 8. 합은 1+4+2+8+5+7.

✓ 풀이

  1. 마디 길이 = 6. 자리 번호를 6으로 나눈 나머지로 위치를 찾아요.
  2. 100 = 6 × 16 + 4 → 나머지 4 → 마디의 4번째 숫자.
  3. 142857 의 4번째 = 8. ∴ 100번째 자리 = 8
  4. ② 1+4+2+8+5+7 = 27

나머지가 0이면 마디의 마지막 숫자(6번째)라는 것만 조심하세요!

도전 3 · 복합

순환소수도 분수라는 걸 배웠죠. 이걸로 신기한 덧셈을 해 볼까요?

0.4̇5̇ = 0.454545… 와 0.5̇4̇ = 0.545454…
① 0.4̇5̇ 를 기약분수로 나타내면 □/11. □는?
② 두 수를 더하면 0.4̇5̇ + 0.5̇4̇ = ?
① 0.4̇5̇ = □/11 의 □:
② 두 수의 합:
힌트 12자리 순환마디 → 분모는 99. 0.4̇5̇ = 45/99. 약분해 볼까요?
힌트 245/99 = 5/11, 0.5̇4̇ = 54/99 = 6/11.
힌트 35/11 + 6/11 = 11/11 = 1. 소수로도 0.4545… + 0.5454… = 0.9999… = 1!

✓ 풀이

  1. 0.4̇5̇ = 45/99 = 5/11 (분자·분모 9로 약분)
  2. 0.5̇4̇ = 54/99 = 6/11
  3. 합: 5/11 + 6/11 = 11/11 = 1

도전 1과 이어지죠? 0.4545…+0.5454… 는 자리마다 4+5=9 → 0.9999… → 1. 순환소수가 분수라서 이런 딱 떨어지는 계산이 가능한 거예요.

도전 4 · 문자로 일반화

한 자리 순환소수는 규칙이 있어요 — 0.ȧ = a/9. 이 규칙을 거꾸로 써 볼까요?

① 한 자리 자연수 a에 대해 0.ȧ = 2/3 이 되는 a는?
② 0.1̇2̇ = 0.1212… 를 기약분수로 나타내면 분모는?
① a =
② 기약분수의 분모:
힌트 12/3 의 분모를 9로 맞춰 볼까요? 2/3 = □/9.
힌트 22/3 = 6/9 이니까 0.ȧ = 6/9 → a = 6.
힌트 3② 2자리 순환 → 0.1̇2̇ = 12/99. 12/99 를 3으로 약분하면?

✓ 풀이

  1. ① 0.ȧ = a/9 이고 2/3 = 6/9 이므로 a = 6. (확인: 0.6̇ = 2/3)
  2. ② 0.1̇2̇ = 12/99
  3. 12/99 = 4/33 (분자·분모 3으로 약분) → 분모 = 33

순환소수를 분수로 바꾸는 규칙(1자리→9, 2자리→99)만 알면, 문자든 숫자든 똑같이 다뤄요.

도전 5 · 대소와 계산

0.5̇ = 0.5555… 와 0.5 — 얼마나 다를까요? 끝없이 이어지는 쪽이 더 크다는 건 알겠는데, 얼마나 큰지 정확히 재 볼까요?

① 0.5̇ = □/9 의 □는?
② 0.5̇ − 0.5 를 기약분수로 하면 1/□. 분모 □는?
① 0.5̇ = □/9 의 □:
② 0.5̇ − 0.5 = 1/□ 의 □:
힌트 10.5̇ = 5/9, 0.5 = 1/2. 두 분수를 빼려면 분모를 맞춰야죠.
힌트 2분모를 18로: 5/9 = 10/18, 1/2 = 9/18.
힌트 310/18 − 9/18 = 1/18. 그래서 0.5̇ 가 0.5 보다 1/18 만큼 커요.

✓ 풀이

  1. ① 0.5̇ = 5/9 → □ = 5
  2. ② 0.5̇ − 0.5 = 5/9 − 1/2 = 10/18 − 9/18 = 1/18 → 분모 = 18

0.5̇ 가 0.5 보다 크긴 해도, 그 차이는 1/18 ≈ 0.0556 뿐이에요. 순환소수도 분수로 바꾸면 이렇게 정확히 잴 수 있어요.

도전 6 · 실생활·도형

직사각형 화단을 만들어요. 가로가 0.6̇ m, 세로가 0.75 m 예요.

① 이 화단의 넓이는 몇 m² 일까요? (소수로)
② 왜 딱 떨어지는지 분수로 설명해 보세요.
① 넓이(m²):
힌트 10.6̇ = 2/3, 0.75 = 3/4 로 바꿔 볼까요?
힌트 2넓이 = 가로 × 세로 = 2/3 × 3/4. 3이 위아래로 약분돼요.
힌트 32/3 × 3/4 = 6/12 = 1/2. 소수로는?

✓ 풀이

  1. 0.6̇ = 2/3, 0.75 = 3/4
  2. 넓이 = 2/3 × 3/4 = 6/12 = 1/2 = 0.5 m²

순환소수(가로)와 유한소수(세로)가 섞여도, 분수로 바꾸면 3이 약분되면서 깔끔하게 0.5 가 나와요.

✓
