중2-1단원 1심화 문제

도전 — 순환소수의 비밀

답만 맞히는 게 아니라 이유를 글로 써보는 문제야. 막히면 힌트를 한 칸씩 열어봐.

각 문제에 단계별 힌트와 풀이 보기가 있다. 먼저 스스로 풀고, 막히면 연다.

도전 1 · 서술형

친구가 이렇게 우겨. "0.999999… 는 1보다 아주 조금 작아!" 정말 그럴까?

x = 0.999… 라고 두고, 이 x가 얼마인지 계산으로 밝혀서 친구를 설득해봐.
계산해서: 9x = 9 라면 x = ?
힌트 1x = 0.999… 의 양변에 10을 곱하면 10x는 얼마가 될까?
힌트 210x = 9.999… 이야. 꼬리(0.999…)가 x랑 똑같지? 그럼 10x − x 를 해봐.
힌트 39.999… − 0.999… = 9. 그래서 9x = 9. 이제 x는?

✓ 풀이

  1. x = 0.999… 로 둔다.
  2. 양변 ×10 → 10x = 9.999…
  3. 아래에서 위를 빼기: 10x − x = 9.999… − 0.999… → 무한 꼬리가 서로 사라져 9x = 9
  4. ∴ x = 1

그러니까 0.999… = 1. "아주 조금 작은" 게 아니라 정확히 같아. 둘 사이엔 어떤 수도 낄 수 없거든. 친구가 틀렸어 🙂

도전 2 · 복합

1/7 = 0.142857142857… — 여섯 자리 142857이 계속 반복돼.

① 소수점 아래 100번째 자리 숫자는?
② 순환마디 142857 여섯 숫자를 모두 더하면?
① 100번째 자리 숫자:
② 여섯 숫자의 합:
힌트 1마디가 6자리니까, 자리 번호를 6으로 나눈 나머지가 마디 안에서 몇 번째인지 알려줘.
힌트 2100 ÷ 6 = 16 … 나머지 4. 그러니 마디의 4번째 숫자야.
힌트 3마디 1·4·2·8·5·7 의 4번째 = 8. 합은 1+4+2+8+5+7.

✓ 풀이

  1. 마디 길이 = 6. 자리 번호를 6으로 나눈 나머지로 위치를 찾는다.
  2. 100 = 6 × 16 + 4 → 나머지 4 → 마디의 4번째 숫자.
  3. 142857 의 4번째 = 8. ∴ 100번째 자리 = 8
  4. ② 1+4+2+8+5+7 = 27

나머지가 0이면 마디의 마지막 숫자(6번째)라는 것만 조심!

도전 3 · 복합

순환소수도 분수라는 걸 배웠지. 이걸로 신기한 덧셈을 해보자.

0.4̇5̇ = 0.454545… 와 0.5̇4̇ = 0.545454…
① 0.4̇5̇ 를 기약분수로 나타내면 □/11. □는?
② 두 수를 더하면 0.4̇5̇ + 0.5̇4̇ = ?
① 0.4̇5̇ = □/11 의 □:
② 두 수의 합:
힌트 12자리 순환마디 → 분모는 99. 0.4̇5̇ = 45/99. 약분해봐.
힌트 245/99 = 5/11, 0.5̇4̇ = 54/99 = 6/11.
힌트 35/11 + 6/11 = 11/11 = 1. 소수로도 0.4545… + 0.5454… = 0.9999… = 1!

✓ 풀이

  1. 0.4̇5̇ = 45/99 = 5/11 (분자·분모 9로 약분)
  2. 0.5̇4̇ = 54/99 = 6/11
  3. 합: 5/11 + 6/11 = 11/11 = 1

도전 1과 이어지지? 0.4545…+0.5454… 는 자리마다 4+5=9 → 0.9999… → 1. 순환소수가 분수라서 이런 딱 떨어지는 계산이 가능한 거야.
