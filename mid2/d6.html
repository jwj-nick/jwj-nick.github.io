중2-1단원 6심화 탐구

식과 그래프는, 사실 한 이야기

방정식의 해는 그래프의 x절편, 연립방정식의 해는 두 직선의 교점. 같은 답을 두 얼굴로 보는 실험실이야.

이 페이지엔 채점 문제가 없다. 슬라이더를 움직여 그래프와 방정식이 같은 답을 가리키는지 확인한다.

1큰 그림

따로 배운 둘이 사실 하나였어

작년엔 ax + b = 0 같은 방정식의 답을 구했고, 올해는 y = ax + b 의 그래프를 그렸지. 그런데 —

그래프가 x축과 만나는 곳은 y = 0 인 지점. 거기 x값이 바로 ax + b = 0 의 답이야. 즉 x절편 = 방정식의 해. 두 직선이면, 그 교점이 연립방정식의 해가 되고.

주황 점(x절편)이 방정식 ax+b=0 의 답이야. "두 번째 직선"을 켜면 두 선의 교점이 연립방정식의 답이 되는 걸 볼 수 있어.

2패턴 발견

세 가지를 한 문장으로

일차방정식 ax+b=0 의 해 = 그래프의 x절편 (한 개)

연립방정식 의 해 = 두 그래프의 교점 (평행이면 해 없음)

계산으로 풀든 그래프로 찾든 답은 똑같아. 그래서 어려운 문제는 그림을 그려보면 길이 보여.
