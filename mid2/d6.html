중2-1단원 6심화 탐구

식과 그래프는, 사실 한 이야기

방정식의 해는 그래프의 x절편, 연립방정식의 해는 두 직선의 교점. 같은 답을 두 얼굴로 보는 실험실이에요.

이 페이지엔 채점 문제가 없어요. 슬라이더를 움직여 그래프와 방정식이 같은 답을 가리키는지 확인해요.

1큰 그림

따로 배운 둘이 사실 하나였어요

작년엔 ax + b = 0 같은 방정식의 답을 구했고, 올해는 y = ax + b 의 그래프를 그렸죠. 그런데 —

그래프가 x축과 만나는 곳은 y = 0 인 지점. 거기 x값이 바로 ax + b = 0 의 답이에요. 즉 x절편 = 방정식의 해. 두 직선이면, 그 교점이 연립방정식의 해가 돼요.

주황 점(x절편)이 방정식 ax+b=0 의 답이에요. "두 번째 직선"을 켜면 두 선의 교점이 연립방정식의 답이 되는 걸 볼 수 있어요.

2패턴 발견

세 가지를 한 문장으로

일차방정식 ax+b=0 의 해 = 그래프의 x절편 (한 개)

연립방정식 의 해 = 두 그래프의 교점 (평행이면 해 없음)

계산으로 풀든 그래프로 찾든 답은 똑같아요. 그래서 어려운 문제는 그림을 그려보면 길이 보여요.

3조건으로 정하기

평행·일치·한 점이 되게 하는 상수 (미정계수)

계수에 모르는 상수가 있을 때, "이 두 직선이 평행하려면?" 같은 조건으로 상수를 정하는 문제가 자주 나와요. 열쇠는 기울기 비교예요.

y = ax + 1 이 y = 3x − 2 와 평행하려면 a는? 눌러서 확인해 볼까요?

평행 = 기울기가 같다. 그러니 a = 3 이면 돼요 (y절편이 다르니 겹치진 않고 나란히).

만약 한 점에서 만나게 하려면 기울기가 달라야 하니 a ≠ 3. 일치하려면 기울기·y절편이 모두 같아야 하니 a=3 이고 y절편도 −2여야 해요.

세 직선이 한 점에서 만나는 문제도 같은 방법 — 두 직선의 교점을 구해, 나머지 직선이 그 점을 지나게 상수를 맞추면 돼요.
