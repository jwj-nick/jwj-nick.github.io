중2-1단원 3심화 문제

도전 — 부등식으로 결정하기

"몇 개부터 이득일까요?" 처럼 범위를 판단하는 문제예요. 식을 세우고 이유를 글로 적어 보세요.

각 문제에 단계별 힌트와 풀이 보기가 있어요. 먼저 식을 세워 보고, 막히면 열어요.

도전 1 · 서술형

놀이공원 요금이 두 가지예요.

A안 — 자유이용권 25000원 (놀이기구 무제한)
B안 — 입장료 10000원 + 놀이기구 1개당 3000원
놀이기구를 x개 탄다면, 몇 개 이상부터 A안(자유이용권)이 이득일까요?
몇 개 이상부터 A안 이득? x = 개 이상
힌트 1B안 비용 = 10000 + 3000x. A안이 이득이려면 B안이 A안보다 비싸야 해요: 10000 + 3000x ≥ 25000.
힌트 2양변 −10000 → 3000x ≥ 15000.
힌트 3양변 ÷3000 → x ≥ 5. 즉 5개 이상.

✓ 풀이

  1. B안 비용 = 10000 + 3000x
  2. A안이 이득 ⇔ 10000 + 3000x ≥ 25000
  3. 양변 −10000 → 3000x ≥ 15000 → 양변 ÷3000 → x ≥ 5
  4. ∴ 놀이기구를 5개 이상 탈 거면 자유이용권(A안)이 이득
도전 2 · 서술형

문장을 부등식으로 옮기고, 양변을 정리해서 범위를 구하는 문제예요.

"어떤 수의 3배에서 5를 뺀 것이, 그 수에 7을 더한 것보다 크지 않다."
이 수의 범위를 구해 보세요. ('크지 않다' = ≤)
x ≤ □ 의 경계값 □:
힌트 1어떤 수를 x라 하면 3x − 5 ≤ x + 7.
힌트 2x항을 왼쪽으로, 수를 오른쪽으로: 양변 −x, 양변 +5 → 2x ≤ 12.
힌트 3양변 ÷2 (양수라 그대로!) → x ≤ 6.

✓ 풀이

  1. 식 세우기: 3x − 5 ≤ x + 7
  2. 양변에서 x를 빼기: 2x − 5 ≤ 7
  3. 양변에 5를 더하기: 2x ≤ 12
  4. 양변 ÷2 (양수 → 방향 그대로): x ≤ 6

한 단계씩 양변에 똑같이 — 이게 정리의 전부예요. 여긴 양수로 나눠서 부등호가 안 뒤집혔어요.

도전 3 · 실생활

택배로 책을 부치려고 해요.

빈 상자 무게 1.2kg, 책 한 권 0.4kg. 총 무게를 5kg 이하로 맞추려면 책을 최대 몇 권 넣을 수 있을까요?
최대 □ 권: 권
힌트 1책 x권일 때 총 무게 = 1.2 + 0.4x. 조건: 1.2 + 0.4x ≤ 5.
힌트 2양변 −1.2 → 0.4x ≤ 3.8 → 양변 ÷0.4 → x ≤ 9.5.
힌트 3책은 정수 권! 9.5 이하 자연수 중 최대는 9권 (10권이면 넘음).

✓ 풀이

  1. 1.2 + 0.4x ≤ 5
  2. 양변 −1.2 → 0.4x ≤ 3.8
  3. 양변 ÷0.4 → x ≤ 9.5
  4. 책은 정수 → 최대 9권 (검산: 1.2+0.4×9 = 4.8kg ≤ 5 ✓)

답이 9.5처럼 나와도 "물건 개수"는 정수라서 내림하는 걸 잊지 마세요!

도전 4 · 정수해 세기

부등식을 풀고, 그 해 중에서 자연수가 몇 개인지 세는 문제예요.

부등식 2x − 1 < 9 의 해 중 자연수는 모두 몇 개일까요?
자연수 해의 개수: 개
힌트 1양변 +1 → 2x < 10 → 양변 ÷2 → x < 5.
힌트 2x < 5 인 자연수는? 5는 미포함(<)이니 5는 빼요.
힌트 31, 2, 3, 4 → 4개.

✓ 풀이

  1. 2x − 1 < 9 → 2x < 10 → x < 5
  2. 자연수 해: 1, 2, 3, 4 (5는 미포함) → 4개

부등호가 ≤ 였다면 5도 포함해서 5개가 됐을 거예요. 등호 유무가 개수를 바꿔요!

도전 5 · 문자계수

부등식 안에 모르는 상수 a가 들어 있어요. 해가 주어졌을 때 a를 거꾸로 찾는 문제예요.

부등식 x + a ≤ 3x − 1 의 해가 x ≥ 4 일 때, 상수 a의 값은?
a =
힌트 1x항을 한쪽으로: x + a ≤ 3x − 1 → a + 1 ≤ 2x.
힌트 2양변 ÷2 (양수, 그대로) → x ≥ (a + 1)/2.
힌트 3이게 x ≥ 4 와 같으니 (a+1)/2 = 4 → a + 1 = 8 → a = 7.

✓ 풀이

  1. x + a ≤ 3x − 1 → 양변 −x, +1 → a + 1 ≤ 2x
  2. 양변 ÷2 → x ≥ (a + 1)/2
  3. 해가 x ≥ 4 → (a + 1)/2 = 4 → a + 1 = 8 → a = 7

경계값(4)이 (a+1)/2 와 같다는 걸 이용했어요. 이런 문자계수 문제는 "해의 경계값 맞추기"가 열쇠예요.

도전 6 · 실생활(이익률)

문구점에서 원가 8000원인 필통에 이익을 붙여 팔려고 해요.

원가에 x%의 이익을 붙인 정가가 10000원 이하가 되게 하려고 해요. 이익률 x는 최대 몇 %까지 가능할까요?
최대 이익률 x = %
힌트 1정가 = 8000 × (1 + x/100). 조건: 8000(1 + x/100) ≤ 10000.
힌트 2양변 ÷8000 → 1 + x/100 ≤ 1.25 → x/100 ≤ 0.25.
힌트 3양변 ×100 → x ≤ 25. 최대 25%.

✓ 풀이

  1. 정가 = 8000(1 + x/100)
  2. 8000(1 + x/100) ≤ 10000 → 1 + x/100 ≤ 1.25
  3. x/100 ≤ 0.25 → x ≤ 25 → 최대 25%

검산: 8000의 25% 이익 = 2000, 정가 10000원 = 딱 10000 이하 ✓. 할인·이익 문제도 결국 부등식 하나예요.

✓
일차부등식 심화를 마쳤어요
정수해·문자계수·이익률까지 판단했어요.
