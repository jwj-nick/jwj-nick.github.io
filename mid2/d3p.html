중2-1단원 3심화 문제

도전 — 부등식으로 결정하기

"몇 개부터 이득일까?" 처럼 범위를 판단하는 문제야. 식을 세우고 이유를 글로 적어봐.

각 도전엔 단계별 힌트와 풀이 전체 보기가 있어. 먼저 스스로 식을 세워봐.

도전 1 · 서술형

놀이공원 요금이 두 가지야.

A안 — 자유이용권 25000원 (놀이기구 무제한)
B안 — 입장료 10000원 + 놀이기구 1개당 3000원
놀이기구를 x개 탄다면, 몇 개 이상부터 A안(자유이용권)이 이득일까?
몇 개 이상부터 A안 이득? x = 개 이상
힌트 1B안 비용 = 10000 + 3000x. A안이 이득이려면 B안이 A안보다 비싸야 해: 10000 + 3000x ≥ 25000.
힌트 2양변 −10000 → 3000x ≥ 15000.
힌트 3양변 ÷3000 → x ≥ 5. 즉 5개 이상.

✓ 풀이

  1. B안 비용 = 10000 + 3000x
  2. A안이 이득 ⇔ 10000 + 3000x ≥ 25000
  3. 양변 −10000 → 3000x ≥ 15000 → 양변 ÷3000 → x ≥ 5
  4. ∴ 놀이기구를 5개 이상 탈 거면 자유이용권(A안)이 이득
도전 2 · 서술형

문장을 부등식으로 옮기고, 양변을 정리해서 범위를 구하는 문제야.

"어떤 수의 3배에서 5를 뺀 것이, 그 수에 7을 더한 것보다 크지 않다."
이 수의 범위를 구하시오. ('크지 않다' = ≤)
x ≤ □ 의 경계값 □:
힌트 1어떤 수를 x라 하면 3x − 5 ≤ x + 7.
힌트 2x항을 왼쪽으로, 수를 오른쪽으로: 양변 −x, 양변 +5 → 2x ≤ 12.
힌트 3양변 ÷2 (양수라 그대로!) → x ≤ 6.

✓ 풀이

  1. 식 세우기: 3x − 5 ≤ x + 7
  2. 양변에서 x를 빼기: 2x − 5 ≤ 7
  3. 양변에 5를 더하기: 2x ≤ 12
  4. 양변 ÷2 (양수 → 방향 그대로): x ≤ 6

한 단계씩 양변에 똑같이 — 이게 정리의 전부야. 여긴 양수로 나눠서 부등호가 안 뒤집혔어.

도전 3 · 실생활

택배로 책을 부치려고 해.

빈 상자 무게 1.2kg, 책 한 권 0.4kg. 총 무게를 5kg 이하로 맞추려면 책을 최대 몇 권 넣을 수 있을까?
최대 □ 권: 권
힌트 1책 x권일 때 총 무게 = 1.2 + 0.4x. 조건: 1.2 + 0.4x ≤ 5.
힌트 2양변 −1.2 → 0.4x ≤ 3.8 → 양변 ÷0.4 → x ≤ 9.5.
힌트 3책은 정수 권! 9.5 이하 자연수 중 최대는 9권 (10권이면 넘음).

✓ 풀이

  1. 1.2 + 0.4x ≤ 5
  2. 양변 −1.2 → 0.4x ≤ 3.8
  3. 양변 ÷0.4 → x ≤ 9.5
  4. 책은 정수 → 최대 9권 (검산: 1.2+0.4×9 = 4.8kg ≤ 5 ✓)

답이 9.5처럼 나와도 "물건 개수"는 정수라서 내림하는 걸 잊지 마!
