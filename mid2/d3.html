부등호가 뒤집히는 순간을 눈으로

부등식 푸는 손놀림은 방정식과 거의 같아요. 딱 한 곳 — 음수로 나눌 때만 다르죠. 그 순간을 직접 잡아 볼까요?

이 페이지엔 채점 문제가 없어요. 슬라이더를 움직이면 풀이 과정과 수직선이 함께 바뀌어요.

1큰 그림

방정식과 똑같이, 그러나 한 곳만 다르게

부등식도 방정식처럼 이항하고 양변을 같은 수로 나눠서 x만 남겨요. 더하고 빼는 건 아무 문제 없어요.

단 하나 — 양변을 음수로 곱하거나 나누면 부등호가 홱 뒤집혀요. 왜냐면 수직선에서 −1을 곱하면 좌우가 뒤바뀌거든요 (3 < 5 인데 −3 > −5 이잖아요).

아래에서 a를 음수로 바꿔보면, 뒤집히는 순간이 빨갛게 켜져요.

부등식 풀이기 · 직접 굴려 볼까요?
부등호 고르기
a·x + b < c
해: —

a를 음수로 내려 볼까요? (−1, −2, −3). 세 번째 줄에서 부등호가 뒤집히고 ⚠가 켜질 거예요. 수직선의 채워진 방향도 반대로 바뀌죠.

2패턴 발견

언제 뒤집히나요? — 오직 음수로 곱하거나 나눌 때

정리하면 딱 이거예요:

그대로 — 양변에 같은 수를 더하기·빼기, 양수로 곱하기·나누기

뒤집힘 — 양변을 음수로 곱하기·나누기 (예: −x < 2 → x > −2)

이 한 가지만 몸에 익히면 부등식은 방정식만큼 쉬워져요.

3해를 세어보기

범위 안에 정수는 몇 개 들어 있을까요?

부등식의 해는 수많은 수예요. 그중 정수만 세는 문제가 시험에 자주 나와요. 핵심은 경계값을 포함하는지(등호 유무) 확인하는 거예요.

−2 ≤ x < 3 을 만족하는 정수는 몇 개일까요? 먼저 세어 볼까요?

왼쪽 −2 는 이상(≤)이라 포함, 오른쪽 3 은 미만(<)이라 불포함이에요.

그래서 −2, −1, 0, 1, 2 → 5개. 만약 −2 < x < 3 이었다면 −2도 빠져서 4개가 돼요.

수직선에 점을 찍어 하나씩 세면 실수가 없어요. 등호(●)와 미포함(○)만 잘 구분하면 돼요.
