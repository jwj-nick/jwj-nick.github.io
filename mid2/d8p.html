중2단원 8심화 문제

도전 — 사각형의 변·각·대각선

평행사변형의 각·대각선부터 직사각형·마름모·정사각형까지. 과정을 글로 남겨 보세요.

각 문제에 단계별 힌트와 풀이 보기가 있어요. 먼저 직접 풀어 보고, 막히면 열어요.

도전 1 · 평행사변형 각

이웃한 두 각의 비를 이용해요.

평행사변형에서 이웃한 두 각의 크기의 비가 1 : 3일 때, 작은 각의 크기는?
작은 각 =°
힌트 1이웃각의 합 x + 3x = 180.
힌트 24x = 180 → x = 45.

✓ 풀이

  1. 이웃각의 합은 180° → x + 3x = 180
  2. 4x = 180 → x = 45°
도전 2 · 대각선 이등분

대각선이 서로 이등분하는 성질을 식으로 써요.

평행사변형 ABCD에서 대각선의 교점을 M이라 할 때 AM = x + 1, MC = 2x − 3이에요. 대각선 AC의 길이는?
AC =
힌트 1이등분이므로 AM = MC → x + 1 = 2x − 3 → x = 4.
힌트 2AM = 5, AC = 2 × 5 = 10.

✓ 풀이

  1. 이등분: x+1 = 2x−3 → x = 4
  2. AM = 5 → AC = AM + MC = 10
도전 3 · 직사각형 대각선

직사각형의 대각선 길이가 같음을 이용해요.

직사각형에서 두 대각선의 길이가 AC = x + 4, BD = 2x일 때, 대각선의 길이는?
대각선 길이 =
힌트 1직사각형: AC = BD → x + 4 = 2x → x = 4.
힌트 2BD = 2 × 4 = 8.

✓ 풀이

  1. 대각선 길이 같음: x+4 = 2x → x = 4
  2. 대각선 = 2x = 8
도전 4 · 마름모 각

마름모의 대각선이 꼭지각을 이등분함을 이용해요.

마름모 ABCD에서 ∠A = 60°일 때, 대각선 AC가 ∠A를 나눈 한 각의 크기는?
나눈 한 각 =°
힌트 1마름모의 대각선은 꼭지각을 이등분해요.
힌트 260 ÷ 2 = 30°.

✓ 풀이

  1. 마름모의 대각선은 각을 이등분 → 60 ÷ 2 = 30°
도전 5 · 정사각형 대각선

정사각형 대각선이 이루는 각을 구해요.

정사각형에서 대각선이 한 꼭짓각(90°)을 나눈 한 각의 크기는?
나눈 한 각 =°
힌트 1정사각형도 마름모라 대각선이 꼭지각(90°)을 이등분해요.
힌트 290 ÷ 2 = 45°.

✓ 풀이

  1. 대각선이 90°를 이등분 → 90 ÷ 2 = 45°
도전 6 · 둘레

평행사변형의 대변이 같음을 이용해요.

평행사변형 ABCD에서 AB = 7, BC = 5일 때, 둘레의 길이는?
둘레 =
힌트 1대변이 같으니 CD = 7, DA = 5.
힌트 2둘레 = 2 × (7 + 5) = 24.

✓ 풀이

  1. 대변이 같음: CD=7, DA=5
  2. 둘레 = 2×(7+5) = 24
