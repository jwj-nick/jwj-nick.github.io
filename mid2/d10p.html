도전 1 · 빗변

직각을 낀 두 변으로 빗변을 구해요.

직각을 낀 두 변이 9, 12인 직각삼각형의 빗변은?
빗변 =
힌트 19² + 12² = 81 + 144 = 225.
힌트 2√225 = 15.

✓ 풀이

  1. c² = 81 + 144 = 225
  2. c = 15
도전 2 · 한 변

빗변과 한 변으로 나머지 변을 구해요.

빗변이 25, 직각을 낀 한 변이 7인 직각삼각형의 나머지 변은?
나머지 변 =
힌트 125² − 7² = 625 − 49 = 576.
힌트 2√576 = 24.

✓ 풀이

  1. x² = 625 − 49 = 576
  2. x = 24
