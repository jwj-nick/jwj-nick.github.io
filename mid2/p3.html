중2-1단원 3연습

직접 풀어보기 — 일차부등식

용돈·놀이기구·시험 평균… 실생활 속 조건을 부등식으로 바꿔 풀어보자.

미션을 하나씩 풀 때마다 진행 막대가 차. 다 채우면 도장을 받아 🌸

1용돈으로 몇 개 살까
실생활쉬움
💰지갑에 12000원. 한 개에 3000원인 팬시를 x개 사려면 3000x ≤ 12000.

최대 몇 개까지 살 수 있을까?

개
왜?양변을 3000으로 나누면 x ≤ 4. 4개까진 되고 5개는 돈이 모자라 → 4개.
2놀이기구를 타려면
실생활원리보통
🎢"키 140cm 이상(at least) 탑승". 지금 132cm, 1년에 4cm씩 자라. 132 + 4x ≥ 140.

몇 년 뒤부터 탈 수 있을까?

년
왜?양변 −132 → 4x ≥ 8, 양변 ÷4 → x ≥ 2. 2년 뒤엔 140cm가 되니까 → 2년.
3부호의 함정 — 뒤집힌다!
원리예측보통
⚠️−2x < 6 을 풀 거야. 양변을 −2로 나눠야 하는데… 부등호 방향이 어떻게 될까? 먼저 예측해봐!
−2x < 6 → 양변 ÷(−2) → x > −3
왜 뒤집힐까?음수로 곱하거나 나누면 부등호가 홱 뒤집혀. 이게 부등식에만 있는 함정이야. (더하고 빼는 건 안 뒤집혀.)

4정액권이 이득일까
실생활보통
🚌지하철 정액권 40000원(무제한) vs 1회 1250원. 몇 번 이상 타야 정액권이 이득? 1250x ≥ 40000.

한 달에 몇 번 이상 타면 정액권이 이득일까?

번
왜?양변 ÷1250 → x ≥ 32. 32번부터는 1회권이 4만원을 넘어 → 정액권이 이득 → 32번.
5평균 80점을 넘기려면
실생활도전
📊수학 세 번 평균을 80점 이상으로! 앞 두 번은 76점, 82점. (76 + 82 + x) ÷ 3 ≥ 80.

마지막 시험에서 최소 몇 점을 받아야 할까?

점
왜?양변 ×3 → 158 + x ≥ 240, 양변 −158 → x ≥ 82. 최소 82점.
