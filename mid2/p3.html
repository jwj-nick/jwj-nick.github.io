유형별 연습 — 일차부등식

부등호 세우기부터 활용까지, 시험에 나오는 8가지 유형을 하나씩 다뤄 볼까요?

유형 하나를 다 풀면 위 막대의 그 칸이 완성돼요.

푼 문제: 0 / 24

1부등식으로 나타내기
표현기본

이상 ≥, 이하 ≤ 는 그 수를 포함, 초과 >, 미만 < 는 포함하지 않아요.

(1)한 개 700원 사탕 x개의 값이 5000원 이하. 알맞은 식은?

(2)"x는 3보다 크다"를 식으로?

(3)정원이 30명 이하인 방에 x명. 알맞은 식은?

2해 확인하기 (대입)
대입기본

주어진 수를 대입해서 부등식이 참이면 해, 거짓이면 해가 아니에요.

(1)x = 2 는 2x − 1 < 6 의 해일까요?

(2)x = 4 는 3x ≥ 15 의 해일까요?

(3)x = −1 은 −2x + 1 ≤ 4 의 해일까요?

3부등식의 성질
원리보통

양변에 같은 수를 더하거나 빼면 부등호 그대로. 양수를 곱/나누면 그대로, 음수를 곱/나누면 뒤집혀요.

(1)a < b 일 때, a + 3 과 b + 3 사이 부등호는?

(2)a < b 일 때, −2a 와 −2b 사이 부등호는?

왜?음수(−2)를 곱했으니 부등호가 뒤집혀요 → −2a > −2b.

(3)a < b 일 때, a − 5 와 b − 5 사이 부등호는?

4일차부등식 풀기
풀이보통

방정식처럼 이항하고 양변을 나눠 x만 남겨요. 답의 경계값(부등호가 바뀌는 수)을 적어요.

(1)2x + 1 < 7 → x < □ 의 □?

(2)3x − 2 ≥ 4 → x ≥ □ 의 □?

(3)−x + 5 > 2 → x < □ 의 □? (음수로 나눠요!)

왜?−x > −3 → 양변 ÷(−1) → 부등호 뒤집혀 x < 3. 경계값 3.
5수직선으로 나타내기
표현기본

포함하면(≥, ≤) 속이 찬 점 ●, 포함 안 하면(>, <) 빈 점 ○. 큰 쪽(>, ≥)은 오른쪽, 작은 쪽(<, ≤)은 왼쪽으로 칠해요.

(1)x ≥ 2 를 나타낼 때, 2에 찍는 점은?

(2)x < 5 는 5를 기준으로 어느 쪽을 칠할까요?

(3)3에 빈 점, 오른쪽으로 칠했다면 부등식은?

6해의 개수·조건
상상력도전

범위 안에 든 자연수·정수를 직접 세어요. 경계값을 포함하는지(등호) 꼭 확인해요.

(1)x ≤ 4 를 만족하는 자연수 x는 모두 몇 개?

왜?자연수 1, 2, 3, 4 → 4개 (4 포함).

(2)−2 ≤ x < 3 을 만족하는 정수 x는 모두 몇 개?

왜?−2, −1, 0, 1, 2 → 5개 (−2 포함, 3 미포함).

(3)부등식 x > a 의 가장 작은 정수해가 3일 때, 정수 a는? (a는 정수)

왜?x > 2 면 정수해가 3, 4, 5… → 가장 작은 게 3. 그래서 a = 2.
7괄호·분수·소수 계수
풀이도전

괄호는 먼저 전개, 분수는 분모의 최소공배수를 양변에 곱하고, 소수는 10·100을 곱해 정수로 바꾼 뒤 풀어요.

(1)2(x − 1) ≤ 6 → x ≤ □ 의 □?

(2)x/2 + 1 > 3 → x > □ 의 □? (양변 ×2)

(3)0.3x − 0.5 ≥ 0.4 → x ≥ □ 의 □? (양변 ×10)

왜?양변 ×10 → 3x − 5 ≥ 4 → 3x ≥ 9 → x ≥ 3.
8활용 (개수·평균·요금)
실생활보통

구하는 것을 x로 두고 부등식을 세워 풀어요. 개수·사람 수는 정수라 마지막에 내림·올림을 확인해요.

(1)1500원 아이스크림을 8000원으로 최대 몇 개 살 수 있을까요?

개
왜?1500x ≤ 8000 → x ≤ 5.3… → 정수라 최대 5개.

(2)수학 두 번 85점, 90점. 세 번째까지 평균이 88점 이상이려면 세 번째 시험 최소 몇 점?

점
왜?(85+90+x)/3 ≥ 88 → 175 + x ≥ 264 → x ≥ 89. 최소 89점.

(3)기본요금 3000원 + 1km마다 1000원 택시. 15000원으로 최대 몇 km?

km
왜?3000 + 1000x ≤ 15000 → 1000x ≤ 12000 → x ≤ 12. 최대 12km.
