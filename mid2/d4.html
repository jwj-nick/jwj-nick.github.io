연립방정식은 사실 '두 직선이 만나는 점'

대입법으로 구한 답 (x, y)는, 두 직선의 교점(intersection)이에요. 그림과 계산이 같은 답을 가리키는 걸 직접 확인해 볼까요?

이 페이지엔 채점 문제가 없어요. 슬라이더를 움직이면 두 직선·교점·대입 계산이 함께 움직여요.

1큰 그림

두 조건을 동시에 만족하는 딱 한 점

식 하나는 직선 하나예요. 연립방정식은 두 직선을 동시에 만족하는 점을 찾는 것 — 그게 두 선이 만나는 곳이죠.

대입법은 이 만나는 점을 계산으로 찾는 방법이에요. 두 y가 같아지는 지점을 찾으니까 a₁x + b₁ = a₂x + b₂ 로 놓고 x를 구하는 거죠.

교점: —

두 기울기를 똑같이 맞춰 볼까요? (a₁ = a₂). 두 직선이 평행해서 만나질 않아요 — 이때 연립방정식은 해가 없어요. y절편까지 같으면 완전히 포개져 해가 무수히 많아요.

2패턴 발견

해가 하나 / 없음 / 무수히 많음

한 점에서 만남 — 기울기가 다름 → 해가 딱 하나 (보통의 경우)

평행 — 기울기 같고 y절편 다름 → 해 없음

포개짐(일치) — 기울기·y절편 모두 같음 → 해 무수히 많음

대입법으로 풀다가 0 = 5 같은 이상한 식이 나오면 "평행(해 없음)", 0 = 0이 나오면 "포개짐(무수히)"이라는 신호예요.

3거꾸로 생각하기

계수에 모르는 수가 섞여 있으면?

가끔 계수 자리에 모르는 상수(a, k…)가 들어 있는 문제가 나와요. 이럴 땐 주어진 해를 그대로 대입하면, 모르는 상수 하나만 남는 방정식이 돼요.

ax + y = 7 의 해가 (2, 3) 이라면, a는 얼마일까요? 눌러서 확인해 볼까요?

해 (2, 3) 을 그대로 넣어요: a×2 + 3 = 7.

2a + 3 = 7 → 2a = 4 → a = 2. 모르는 게 하나뿐이라 보통 일차방정식이 되죠?

"두 식의 공통해가 세 번째 식도 만족한다" 같은 문제도 결국 같은 방법 — 공통해를 구해 대입하면 돼요.
