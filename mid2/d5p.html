도전 — 함수로 세상을 재기

두 점에서 식을 세우고, 절편으로 넓이를 재고, 요금제를 비교해요. 과정을 글로 남겨 보세요.

각 문제에 단계별 힌트와 풀이 보기가 있어요. 먼저 직접 풀어 보고, 막히면 열어요.

도전 1 · 복합

두 점을 지나는 직선의 식을 만들고, 절편까지 구하는 문제예요.

두 점 (1, 3) 과 (3, 7) 을 지나는 일차함수의 식 y = ax + b 를 구해 보세요.
기울기 a = y절편 b =
힌트 1기울기 a = (7−3) ÷ (3−1) = 4 ÷ 2 = 2.
힌트 2y = 2x + b 에 점 (1,3) 대입: 3 = 2×1 + b → b = 1.
힌트 3식은 y = 2x + 1. x절편은 0 = 2x+1 → x = −1/2.

✓ 풀이

  1. 기울기 a = (7−3)/(3−1) = 2
  2. 점 (1,3) 대입: 3 = 2·1 + b → b = 1
  3. ∴ y = 2x + 1
  4. x절편: 0 = 2x + 1 → x = −1/2, y절편: 1
도전 2 · 실생활

통화 요금제 두 개를 비교해요.

A: 기본 15000원 + 1분당 50원 → y = 15000 + 50x
B: 기본 25000원 + 1분당 30원 → y = 25000 + 30x
한 달에 몇 분을 초과해서 쓰면 B가 더 이득(더 쌈)일까요?
몇 분 초과부터 B가 이득? x = 분
힌트 1두 요금이 같아지는 곳: 15000 + 50x = 25000 + 30x.
힌트 220x = 10000 → x = 500 (분).
힌트 3500분보다 많이 쓰면 요금이 빨리 오르는 A가 비싸져 → B가 이득. 즉 500분 초과.

✓ 풀이

  1. 같아지는 지점: 15000 + 50x = 25000 + 30x
  2. 20x = 10000 → x = 500
  3. 500분 초과 시 A의 분당요금(50)이 커서 A가 비쌈 → B가 이득
  4. ∴ 500분 초과부터 B 선택
도전 3 · 복합

그래프와 두 좌표축이 만드는 삼각형 넓이를 구하는 문제예요.

직선 y = 2x − 4 와 x축, y축으로 둘러싸인 삼각형의 넓이는?
삼각형 넓이 =
힌트 1x절편: 0 = 2x−4 → x = 2. y절편: x=0 → y = −4.
힌트 2삼각형의 밑변 = |x절편| = 2, 높이 = |y절편| = 4.
힌트 3넓이 = ½ × 2 × 4 = 4.

✓ 풀이

  1. x절편: 0 = 2x − 4 → x = 2 → 점 (2, 0)
  2. y절편: y = −4 → 점 (0, −4)
  3. 직각삼각형의 두 변 = |2|, |−4|
  4. 넓이 = ½ × 2 × 4 = 4
도전 4 · 미정계수

그래프(또는 두 점)만 주어졌을 때, 아직 모르는 a, b 를 알아내는 문제예요.

일차함수 y = ax + b 의 그래프가 두 점 (1, 5) 와 (3, 1) 을 지날 때, a와 b는?
a = b =
힌트 1기울기 a = (1 − 5) ÷ (3 − 1) = −4 ÷ 2 = −2.
힌트 2y = −2x + b 에 (1, 5) 대입: 5 = −2 + b → b = 7.
힌트 3식은 y = −2x + 7. 검산: (3, 1) → −6 + 7 = 1 ✓

✓ 풀이

  1. 기울기 a = (1 − 5)/(3 − 1) = −2
  2. (1, 5) 대입: 5 = −2×1 + b → b = 7
  3. ∴ a = −2, b = 7 → y = −2x + 7
도전 5 · 조건으로 식 세우기

말로 된 조건 두 개로 직선을 딱 정하는 문제예요.

직선 y = 2x − 3 과 평행하고, y = −x + 6 과 y축 위에서 만나는 직선의 기울기와 y절편은?
기울기 = y절편 =
힌트 1y = 2x − 3 과 평행 → 기울기 2 그대로.
힌트 2"y축 위에서 만난다" = y절편이 같다. y = −x + 6 의 y절편은 6.
힌트 3그래서 기울기 2, y절편 6 → y = 2x + 6.

✓ 풀이

  1. 평행 → 기울기 = 2
  2. y축에서 만남 → y절편이 y = −x + 6 과 같은 6
  3. ∴ y = 2x + 6 (기울기 2, y절편 6)
도전 6 · 복합(그래프 해석)

두 물통의 물의 양이 시간에 따라 변해요.

물통 A: 처음 30L에서 1분에 2L씩 빠짐 → y = 30 − 2x
물통 B: 처음 6L에서 1분에 2L씩 채워짐 → y = 2x + 6
두 물통의 물의 양이 같아지는 건 몇 분 뒤이고, 그때 물의 양은?
몇 분 뒤 =분 그때 양 =L
힌트 1양이 같아지는 순간: 30 − 2x = 2x + 6.
힌트 230 − 6 = 4x → 24 = 4x → x = 6 (분).
힌트 3x=6 을 넣으면 y = 2×6 + 6 = 18 (L).

✓ 풀이

  1. 양이 같음: 30 − 2x = 2x + 6
  2. 24 = 4x → x = 6 (분)
  3. 물의 양: y = 2×6 + 6 = 18 (L) (A로도 30−12=18 ✓)
