중2-1단원 5심화 문제

도전 — 함수로 세상을 재기

두 점에서 식을 세우고, 절편으로 넓이를 재고, 요금제를 비교해요. 과정을 글로 남겨 보세요.

각 문제에 단계별 힌트와 풀이 보기가 있어요. 먼저 직접 풀어 보고, 막히면 열어요.

도전 1 · 복합

두 점을 지나는 직선의 식을 만들고, 절편까지 구하는 문제예요.

두 점 (1, 3) 과 (3, 7) 을 지나는 일차함수의 식 y = ax + b 를 구해 보세요.
기울기 a = y절편 b =
힌트 1기울기 a = (7−3) ÷ (3−1) = 4 ÷ 2 = 2.
힌트 2y = 2x + b 에 점 (1,3) 대입: 3 = 2×1 + b → b = 1.
힌트 3식은 y = 2x + 1. x절편은 0 = 2x+1 → x = −1/2.

✓ 풀이

  1. 기울기 a = (7−3)/(3−1) = 2
  2. 점 (1,3) 대입: 3 = 2·1 + b → b = 1
  3. ∴ y = 2x + 1
  4. x절편: 0 = 2x + 1 → x = −1/2, y절편: 1
도전 2 · 실생활

통화 요금제 두 개를 비교해요.

A: 기본 15000원 + 1분당 50원 → y = 15000 + 50x
B: 기본 25000원 + 1분당 30원 → y = 25000 + 30x
한 달에 몇 분을 초과해서 쓰면 B가 더 이득(더 쌈)일까요?
몇 분 초과부터 B가 이득? x = 분
힌트 1두 요금이 같아지는 곳: 15000 + 50x = 25000 + 30x.
힌트 220x = 10000 → x = 500 (분).
힌트 3500분보다 많이 쓰면 요금이 빨리 오르는 A가 비싸져 → B가 이득. 즉 500분 초과.

✓ 풀이

  1. 같아지는 지점: 15000 + 50x = 25000 + 30x
  2. 20x = 10000 → x = 500
  3. 500분 초과 시 A의 분당요금(50)이 커서 A가 비쌈 → B가 이득
  4. ∴ 500분 초과부터 B 선택
도전 3 · 복합

그래프와 두 좌표축이 만드는 삼각형 넓이를 구하는 문제예요.

직선 y = 2x − 4 와 x축, y축으로 둘러싸인 삼각형의 넓이는?
삼각형 넓이 =
힌트 1x절편: 0 = 2x−4 → x = 2. y절편: x=0 → y = −4.
힌트 2삼각형의 밑변 = |x절편| = 2, 높이 = |y절편| = 4.
힌트 3넓이 = ½ × 2 × 4 = 4.

✓ 풀이

  1. x절편: 0 = 2x − 4 → x = 2 → 점 (2, 0)
  2. y절편: y = −4 → 점 (0, −4)
  3. 직각삼각형의 두 변 = |2|, |−4|
  4. 넓이 = ½ × 2 × 4 = 4
✓
