중2-1단원 2심화 문제

도전 — 거듭제곱의 힘

지수를 실제 세계에 써먹는 문제야. 이유를 글로 적어보고, 막히면 힌트를 한 칸씩 열어.

각 문제에 단계별 힌트와 풀이 보기가 있다. 먼저 스스로 풀고, 막히면 연다.

도전 1 · 서술형

컴퓨터 용량은 전부 2의 거듭제곱으로 세. 1KB = 210 byte 인데, 놀랍게도 이게 약 1000 byte야.

① 210 의 정확한 값은?
② 왜 210 ≈ 103 (천) 이라고 할 수 있는지, 그리고 220(1MB), 230(1GB)이 대략 얼마인지 글로 설명해봐.
① 210 = ?
힌트 1210 = 2×2×…×2 (2를 10번). 계산하면 1024 — 1000에 아주 가깝지?
힌트 2그래서 210 ≈ 103. 지수법칙으로 220 = (210)2 ≈ (103)2 = 106 (백만).
힌트 3같은 식으로 230 ≈ 109 (십억). 그래서 1MB≈백만 byte, 1GB≈십억 byte라고 부르는 거야.

✓ 풀이

  1. 210 = 1024 ≈ 1000 = 103
  2. 220 = (210)2 ≈ (103)2 = 106 → 약 백만 byte = 1MB
  3. 230 = (210)3 ≈ 109 → 약 십억 byte = 1GB

지수법칙 (210)n 딱 한 줄로 KB·MB·GB가 전부 설명돼!

도전 2 · 복합

직사각형 모양 밭이 있어. 넓이가 12a3b2 이고, 가로가 3ab 라면 세로는 얼마일까?

직사각형 넓이 = 가로 × 세로 → 세로 = 넓이 ÷ 가로 = 12a3b2 ÷ 3ab
세로 = □a2b 의 계수 □:
힌트 1나눗셈은 계수끼리 나누고(12÷3), 같은 문자의 지수는 뺀다.
힌트 2a3÷a = a3−1 = a2, b2÷b = b2−1 = b.
힌트 312÷3 = 4 → 세로 = 4a2b.

✓ 풀이

  1. 계수: 12 ÷ 3 = 4
  2. 문자 a: a3 ÷ a1 = a2
  3. 문자 b: b2 ÷ b1 = b
  4. ∴ 세로 = 4a2b (검산: 3ab × 4a²b = 12a³b² ✓)
도전 3 · 실생활

두께 0.1mm 종이를 계속 반으로 접어. 한 번 접을 때마다 두께가 2배 → n번 접으면 두께는 2n × 0.1mm.

한라산 높이는 1950m = 1,950,000mm. 종이를 최소 몇 번 접어야 한라산보다 두꺼워질까?
최소 접는 횟수 n =
힌트 1식: 2n × 0.1 ≥ 1,950,000 → 2n ≥ 19,500,000.
힌트 2224 = 16,777,216 (아직 부족), 225 = 33,554,432 (충분!).
힌트 319,500,000을 처음 넘는 건 225 → 25번.

✓ 풀이

  1. 2n × 0.1 ≥ 1,950,000 → 양변 ×10 → 2n ≥ 19,500,000
  2. 224 = 16,777,216 < 19,500,000 (부족)
  3. 225 = 33,554,432 ≥ 19,500,000 (충분)
  4. ∴ 최소 25번

종이를 단 25번 접으면 한라산을 넘어! 실제로는 종이가 두꺼워 그렇게 못 접지만, 지수의 힘이 이 정도야 🤯
