1일차방정식의 그래프 (y= 꼴로)
변형보통

ax + by + c = 0 꼴도 y만 남기게 이항하면 y = (기울기)x + (y절편) 이 돼요.

(1)2x + y − 5 = 0 을 y = □x + □ 로 고쳤을 때 기울기는?

왜?y만 남기면 y = −2x + 5. 기울기 −2.

(2)같은 식 2x + y − 5 = 0 의 y절편은?

(3)x − y + 3 = 0 을 y = □x + □ 로 고쳤을 때 기울기는?

왜?−y = −x − 3 → y = x + 3. 기울기 1.
2좌표축에 평행한 직선 (x=k, y=k)
개념보통

y = k 는 x축에 평행한 가로선, x = k 는 y축에 평행한 세로선이에요.

(1)x축에 평행하고 점 (2, 5) 를 지나는 직선 y = □ 의 □?

(2)y축에 평행하고 점 (3, −1) 을 지나는 직선 x = □ 의 □?

왜?y축에 평행한 세로선은 x가 항상 같아요. (3, −1)을 지나니 x = 3.

(1)점 (2, 3) 은 y = x + 1 과 y = −x + 5 의 교점일까요?

(2)"두 직선의 교점 좌표는 그 연립방정식의 해와 같다." 참일까요?

6두 직선의 위치 관계
성질보통

기울기 다름 → 한 점에서 만남. 기울기 같고 y절편 다름 → 평행. 둘 다 같음 → 일치(같은 직선).

(1)y = 2x + 1 과 y = 2x − 3 의 관계는?

왜?기울기 둘 다 2로 같고 y절편이 달라 → 평행.

(2)y = 3x + 2 와 y = −x + 2 의 관계는?

(3)y = x + 5 와 2y = 2x + 10 의 관계는?

왜?2y = 2x + 10 을 정리하면 y = x + 5 — 완전히 같은 직선 → 일치.
7세 직선이 한 점에서 만나기
상상력도전

먼저 계수를 아는 두 직선의 교점을 구하고, 그 점을 나머지 직선이 지나도록 상수를 정해요.

(1)세 직선 y = 2x − 1, y = −x + 5, y = x + a 가 한 점에서 만날 때 a?

왜?앞 두 직선 교점: 2x−1=−x+5 → x=2, y=3. y=x+a 가 (2,3) 지남 → 3=2+a → a=1.

(2)세 직선 y = x + 2, y = −2x + 8, y = ax 가 한 점에서 만날 때 a?

왜?앞 두 직선 교점: x+2=−2x+8 → x=2, y=4. y=ax 가 (2,4) 지남 → 4=2a → a=2.
8활용 (손익분기·온도·넓이)
실생활보통

두 상황이 같아지는 순간 = 두 직선의 교점. x축과 만나는 순간 = x절편(방정식의 답).

(1)비용 y = 2000x + 30000, 수입 y = 5000x. 몇 개 팔면 본전(손익분기)?

개
왜?5000x = 2000x + 30000 → 3000x = 30000 → x = 10. 10개가 손익분기.

(2)기온 24℃가 1시간에 3℃씩 내려요(y = 24 − 3x). 0℃가 되는 건 몇 시간 뒤?

시간
왜?24 − 3x = 0 → x = 8. 0℃가 되는 시각 = x절편.

(3)직선 y = −2x + 6 과 x축, y축으로 둘러싸인 삼각형의 넓이는?

왜?x절편 3, y절편 6 → ½ × 3 × 6 = 9.
