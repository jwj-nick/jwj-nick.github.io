중2-1단원 6심화 문제

도전 — 그래프와 계산, 둘 다로

같은 답을 그래프로도, 계산으로도 구해 보고 손익분기·넓이까지. 과정을 글로 남겨 보세요.

각 문제에 단계별 힌트와 풀이 보기가 있어요. 먼저 직접 풀어 보고, 막히면 열어요.

도전 1 · 서술형

두 직선의 교점을 두 가지 방법으로 구하고, 답이 같은지 확인하는 문제예요.

y = x + 1 과 y = −2x + 7 의 교점을 ① 계산(대입)으로, ② 그래프를 떠올려 구하고 같음을 설명해 보세요.
x = y =
힌트 1교점에서 두 y가 같음: x + 1 = −2x + 7.
힌트 23x = 6 → x = 2.
힌트 3y = 2 + 1 = 3 → 교점 (2, 3). 그래프로도 두 선이 (2,3)에서 만나요.

✓ 풀이

  1. 교점 ⇔ 두 y가 같음: x + 1 = −2x + 7
  2. 3x = 6 → x = 2
  3. y = 2 + 1 = 3 → 교점 (2, 3)
  4. 그래프에서도 두 직선이 (2, 3)에서 만남 → 두 방법의 답이 같음 ✓
도전 2 · 실생활

굿즈(스티커)를 만들어 팔아요.

초기비용 30000원 + 1개당 원가 2000원 → 비용 y = 2000x + 30000
판매가 5000원 → 수입 y = 5000x
몇 개를 팔아야 손익분기(본전)가 될까요?
손익분기 개수 = 개
힌트 1본전: 수입 = 비용 → 5000x = 2000x + 30000.
힌트 23000x = 30000.
힌트 3x = 10 → 10개부터 이익!

✓ 풀이

  1. 손익분기 ⇔ 수입 = 비용: 5000x = 2000x + 30000
  2. 3000x = 30000 → x = 10
  3. ∴ 10개를 팔면 본전, 그 이상 팔면 이익 (두 직선의 교점이 손익분기점)
도전 3 · 복합

직선과 두 좌표축이 만드는 삼각형의 넓이를 구하는 문제예요.

직선 y = −2x + 6 과 x축, y축으로 둘러싸인 삼각형의 넓이는?
삼각형 넓이 =
힌트 1x절편: 0 = −2x + 6 → x = 3. y절편: x=0 → y = 6.
힌트 2밑변 = 3, 높이 = 6인 직각삼각형.
힌트 3넓이 = ½ × 3 × 6 = 9.

✓ 풀이

  1. x절편: 0 = −2x + 6 → x = 3 → (3, 0)
  2. y절편: y = 6 → (0, 6)
  3. 밑변 3, 높이 6인 직각삼각형
  4. 넓이 = ½ × 3 × 6 = 9
도전 4 · 교점 지나는 직선

두 직선의 교점을 지나면서 조건에 맞는 새 직선을 구하는 문제예요.

두 직선 y = x + 1 과 y = −x + 5 의 교점을 지나고, 기울기가 3인 직선의 y절편은?
y절편 b =
힌트 1교점: x + 1 = −x + 5 → x = 2, y = 3 → (2, 3).
힌트 2기울기 3이니 y = 3x + b. (2, 3) 대입: 3 = 3×2 + b.
힌트 33 = 6 + b → b = −3.

✓ 풀이

  1. 교점: x + 1 = −x + 5 → x = 2, y = 3 → (2, 3)
  2. 기울기 3: y = 3x + b, (2, 3) 대입 → 3 = 6 + b
  3. b = −3 → 직선은 y = 3x − 3
도전 5 · 세 직선이 한 점에서

세 직선이 한 점에서 모두 만나도록 상수를 정하는 문제예요.

세 직선 y = 2x, y = −x + 6, y = x + a 가 한 점에서 만날 때, 상수 a는?
a =
힌트 1앞 두 직선의 교점: 2x = −x + 6 → x = 2, y = 4 → (2, 4).
힌트 2세 직선이 한 점에서 만나려면 y = x + a 도 (2, 4)를 지나야 해요.
힌트 34 = 2 + a → a = 2.

✓ 풀이

  1. 앞 두 직선 교점: 2x = −x + 6 → x = 2, y = 4 → (2, 4)
  2. 세 번째 직선도 이 점을 지나야: 4 = 2 + a
  3. a = 2

"세 직선이 한 점" = "두 직선의 교점을 세 번째도 지난다"로 바꿔 생각하는 게 핵심이에요.

도전 6 · 복합(넓이)

두 직선과 x축이 만드는 삼각형의 넓이를 구하는 문제예요.

두 직선 y = x 와 y = −x + 4, 그리고 x축으로 둘러싸인 삼각형의 넓이는?
삼각형 넓이 =
힌트 1두 직선의 교점(꼭대기): x = −x + 4 → x = 2, y = 2 → (2, 2).
힌트 2x축과 만나는 점: y = x 는 (0, 0), y = −x + 4 는 (4, 0). 밑변 = 4.
힌트 3밑변 4(x축 위), 높이 = 꼭대기의 y = 2 → ½ × 4 × 2 = 4.

✓ 풀이

  1. 두 직선의 교점(꼭대기): x = −x + 4 → (2, 2)
  2. x축과 만나는 점: (0, 0) 과 (4, 0) → 밑변 = 4
  3. 높이 = 꼭대기의 y좌표 = 2
  4. 넓이 = ½ × 4 × 2 = 4

그림을 그려 세 꼭짓점을 찍으면 밑변·높이가 한눈에 보여요.

✓
함수와 방정식 심화를 마쳤어요
교점·세 직선·넓이까지 풀었어요.
