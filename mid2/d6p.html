중2-1단원 6심화 문제

도전 — 그래프와 계산, 둘 다로

같은 답을 그래프로도, 계산으로도 구해보고 손익분기·넓이까지. 과정을 글로 남겨봐.

각 도전엔 단계별 힌트와 풀이 전체 보기가 있어. 먼저 스스로 그림을 그려봐.

도전 1 · 서술형

두 직선의 교점을 두 가지 방법으로 구하고, 답이 같은지 확인하는 문제야.

y = x + 1 과 y = −2x + 7 의 교점을 ① 계산(대입)으로, ② 그래프를 떠올려 구하고 같음을 설명하시오.
x = y =
힌트 1교점에서 두 y가 같음: x + 1 = −2x + 7.
힌트 23x = 6 → x = 2.
힌트 3y = 2 + 1 = 3 → 교점 (2, 3). 그래프로도 두 선이 (2,3)에서 만나.

✓ 풀이

  1. 교점 ⇔ 두 y가 같음: x + 1 = −2x + 7
  2. 3x = 6 → x = 2
  3. y = 2 + 1 = 3 → 교점 (2, 3)
  4. 그래프에서도 두 직선이 (2, 3)에서 만남 → 두 방법의 답이 같음 ✓
도전 2 · 실생활

굿즈(스티커)를 만들어 팔아.

초기비용 30000원 + 1개당 원가 2000원 → 비용 y = 2000x + 30000
판매가 5000원 → 수입 y = 5000x
몇 개를 팔아야 손익분기(본전)가 될까?
손익분기 개수 = 개
힌트 1본전: 수입 = 비용 → 5000x = 2000x + 30000.
힌트 23000x = 30000.
힌트 3x = 10 → 10개부터 이익!

✓ 풀이

  1. 손익분기 ⇔ 수입 = 비용: 5000x = 2000x + 30000
  2. 3000x = 30000 → x = 10
  3. ∴ 10개를 팔면 본전, 그 이상 팔면 이익 (두 직선의 교점이 손익분기점)
도전 3 · 복합

직선과 두 좌표축이 만드는 삼각형의 넓이를 구하는 문제야.

직선 y = −2x + 6 과 x축, y축으로 둘러싸인 삼각형의 넓이는?
삼각형 넓이 =
힌트 1x절편: 0 = −2x + 6 → x = 3. y절편: x=0 → y = 6.
힌트 2밑변 = 3, 높이 = 6인 직각삼각형.
힌트 3넓이 = ½ × 3 × 6 = 9.

✓ 풀이

  1. x절편: 0 = −2x + 6 → x = 3 → (3, 0)
  2. y절편: y = 6 → (0, 6)
  3. 밑변 3, 높이 6인 직각삼각형
  4. 넓이 = ½ × 3 × 6 = 9
