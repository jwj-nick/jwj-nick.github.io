중2-1단원 5연습

유형별 연습 — 일차함수

함숫값부터 식 구하기·활용까지, 시험에 나오는 9가지 유형을 하나씩 다뤄 볼까요?

유형 하나를 다 풀면 위 막대의 그 칸이 완성돼요.

푼 문제: 0 / 27

1함숫값 구하기
대입기본

f(x) 의 x 자리에 수를 대입하면 함숫값이 나와요. 음수는 괄호로 감싸서 넣어요.

(1)f(x) = 2x + 1 일 때 f(3)?

(2)f(x) = −x + 5 일 때 f(2)?

(3)f(x) = 3x − 4 일 때 f(−1)?

왜?3×(−1) − 4 = −3 − 4 = −7. 음수 대입은 괄호로!
2일차함수인지 판별
개념기본

일차함수 = y = ax + b 꼴 (단, a ≠ 0). 상수(y=5)나 이차(y=x²)는 일차함수가 아니에요.

(1)y = 3x − 2 는 일차함수일까요?

(2)y = 7 은 일차함수일까요?

왜?y=7 은 x가 없어요 (a=0). 기울기 없는 상수함수라 일차함수가 아니에요.

(3)y = x² − 1 은 일차함수일까요?

왜?x² 이 있으면 이차예요. 일차함수는 x의 1차식만!
3평행이동
개념보통

y = ax 를 y축 방향으로 b만큼 평행이동하면 y = ax + b. 위로면 +, 아래로면 −.

(1)y = 2x 를 위로 3만큼 옮긴 식의 y절편은?

(2)y = −x 를 아래로 2만큼 옮긴 식의 y절편은?

왜?아래로 2 → y = −x − 2. y절편 = −2.

(3)y = 3x + 1 을 위로 4만큼 옮긴 식의 y절편은?

왜?y = 3x + (1+4) = 3x + 5. y절편 = 5.
4x절편·y절편
원리보통

y절편은 x=0 넣으면 나오는 값(= b). x절편은 y=0 넣고 x를 구해요.

(1)y = 2x − 6 의 x절편은? (y=0 대입)

왜?0 = 2x − 6 → x = 3. x절편 3.

(2)y = 2x − 6 의 y절편은? (x=0 대입)

(3)y = −x + 4 의 x절편은?

5기울기 구하기
원리보통

기울기 = (y의 변화량) ÷ (x의 변화량). 두 점 사이 "세로로 몇, 가로로 몇"을 보면 돼요.

(1)두 점 (1, 2), (3, 8) 을 지나는 직선의 기울기는?

왜?가로 2(1→3), 세로 6(2→8) → 6 ÷ 2 = 3.

(2)두 점 (−1, 2), (2, 8) 의 기울기는?

(3)두 점 (0, 5), (5, 0) 의 기울기는?

왜?세로 −5(5→0), 가로 5 → −5 ÷ 5 = −1. 내리막이라 음수!
6그래프의 모양 (a·b 부호)
성질보통

a > 0 오른쪽 위로(증가), a < 0 오른쪽 아래로(감소). b는 y축과 만나는 높이(+면 위, −면 아래).

(1)y = 2x + 3 의 그래프는 오른쪽으로 갈수록?

(2)y = −3x + 1 의 그래프는 오른쪽으로 갈수록?

왜?기울기 −3 < 0 이라 감소(오른쪽 아래로).

(3)y = 2x − 5 는 y축과 원점보다 위에서 만날까요, 아래에서 만날까요?

왜?y절편 −5 < 0 → 원점보다 아래에서 만나요.
7식 구하기
종합도전

기울기 a를 먼저 구하고, 지나는 점을 대입해 b를 구해요. 그러면 y = ax + b 완성.

(1)기울기 2, 점 (0, 3) 을 지나는 직선의 y절편은?

(2)기울기 −1, 점 (1, 4) 를 지나는 직선의 y절편은?

왜?y = −x + b 에 (1,4) 대입 → 4 = −1 + b → b = 5.

(3)두 점 (0, −2), (2, 4) 를 지나는 직선의 기울기는?

왜?(4 − (−2)) ÷ (2 − 0) = 6 ÷ 2 = 3.
8평행·일치
성질보통

기울기가 같으면 평행(y절편 다름), 기울기·y절편 모두 같으면 일치(같은 직선).

(1)y = 2x + 1 과 평행한 직선의 기울기는?

(2)y = 3x − 2 와 평행하고 점 (0, 4) 를 지나는 직선의 y절편은?

(3)y = ax + 3 이 y = −2x + 1 과 평행할 때 a는?

왜?평행 → 기울기 같음 → a = −2.
9활용 (양초·요금·물통)
실생활보통

상황을 y = ax + b 로 세워요. b = 출발값, a = 매번 변하는 양.

(1)20cm 양초가 1시간에 4cm씩 줄어요(y = 20 − 4x). 3시간 뒤 길이는?

cm

(2)기본요금 3000원 + 1km당 500원 택시로 10km 가면 요금은?

원

(3)물통에 5L가 있고 1분에 2L씩 채워요(y = 5 + 2x). 25L가 되는 건 몇 분 뒤?

분
왜?5 + 2x = 25 → 2x = 20 → x = 10.
