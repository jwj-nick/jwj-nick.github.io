직접 풀어보기 — 일차함수

양초·택시요금·요금제… 변하는 관계를 y = ax + b 로 나타내 써먹어 볼까요?

문제를 풀면 위 막대가 차요. 다 풀면 완료로 표시돼요.

1타들어가는 양초
실생활쉬움
20cm 양초가 1시간에 4cm씩 줄어요. 길이 y = 20 − 4x (x = 시간).

3시간 뒤 양초의 길이는 몇 cm?

cm
왜?y = 20 − 4×3 = 20 − 12 = 8. 기울기 −4는 "1시간마다 4cm 줄어듦", 절편 20은 "출발 길이" → 8cm.
2택시요금 계산기
실생활보통
🚕기본요금 3800원 + 1km당 1000원. 요금 y = 3800 + 1000x (x = km).

5km를 가면 요금은 얼마?

원
왜?y = 3800 + 1000×5 = 8800. 절편 3800=문 여는 순간의 기본요금, 기울기 1000=km당 오르는 요금 → 8800원.
3그래프에서 기울기 읽기
원리보통
📈두 점 (0, 1) 과 (2, 5) 를 지나는 직선이 있어요. 기울기(slope)는 "가로 1칸 갈 때 세로가 몇 칸 오르나".

이 직선의 기울기는?

왜?가로로 2칸(0→2) 갈 때 세로로 4칸(1→5) 올라요. 기울기 = 세로변화 ÷ 가로변화 = 4 ÷ 2 = 2 → 2.
4요금제, 어디서 같아질까
실생활도전
📱데이터 요금제 두 개. A: 기본 10000 + GB당 1000 (y = 10000 + 1000x). B: 기본 5000 + GB당 2000 (y = 5000 + 2000x).

두 요금이 똑같아지는 건 몇 GB일 때? (두 식을 같다고 놓아 보세요)

GB
왜?10000 + 1000x = 5000 + 2000x → 5000 = 1000x → x = 5. 5GB에서 두 요금이 만나 → 5GB. (다음 단원에서 이 "만나는 점"을 더 깊이 볼 거예요!)
